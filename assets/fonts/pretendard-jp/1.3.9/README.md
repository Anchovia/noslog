# Pretendard JP for generated profile images

These are complete, unmodified TTF files from the user-provided official
`PretendardJP-1.3.9.zip`, under `public/static/alternative/`. They are server-only
inputs to ImageResponse/Satori; the website still requests its single WOFF2 file.
No Unicode subsetting or font conversion is performed.

Satori supports TTF/OTF/WOFF, but not WOFF2:
https://github.com/vercel/satori#fonts
