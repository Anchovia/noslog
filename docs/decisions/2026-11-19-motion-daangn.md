# 움직임 판 1차 결정 — 당근 SEED 시간 · 곡선, 진행 막대 · 안내 GIF 는 그대로

- 상태: 일부 대체됨(6 헤더 숨김) → [2026-11-19 움직임 반영](./2026-11-19-motion-apply.md)
- 날짜: 2026-11-19
- 분야: 디자인 · 기초값
- 고른 사람: 사용자(데스크톱 재설계 공통 층 3단계 움직임 판에서 칸마다 고름, 3-m1–m3 은 추천과 다르게 당근을 고름)

## 맥락

지금 움직임은 2026-09-19 에 정한 Atlassian 곡선 두 개((.4,1,.6,1) · (.6,0,.8,.6))와 시간 100–800ms, 대화상자 · 토스트 8px 떠오름이다. 탭 밑줄 · 구역 펼침 · 툴팁 · 체크박스는 즉시 바뀐다. 공통 층 3단계에서 당근 SEED 를 뼈대 한 벌로 삼아, 지금 NosLog 의 움직이는 자리 33곳 · 즉시 자리 19곳을 칸마다 지금 · 당근 · 실측한 서비스 안으로 나란히 재생해 골랐다.

## 결정

곡선 이름은 당근 SEED 값이다. enter (0,0,.15,1) · exit (.35,0,1,1) · easing (.35,0,.35,1) · enter-expressive (.03,.4,.1,1) · exit-expressive (.35,0,.95,.55).

1. 올림 · 누름 색(1-a): 150ms easing. Tailwind 올림 색 자리도 같다.
2. 대화상자(1-c · 3-a): 가림막 100ms enter, 상자 200ms enter-expressive 로 크기 1.3→1 · 불투명 0→1, 사라짐 100ms exit.
3. 토스트(1-d · 3-b): 나타남 150ms enter 로 크기 .8→1 · 불투명 0→1, 사라짐 100ms exit 로 →.8, 여러 장이 자리 옮김 .2s easing, 표시 4000ms.
4. 메뉴(1-b · 3-c): 열림 150ms enter 로 불투명 + 크기 .95→1(원점은 단추 쪽), 닫힘 100ms exit 로 →.95. 1-b 는 판 재생을 고쳐 다시 보여 준 뒤 이 값으로 둔다.
5. 시트(1-e): 스냅 옮김 300ms enter-expressive.
6. 헤더 숨김(1-f): 숨음 300ms exit-expressive · 나타남 300ms enter-expressive. 숨기는 범위는 지금(1055 이하 모든 쪽) 그대로이고 따로 판을 연다.
7. expressive 곡선 두 개를 들인다(2-b). 대화상자 · 시트 · 헤더 숨김 · 내보내기 창이 쓴다.
8. 이미지 내보내기 창(3-d): 열림은 가림막 300ms enter · 창이 아래 100% 에서 300ms enter-expressive, 닫힘은 가림막 · 창 200ms exit.
9. 위쪽 진행 막대(3-e): 지금 그대로. 100ms 안에 끝나면 띄우지 않고, 1500ms 동안 0→80% (.4,1,.6,1), 도착하면 100% 채우고 150ms (.6,0,.8,.6) 로 사라진다. 동작 줄이기에서도 차오름은 남긴다. 옛 곡선 두 개는 진행 막대 전용으로 남는다.
10. 스피너(3-f): 한 바퀴 1.2s (.35,.25,.65,.75) 무한, 호 길이도 1.2s.
11. 그래프 드러남(3-h): 선이 왼쪽부터 1000ms, swing 곡선(0.5 − cos(πt)/2, easeInOutSine). 바닥선 · 축은 그대로다.
12. 값 바뀜(3-i): 막대 길이 · 그래프 값이 .3s enter 로 옮겨 간다.
13. 동기화 안내 GIF(3-l): 지금 그대로. 동작 줄이기에서는 그림 대신 라벨 글자, 누르면 여는 큰 그림은 그대로다.
14. 새 움직임 넷(사용자 허락): 탭 밑줄 left · width .2s easing(3-m1), 구역 펼침 내용 height · opacity 와 화살표 .3s easing(3-m2), 스위치 손잡이 .15s easing · 바탕색 50ms 지연 20ms · 체크 상자 바탕색 .15s easing(3-m3), 툴팁 · 용어 도움말 나타남 200ms enter 불투명 0→1 · 크기 .9→1, 사라짐 200ms easing 페이드(3-m4).
15. 채보 뷰어 말풍선 펼침(4-a): 열림 150ms enter 불투명 0→1 · 크기 .95→1, 닫힘 100ms exit 불투명→0 · 크기→.95. 원점은 시안에서 오른쪽 위로 그렸고 구현 때 확인한다.
16. 그대로 두는 원칙: 움직임은 상태 · 위치 · 로딩에만 쓰고 장식은 없다. 동작 줄이기 규칙은 그대로다.

아직 정하지 않은 칸: 2-a · 3-g 스켈레톤 · 3-j 지도 미끄러짐 · 3-k 서열표 끌어 옮기기 · 4-b, 1-f 숨기는 범위. 정하면 새 결정 파일로 쓴다.

## 고르지 않은 안

- 지금 NosLog 값 그대로(1-a · 1-c–1-f · 3-a–3-d · 3-f · 3-i) — 당근 한 벌로 시간 · 곡선을 맞추는 쪽을 골랐다
- 탭 밑줄 · 구역 펼침 · 체크박스 즉시 유지(3-m1–m3 가, master 추천) — 많은 서비스가 쓰고 당근에 맞추는 편이 낫다고 사용자가 골랐다
- 진행 막대 당근 방식(3-e) — 지금 방식이 낫다고 보고 유지했다
- 그래프 드러남 지금 800ms 막대 · 선 왼쪽부터와 당근 값(3-h) — Steam Charts 방식을 쓰는 곳이 있고 괜찮다고 보고 라를 골랐다
