# 합격 인증 찍을 것 번호 목록

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 디자인 · 화면(검정)
- 고른 사람: 사용자(사용자 지시)

## 맥락

합격 인증의 「찍을 것」 다섯 줄은 줄마다 체크 아이콘을 달고 있었다. 사용자가 체크 대신 번호를 쓰자고 했다. 동기화 번호 원(24)을 먼저 써 보았으나 글자 옆에서 크다고 해 글자 번호로 정했다.

## 결정

- 줄 앞을 `1.` ~ `5.` 글자 번호로 바꾼다. 목록은 순서 목록(`ol`)이고 들여쓰기 24 · decimal 은 공지 본문 번호 목록과 같다.
- 번호 원은 쓰지 않아 [AI 티 확인](../ai-check.md) 6번 「장식 번호」 와 부딪히지 않는다. 예외 추가는 없다.
- 새 값은 없다.

## 근거

사용자 지시.
