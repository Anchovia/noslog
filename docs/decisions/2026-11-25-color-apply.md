# 색 값 반영 — 당근 SEED 다크 한 벌 · 게임 색 · 선 · 포커스 · 올림 · 층 규칙

- 상태: 유효
- 날짜: 2026-11-25
- 분야: 디자인 · 기초값
- 고른 사람: 사용자(공통 층 3단계 색 판을 2026-11-20 부터 2026-11-25 까지 물음마다 고름, 값 판 · 바탕 값 판 · 남은 값 판 · 최종 검수 18물음 포함)

## 맥락

공통 층 3단계 색 결정이 끝났다. 규칙(자리마다 색을 어떻게 쓰나)은 11-20 부터 11-24 까지, 값(어떤 색인가)은 11-25 에 정했다. 사용자는 값 판에서 바탕 · 면 · 글자 같은 파운데이션 색을 한 번 「전부 임시」 로 풀고, 무채 한 벌을 먼저 당근 SEED 3.2.1 다크로 정한 뒤 나머지를 그 위에서 다시 골랐다. 이 파일은 정한 값과 규칙을 코드 · 가이드에 한꺼번에 반영하는 기준이다. 판 · 시안 없이 이 표대로 반영한다. 밝은 테마는 다루지 않는다(11-24 사용자: 「화이트테마는 추후 별도 지원」).

### 7. 규칙

- 목록 · 표 줄 선은 없고 높이 · 간격으로 나눈다. 랭킹은 줄무늬 칸 #1d2025.
- 보더는 어느 층에도 쓰지 않는다. 선은 선이 곧 모양인 부품(입력칸 · 태그 둘레 · 체크박스 · 라디오 · 빈 원 · 인용 선 · 미니맵 창 · 빈 칸 점선)에만 쓴다.
- 포커스는 `focus/ring` 2px 이다. 버튼 · 칩 · 세그먼트 · 체크박스 · 라디오 · 스위치 · 탭 · 링크는 바깥 간격 2px 이고(2026-10-25 결정 5번 「버튼 간격 0」 을 바꿈), 텍스트 입력칸은 둘레에 붙은 링이고 간격이 없다.
- 올림과 눌림은 한 값이다. 면 있는 부품은 면 값을 바꾸고 면 없는 부품은 `interaction/row` 를 쓴다. 위험 버튼은 올림 없이 누름만 있다.
- 고른 것은 반전 면이다(고른 숫자 척도 · 눌러 고른 알약 · 고른 카드 포함, 안쪽 2px 선 없음. 고른 칩 · 세그먼트 칸 · 쪽 번호 · 메뉴 고른 항목 · 투표 고른 항목 · 업적 고르기 · 점수 고르기 · 검정 레일 지금 칸 · 고르기 슬롯 지금 칸 · 이동 메뉴 지금 쪽). 탭은 밑줄 그대로다.
- 링크는 글자 · 밑줄 모두 `content/strong`, 링크 전용 토큰은 없고 평소에도 밑줄이 있다. 푸터 링크만 `content/default` 500 · 처리방침 `content/strong` 700 · 평소 밑줄 없음 · 올림 때 밑줄.
- 층 규칙: 놓인 것(구역 · 상자 · 카드 · 지도 위 검색칸 포함 검색칸 · 악곡 카드 · 홈 이동 칸 · 공식 소식 카드)은 그림자 `0 1px 1px #0000000d` 하나, 붙은 것(헤더 · 표 머리 · 아래 막대 · 진행 막대)과 창(대화상자 · 전체 화면)은 그림자 없음, 떠 있는 것(메뉴 · 셀렉트 · 팝오버 · 툴팁 · 토스트 · 시트 · 검색 미리보기)은 `0 4px 16px #000000cc` 하나. `--nl-tooltip-shadow` 는 지우고 툴팁도 떠 있는 것 그림자를 쓴다.
- 쌓임: 부품 안쪽 above 1 · 붙은 것 200 · 창 300 · 떠 있는 것 400. 같은 단계 안은 문서 순서.
- 대비 기준은 글자 · 글자 아닌 단서 모두 3 : 1 이다(4.5 : 1 에서 낮춤). 사용자 말: 「대비 4.5 기준을 좀 낮추자 저거 사람이 보는거랑 너무 달라」 · 「전체 3:1 로」. 3 아래로 남는 값은 아래 받아들인 대가에 적었다.
- 채운 위험 버튼은 SEED 값을 그대로 둔다(면 #f73526 · 위 글자 #ffffff · 누름 #ff6e60).
- S 색을 다시 골랐다. S #e7d680 → #e3cb53, 990k #f6cb93 → #f7c481(S 와 Pianist 셋째 띠 #f7c6ad 의 OKLCH 평균). 등급 띠와 그레이드 진행 막대도 새 값을 따른다(S 색 판 v1795607481-434c 안 1). 사용자 말: 「s 색깔이 살짝 물탄느낌이라 별론데」 · 「안 1 채도 0.14 추천 이렇게 하자」.
- 같은 뜻은 어느 자리에서도 같은 역할이고, 게임 색 · 상태색은 그 뜻의 자리에만 쓴다. 고유한 뜻이 있는 자리는 그 뜻의 역할 이름을 따로 둔다.
- 게임 원본 색 · 파생 색은 겹침으로 세지 않는다. 판정 JUST(게임 픽셀 값) · 장르 ORIGINAL(게임 장르 색) · 난이도 Hard 처럼 게임에 원본이 있는 색, 그리고 990k(S 와 Pianist 사이) · 서열 계단(난이도 색을 펼친 값)처럼 정한 색에서 끌어낸 색은 다른 역할 색과 가까워도 충돌이 아니고 대가로도 적지 않는다. 서열 계단 사이 칸이 등급 A · 위험 색과 가까운 것도 같다. 사용자 말: 「Just 고유의 색상이 있고 990k는 s랑 p 사이의 색상인데 이게 뭐가 문젠데」 · 「c부터 p까지 색상을 펼쳐서 만든건데 그럼 그 색깔이여야지 뭘 저걸 또 분리하려고 해」.
- 움직임 ⑰(카드 그림 올림)에 서열 카드 · 동기화 사진 칸 두 자리를 더한다.
- `docs/ai-check.md` 2 · 3 · 4 · 5 문구를 위 규칙에 맞춘다.

## 받아들인 대가

정본에 적힌 대가와 최종 검수가 짚은 미달 · 근접 값이다. 값 근거는 대부분 「근거 약함」(실제 서비스 · 디자인 시스템 표본이 적음)이고, 대비 숫자는 #16171b · #2b2e35 위에서 쟀다. 투표 결과 막대 · 채보 색 · 달력 빈 칸과 패턴 0단계의 값 차이는 정본에 대가가 적혀 있지 않아 최종 검수가 짚은 것이다.

- 무채 한 벌: 지금보다 낮은 칸 구분선 1.34 → 1.14 · 둘레 1.77 → 1.28. 상태색 성공 8.61 → 7.74 · 7.34 → 6.60 · 5.57 → 5.01, 경고 13.39 → 7.52 · 11.42 → 6.41 · 8.67 → 4.87. 위험 버튼 위 글자 5.24 → 3.82 는 3 : 1 기준으로 통과한다.
- 입력칸 선 #393d46 은 #16171b 위 1.65 · #2b2e35 위 1.25 이고 3.0 에 못 미친다. 미니맵 창 1.44 · 1.06, 빈 칸 점선 1.65 · 1.25 도 같다. 선이 곧 모양인 자리(미니맵 창 · 인용 선 · 빈 원)가 가장 흐리다.
- 활동 달력 1단 1.38 · 2단 2.75, 업적 동 #2b2e35 위 3.50 은 3 : 1 기준으로 통과한다.
- 포커스 링은 흰 #f3f4f5 그대로 두고 SEED 파랑 링 #1e82eb 은 쓰지 않는다. 낮아진 칸 목록에 링은 들지 않는다.
- 올림 = 눌림 한 값이라 누른 순간 변화가 없다. 올림 값 #393d46 은 트랙 · 입력칸 선과 같은 값이고, 스켈레톤 #1d2025 는 검색칸 면 · 랭킹 줄무늬 칸과 같은 값이며 줄무늬는 거의 보이지 않는다.
- 난이도 Carbon 40 은 다크 태그가 실제로 쓰는 단계(40 · 50)를 확인하지 못했다(디자인 시스템 1곳). Normal 대 성공 ΔE 8.5 · Expert 대 위험 8.6 으로 가깝다. 서열 6–8 구간은 Normal 과 한 단계로 묶인다.
- 판정: GOOD #00a8c4 는 지금 #4ccce6 보다 낮다(게임 색을 그대로 쓴 대가). MISS 는 글자 2단 #dcdee3 과 ΔE 4.0. NEAR #bfd5ec 는 게임 캡처 없이 사용자 기억 값이다. ◆JUST #ff8dcc 는 지금 값 유지이고 게임 값이 아니다.
- 점수 목표 Pianist 무지갯빛 띠의 채도(0.066–0.088)가 S(0.14)보다 낮아 특별함은 여러 색 이음에서 온다. 점수 등급은 A 가 위험 글자 #ff6e60 과 ΔE 2.6, B 가 GOOD 과 4.8, C 가 Expert 와 5.7 로 가깝다.
- 장르 여섯 색은 공식 hex 가 없어 게임 타일 영상 평균에서 옮겼다. BEMANI 는 #2b2e35 위 4.50 으로 3 : 1 기준으로 통과하고, VARIETY 는 경고 #ca901c 와 ΔE 4.8 이다.
- 서열 계단 E–R 칸이 ◆JUST 와 ΔE 4.4 로 가깝다. 끝 색 #ff45ff 는 SEED 밖 새 값이다.
- 검정 곡: 첫째 #4589ff 가 가운데 줄 아래로 내려가 세 곡 밝기가 같지 않고 채도가 진하며 안내 #41a2f9 와 ΔE 9.1, 셋째 #f1c21b 는 검정 급 금 #dab156 과 ΔE 8.4 다. Carbon 문서는 팔레트를 순서대로 쓰라고 하는데 번호를 건너뛰었다. 합격까지 막대는 실측 표본이 Grafana 한 곳이다.
- 업적 위 두 단: 백금 #36cfb0 은 검정 여유 + #35ce9a 와 ΔE 5.6, 다이아 #b9f2ff 는 FC #d4f6ef 와 ΔE 8.7 이다. 업적 금속 값은 SEED 칸이고 AccSaber 한 벌과 다르다.
- 활동 달력 4단 #56d364 가 Normal #42be65 와 같은 초록 자리다. 달력 빈 칸 #1d2025 와 패턴 0단계 #868b94 는 같은 사다리의 0 인데 값이 다르다.
- FAST #5cc1f7 · SLOW #fa575e 는 사용자가 IIDX 꼴로 새로 정했고, SLOW 가 위험 글자 #ff6e60 과 ΔE 6.0 이며 값은 그림에서 뽑은 근삿값이다([조사](../research/2026-11-25-rhythm-fast-slow-colors.md)). FC #d4f6ef 는 게임 원본이 없고 사용자가 고른 값으로 확정했다. 내 위치 #dab156 은 금과 같은 값이고 경고와 가깝다.
- 지도 핀 #5b63d2 는 SEED 밖 새 값이고 근거가 호갱노노 한 곳이다. 카카오 지도 타일 일곱 곳 위 대비가 모두 3.0 을 넘는다.
- 빙고: 채운 칸이 완성 줄에 들었는지는 색으로 갈리지 않고 판 가장자리 줄 진행 표시로만 보인다.
- 투표 결과 1위 #b0b3ba 는 같은 판 서열 투표 분포(1위만 서열 값 색)와 다른 꼴이다. 글자 3단과 같은 값이다.
- 채보 무대 · 두 손 색을 지금 값으로 두는 근거는 「채보 에디터 모양 그대로」 이고, 같은 색을 쓰는 공개 채보 뷰어에는 실측 2곳 · 근거 약함만 남는다.

서열 값 계단 사이 칸의 구간(위 4절)은 사용자가 안 A 로 정했다. 사용자 말: 「그럼 규칙상 a가 맞다는거지 ? 그럼 a로 하자」, 안 B 와 다시 본 뒤 「아니다 그냥 이대로 하자」.

- 랭킹 내 줄 면은 `surface/surface` #16171b 그대로 둔다. 줄무늬(홀수 #000000 · 짝수 #1d2025)와 함께 놓이면 내 줄이 홀수 자리에서는 줄무늬 한 줄처럼, 짝수 자리에서는 줄무늬보다 어둡게 보인다. 랭킹 줄무늬 칸을 구역 면 #16171b 위로 전제했지만 실제로는 쪽 바탕 #000000 위에 놓이고, 이 어긋남도 받는다. 사용자 말: 「A 유지로 하자」.

## 고르지 않은 안

- Spectrum 2 다크 · Geist 다크 · shadcn 무채색 유지 — 사용자가 나머지 값을 모두 당근 SEED 로 정해 놓았으니 기준선도 당근으로 한다고 정했다.
- SEED 파랑 포커스 링 #1e82eb — 무채색 사이트에 유채 링을 두지 않는다.
- 난이도 SEED 700(성공 · 위험 값과 겹침) · 중간값 시안 — Carbon 40 을 골랐다.
- 달력 빈 칸을 트랙으로 바꾸는 안 · 빙고 채운 칸 중간 회색 안 · 검정 급 회 단 — 정한 규칙에서 값을 끌어내야 해서 버렸다.
- 투표 결과 1위 흰 강조 · 서열 값 색 강조 — 1위 #b0b3ba, 나머지 #868b94 로 정했다.
- 점수 자 남의 핀 컨트롤 면 · 트랙 안 — 지금보다 덜 보여 흰 #ffffff 로 정했다.
