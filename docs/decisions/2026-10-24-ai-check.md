# AI 티 피하기 — 확인 목록 · 기계 검사 · 감사 스킬

- 상태: 유효
- 날짜: 2026-10-24
- 분야: 구조
- 고른 사람: 사용자(시안 판 5 추천대로)

## 맥락

화면 · 코드 · 글이 「AI 가 만든 티」 가 난다는 지적이 쌓였다(상태 아이콘 · 색 상자 · 번호 원 · 덧붙인 안내 줄 · 확인 안 한 「완료」 보고 등). 지적은 Claude 메모리에만 남아 다른 에이전트가 보지 못했고, 가이드에는 반대 문장이 남아 있었다. 사용자는 매 작업마다 보는 문서를 원했다.

## 결정

세 겹으로 막는다.

1. `docs/ai-check.md` — 32줄 확인 목록(화면 · 문구 · 구현 · 테스트 · 보고). `AGENTS.md` 가 모든 작업 시작 때 읽게 한다.
2. `tests/ai-tells.test.ts` — 기계로 잴 수 있는 것: 메시지 카탈로그 값의 이모지 · 느낌표 · 줄표 · 금지어, 공개 CSS 의 허용 목록 밖 그라데이션 · 흐림 · 글자 그림자 · `transition: all`, 공개 TSX 의 상태 아이콘 import.
3. `.claude/skills/noslog-check` — `/noslog-check` 로 부르는 감사 스킬(새 맥락). 긴 목록(화면 87 · 구현 66 · 글 161)은 참조 파일로.

외부 스킬은 설치하지 않고 규칙만 우리 말로 옮긴다.

## 고르지 않은 안

- 문서만 — 300항목을 매번 읽혀 덜 지키고, 기계 검사가 없다.
- 스킬 + 훅만 — 스킬이 자동으로 안 켜지는 경우가 절반 가까이다.

## 근거

- Vercel(Next.js 16 API 지식 평가): AGENTS.md 압축 색인 100% · 스킬 기본 53%(문서 없음과 같음) · 스킬 + 쓰라는 지시 79%, 스킬이 56% 사례에서 안 불림. Scott Spence: 훅 없이 스킬 50–55%.
- Claude 문서: CLAUDE.md 는 맥락이고, 훅 · 테스트가 보장. IFScale: 지시가 많을수록 덜 지킴.
- Snyk ToxicSkills: 스킬 3,984개 중 36.82% 보안 결함 — 외부 스킬을 설치하지 않는 근거.
