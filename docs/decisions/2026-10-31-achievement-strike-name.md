# 업적 「전 난이도」 이름을 「스트라이크」로

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 기능
- 고른 사람: 사용자 지시

## 맥락

`all-difficulty` 업적은 한 곡의 모든 난이도를 S 이상으로 채운 곡 수를 센다. 이름 「전 난이도」 는 난이도 전체를 채우는 업적처럼 읽혔다.
「한 곡 정복」 · 「올 난이도」 · 「한 곡 올 S」 · 「전 난이도 정복」 은 AI 말투 같다는 이유로, 「곡 싹쓸이」 · 「올킬」 · 「풀 세트」 · 「올클」 은 사용자가 고르지 않아 쓰지 않았다.

## 결정

1. `all-difficulty` 의 이름을 ko 「스트라이크」 · ja 「ストライク」 · en 「Strike」 로 한다. 한 곡의 핀(난이도)을 한 번에 다 쓰러뜨린다는 볼링 말이다.
2. 데이터 키 · 지표 이름 · 단계 기준값 · 조건 문구는 그대로다.

## 고르지 않은 안

- 한 곡 정복 · 올 난이도 · 한 곡 올 S · 전 난이도 정복 — 사용자가 AI 말투라고 반려.

## 근거

- 다른 서비스의 이름: 웹 검색 네 번에서 같은 조건의 업적 이름을 찾지 못했다(DJMAX RESPECT V 등은 조건 문장만 있고 이름이 확인되지 않음). 근거 약함.
