# 값이 빈 채보에도 Grd 상한을 두고, 범위 밖 저장 기록은 남기지 않음

- 상태: 유효
- 날짜: 2026-11-02
- 분야: 기능
- 고른 사람: 사용자(다섯 영역 점검 수정 지시)

## 맥락

노트 수나 상수가 빈 채보는 Grd 검사를 건너뛰어 100,000,000 이 저장됐다. 값 검사에 걸린 채보의 기록을 남기면서 이렇게 들어온 위조 행도 남았다. 같은 채보를 반복해 보내면 클리어 랭크 수가 부풀었다.

## 결정

- 값이 빈 채보의 Grd 상한은 상수 15 · 노트 수 9,999 로 계산한다. Recital 은 그 1.25배다.
- 값 검사에 걸린 채보의 기존 기록은 저장된 Grd 가 범위 안일 때만 남긴다.
- 전체 기록에 같은 채보가 두 번 오면 400 으로 거절한다.

## 고르지 않은 안

- 값이 빈 채보의 기록을 받지 않기: 새 곡을 친 정상 기록까지 빠진다
- 값을 채울 때 범위 밖 기록을 바로 지우기: 운영자 저장이 다른 사람의 기록을 지우게 된다

## 근거

- 복사본 재현: 값이 빈 채보에 100,000,000 저장, 같은 곡 500번으로 P 수 1,000

## 한계

절대 상한은 실제 최대보다 높아 그 안쪽의 위조는 막지 못한다. 범위 밖 저장 기록은 그 사람이 전체 동기화에서 다시 걸려야 지워지고, 동기화하지 않으면 남는다.
