# 가이드 다시 대조에서 갈린 40곳

- 상태: 일부 대체됨(11 지도 아래 시트 · 지도 위 검색칸 · 지도 위 버튼 모서리 · 16 동기화 단계 카드) → [2026-10-27 부품 토큰 Spectrum 2](./2026-10-27-spectrum-components.md)
- 날짜: 2026-10-27
- 분야: 디자인 · 기초값
- 고른 사람: 사용자(시안 추천대로 전부)

## 맥락

가이드 문서 44개와 코드 전체를 영역 11개로 나눠 다시 대조했다. 보고 298건 가운데 40곳은 두 정본이 서로 다르게 적었거나, 가이드가 말하지 않는 모양이 코드에 있었다. 안은 모두 그 자리의 지금 문서 값이나 지금 코드 값이고 새 값 · 새 토큰은 없다.

## 결정

모양

1. 줄 안 셀렉트의 `outlined` 는 설정 줄에서만 쓴다. 프로필 기간 · 랭킹 지역 · 채보 노트 속도 셀렉트는 면 없는 기본이다.
2. 한 줄에 태그는 하나다. 뮤즈캣 목록 줄은 상태 태그 하나에 대수는 메타 글줄, 빙고 칸 상세 머리도 태그 하나다.
3. 로그아웃이면 제목 줄 「로그인하고 ○○ ›」, 자격이 없으면 입력을 숨기고 설명 문장을 두지 않는다. 이벤트 글쓰기 · 악곡 레일 「내 기록」 · 투표 결과 비공개 · 설정 손님 · 합격 인증 · 게스트 빙고가 해당된다.
4. 같은 화면은 「데이터 동기화」 한 낱말로 부른다.
5. 상자 제목(`nl-component-title`)도 자간 `--nl-type-tracking-title` 이다.
6. 폰에서 전체 화면으로 여는 입력 창은 본문 세로 간격 32 다(두 길 모두).
7. 바탕 위 막대 트랙(누적 막대 · 랭크 분포)은 `border/divider` 다.
8. 체크 목록(`SelectionList`) 줄 사이는 0 이고 줄 높이는 컨트롤 높이다.
9. 점수 자 끝 핀은 안쪽으로 16 당기고 점은 제자리에 둔다.
10. 서열 투표 분포는 막대 목록(`BarList`)이다.
11. 지도 아래 시트 · 지도 위 검색칸은 떠 있는 창 규격(모서리 12 · 둘레 `border/elevated`)이다. 지도 위 버튼은 둘레만 `border/elevated` 이고 모서리는 `radius/control` 그대로다.
12. 필터 개수 배지 면은 `surface/control` 이다.
13. 고른 것 칩의 빈 칸 경계는 `border/ring` 이다.
14. 서열표 · 빙고 목록형 줄의 올림은 `interaction/row` 겹침이다.
15. 공유 이미지의 「NosLog」 는 `content/default` · 600 · 사이트 글꼴, 고양이 원은 `identity-mark` 다.
16. 동기화 단계 카드는 면 카드 규격(둘레 `border/elevated` · 안쪽 16, 1056 이상 24)이다.
17. 프로필 정보 두 줄의 라벨은 `nl-metadata` 흐림이다.
18. 검정 선택 목록은 오른쪽 상태 칸 · 트리거 폭을 둔다. 메뉴 문서에 상태 칸이 있는 목록 변형으로 적는다.
19. 채보 재생 막대의 지나간 구간은 `primary/default` 로 채운다.
20. 헤더 로그인 · ≡ 버튼의 포커스 선 간격은 0 이다.

동작 · 문구

21. 즉시 저장은 저장 상태를 보이고 실패하면 「다시 시도」 를 둔다.
22. `MUSECAT_MODE` 가 꺼져도 연결 기록이 있으면 설정의 뮤즈캣 줄을 보인다(끊을 길을 남긴다).
23. 뮤즈캣 「보냄」 은 `content/default`, 「안 보냄」 은 `content/subdued` 다.
24. 로그인한 동기화 화면의 주 버튼도 넓은 폭에서 내용 폭 · 왼쪽이다.
25. 설정 줄 설명(사진 · 오락실 이용 불가)은 `nl-metadata`(16)다.
26. 뮤즈캣 연결 상세는 설정 줄 목록 규격이다.
27. 다시 동의할 때도 체크는 모두 꺼져 있다.
28. 못 얻은 업적은 분류 순에서도 뒤로 보낸다.
29. 그래프 세로 값 축 높이는 그래프 틀 높이를 따른다.
30. 채보 의견에서 로그아웃이면 필터 자리에 로그인 링크를 둔다.
31. 오락실 「자세히」 는 평소 면이 없고 올릴 때만 칠한다.
32. 같은 탭 안 목록 줄 선은 모두 `border/row` 다.
33. 서열표 「N월 N일 업데이트」 는 배치 · 구간이 바뀐 날이다.
34. 서열표 레벨 순에서 Real 은 맨 끝 한 묶음이다.
35. 검정 반려에는 사유가 있어야 한다.
36. 메뉴 항목의 복사 성공은 토스트로 알린다(메뉴가 닫혀 버튼 글자를 바꿀 수 없다).
37. 빙고 넓은 폭에도 결과 쪽에 결과 수를 둔다.
38. 공지 · 이벤트 글쓰기 아래 바 왼쪽에 「나가기」 를 둔다.
39. 토큰 검사는 `.ts` · 변형 접두(`md:` 등) · 색 팔레트 클래스 · `admin.css` · 캔버스 색도 본다. 예외는 목록에 이유와 함께 둔다.
40. 빙고 자켓 위 카드 트랙은 `border/divider` 다.

## 고르지 않은 안

- 각 자리의 다른 값(지금 코드 값 또는 지금 화면 문서 값). 시안 「NosLog 가이드 대조 2차」 의 B 안들이다.
- 22번은 우선순위로는 문서(꺼지면 없음)가 앞서지만, 연결한 사람이 끊을 곳이 없어져 지금보다 나빠지므로 코드 쪽을 골랐다.
- 18번은 메뉴 문서대로 체크로 바꾸면 급 상태가 목록에서 빠져 지금보다 나빠지므로 상태 칸을 남겼다.

## 근거

- 두 NosLog 문서(또는 문서와 코드) 중 고르는 질문이라 외부 서비스는 재지 않았다. 추천은 「사용자 최신 결정 → 기초값 → 부품 → 패턴 → 화면」 순서다.
- 실측(localhost:3000 · 1280 · 390): 입력 아이콘 #ededed(문서 #8f8f8f), 검색 올림 경계 변화 없음, 앵커 이동 위 여백 80 + 64, 프로필 구역 간격 16 · 12.
- 대비 계산: 바탕 #000 위 `surface/surface` 트랙 1.06 : 1, 기본 태그 면 위 위험 글자 약 3.3 : 1.
