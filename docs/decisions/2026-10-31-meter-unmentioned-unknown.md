# 변박 언급 없음은 「—」

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 기능
- 고른 사람: 사용자(추천대로)

## 맥락

변박이 많은 海神 (BEMANI SYMPHONY Arr.) 가 「없음」 으로 나왔다. 변박 기록은 읽은 글에 언급이 없으면 없음으로 적었고, 海神 의 근거는 영상 링크 하나뿐이었다.
기록 540곡 가운데 519곡이 이렇게 들어간 없음이었다.

## 결정

- 변박이 없다고 확인한 곡만 없음이다. 글에 언급이 없는 곡은 「—」 다. 언급으로 들어간 519곡을 기록에서 뺀다.
- 海神 은 사용자 확인으로 많음이다.
- 사용자가 변박 곡이라고 알려 주거나 글에서 확인한 곡을 기록에 더한다. 기록을 고치면 `npm run db:backfill:pattern-metrics` 로 다시 채운다.

## 고르지 않은 안

- 영상 마디선으로 전곡 재기 — 게임 화면의 선이 박마다 같아 마디 경계를 읽을 수 없다(아래 근거).
- 언급 없음을 없음으로 유지 — 값이 나오는 채보는 많지만 海神 처럼 틀린 값을 사실처럼 보여 준다.

## 근거

- 海神 Real 영상(10.5–137초, 약 390개 선)을 프레임 단위로 쟀다. 선 두께는 2px 로 같고, 밝기의 자기상관은 4박 0.23 · 10박 0.23 으로 4박 주기가 두드러지지 않고, 색은 배경 구간에 따라서만 바뀌었다. 선 간격은 160 BPM 의 한 박(22.5프레임)이다.
- 채보에서 추정하는 방법은 [10-30 결정](./2026-10-30-pattern-tendency-v2.md)에서 이미 맞지 않았다. 그 결정에 값이 나오는 채보가 39 / 723 이라고 적혀 있다.
- 변박 곡 한 곡만 잰 결과라 다른 곡의 선 모양은 미확인이다.
