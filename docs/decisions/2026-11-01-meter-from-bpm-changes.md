# 변박은 박자 · BPM 변화를 채보에서 계산

- 상태: 유효
- 날짜: 2026-11-01
- 분야: 기능
- 고른 사람: 사용자(변박 뜻 · 채보에서 읽기), 단계 기준은 기존 값 유지

## 맥락

변박을 박자표 변화로만 보고 영상 추출 채보의 값을 버려서, 운영 공개 채보 723개 중 701개가 「—」 였다.
BPM 이 15번 바뀌는 Concertino in Blue Real 도 「—」 로 나왔다. 사용자가 BPM 변화도 변박이고 채보에 있는 값을 읽으라고 정했다.

## 결정

- 변박 = 박자 변화 + BPM 변화. 정의와 단계 기준은 [기능 규칙](../design/product-rules.md)에 둔다. 계산식 버전 3.
- 영상 추출 채보도 같은 식으로 계산한다. 값이 없어 「—」 인 경우는 공개 채보가 없을 때뿐이다.
- 곡별 변박 기록에 있는 곡은 기록을 쓴다.

## 고르지 않은 안

- 변속 횟수로 단계 매기기 — 기록 곡과 비교하면 62회인 量子の海のリントヴルム 이 많음이 되어 기록(보통)과 어긋난다. 시간 비율은 0.22 로 보통이다.

## 근거

- 운영 공개 채보 723개(437곡)를 읽기 전용으로 읽었다. 723개 모두 마지막 편집이 영상 추출이고, 채보마다 박자표는 하나다(4/4 649 · 3/4 74). 곡 중간의 박자표 변화는 0 이다.
- BPM 변화는 있다. 변속 0회 316개 · 1–2회 72 · 3–5회 77 · 6–15회 101 · 16회 이상 157.
- 예상 분포(기록 우선): 없음 309 · 적음 138 · 보통 103 · 많음 173.
- 기록 곡 대조: BPM 이 일정한 변박 곡(Leviathan · Ater Regis 등)은 채보 비율이 0 이라 기록이 있어야 맞게 나온다. 기록에 없는 이런 곡은 「없음」 으로 나온다.
