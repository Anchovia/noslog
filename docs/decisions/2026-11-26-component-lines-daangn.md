# 부품 선을 당근 기준으로 — 검색칸 · 파일 줄은 선 없음, 입력 계열 · 체크 · 라디오는 1px

- 상태: 유효
- 날짜: 2026-11-26
- 분야: 디자인 · 부품
- 고른 사람: 사용자(부품 선 판 여섯 칸을 「추천대로 모두」 로 고름, 판 version 1795686483-525f)

## 맥락

부품 선은 Spectrum 2 시절 값(입력 계열 2px 경계, 검색칸 경계, 체크박스 · 라디오 2px 링)이 그대로 남아, 같은 입력 계열이 당근 기준선(1px · 면으로 구분)과 달랐다. 3단계 색 결정은 선을 「선이 곧 모양인 부품」 에만 쓰기로 했지만 굵기와 대상은 정하지 않았다.

## 결정

1. 검색칸(평소 · 포커스 · 지도 위 검색칸)은 선이 없다. 면 `surface/search` 와 놓인 것 그림자 `--nl-card-shadow` 하나로 보이고, 포커스는 포커스 링으로만 보인다.
2. 입력칸 · 여러 줄 입력 · 단위 입력은 선 굵기를 2px 에서 1px 로 줄인다. 색 `border/input` 은 그대로이고 오류 경계도 1px 이다. 포커스는 테두리 색을 바꾸지 않고 [포커스](../design/foundations.md#포커스)의 둘레 링(2px `focus/ring`)이며 1px 선은 그대로 둔다.
3. 스테퍼 둘레 선도 1px 이다.
4. 파일 줄은 선이 없다.
5. 체크박스 · 체크 목록 상자 · 라디오 고리 선은 1px 이다. 고른 모양(체크 면 · 라디오 굵은 고리)은 결정된 모양 그대로다.
6. 적용 조건 알약 · 숫자 척도 칸 · 업적 고르기 칸의 선 색은 `border/input` 이 아니라 `border/default` 다. 굵기는 1px 그대로다.
7. 공지 편집기 · 채보 에디터 입력칸도 공용 부품 새 모양을 따른다(사용자 2026-11-26). AGENTS.md · 관리자 화면 가이드도 같은 뜻으로 고침.

## 고르지 않은 안

- 지금 꼴(면 + 2px 선) 유지 — 당근 기준선과 달라 부품마다 선 굵기가 갈린다
- 당근 입력칸 꼴(1px 선 · 면 없음)을 검색칸에도 쓰기 — 검색칸은 면 `surface/search` 와 그림자로 구분한다
- 다른 칸(스테퍼 · 파일 줄 · 체크 · 라디오 · 선 색)은 판에 적힌 「지금」 꼴을 고르지 않았다

## 근거

- 판(비공개)의 칸마다 「정본 영향」 줄에 값을 적었고 이 파일이 그 값을 옮긴다.
- 포커스 링 · 셀렉트 · 버튼 · 칩 · 카드 · 메뉴는 이미 당근과 같아 건드리지 않는다.
