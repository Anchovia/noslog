# 점수 등급 이름을 랭크로 통일

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 문구 · 화면(곡 상세 · 프로필)
- 고른 사람: 사용자(스크린샷을 보이며 「등급 말고 랭크로」 라고 지시)

## 맥락

곡 상세 내 기록 수치 칸의 S 글자 아래 라벨이 ko 「등급」 · en 「Grade」 였다. 같은 값을 프로필 랭크 분포 · 「{rank} 랭크」 는 이미 「랭크 / Rank / ランク」 로 불러 한 낱말 규칙([AI 티 확인](../ai-check.md) 19번)에 어긋났다.

## 결정

- 점수 등급(S · A+ 같은 클리어 등급)의 이름은 세 언어 모두 「랭크 · Rank · ランク」 하나다.
- 바뀐 문구: `ranking.grade`(ko · en, ja 는 이미 ランク), `partner.consent.item.song_records.help` ko.
- 가이드의 같은 뜻 표기(수치 띠 값 표 · 곡 상세 · 프로필 표 머리)도 「랭크」 로 맞춘다.
- 뜻이 다른 「등급」 은 그대로다: 기여 등급 · 업적 단계 · 이용 등급(Gemini) · 「Grd · 그레이드」(공식 수치).
- 데이터 키 · 타입 이름(`grade`)은 바꾸지 않는다.
