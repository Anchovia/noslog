# 업적 「1인 4역」 삭제

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 기능
- 고른 사람: 사용자 지시

## 결정

`erlkonig` 업적(「1인 4역」, 魔王 모든 난이도 풀콤보)을 곡 묶음 정의 · 아이콘 · ko ja en 이름 · 조건 문구에서 지운다. 이미 얻은 사람의 `user_achievements` 행은 DB 에 남고, 업적 목록과 프로필에는 보이지 않는다. 행까지 지우려면 관리자 「업적 다시 판정」 의 「기준에 못 미치는 단계도 빼기」 를 체크한다([기능 규칙 › 업적](../design/product-rules.md#업적)).
