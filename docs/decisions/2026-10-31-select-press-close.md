# 열린 셀렉트 트리거를 다시 누르면 닫힘

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 디자인 · 동작(셀렉트)
- 고른 사람: 사용자(스크린샷을 보이며 열린 「검정 선택」 칸을 다시 누르면 닫혀야 한다고 지시)

## 맥락

[2026-10-28 전수 검수](./2026-10-28-audit-fixes.md)가 공용 `useSelectOpen` 훅으로 「누르면 닫히고 끝」 을 정했다. 그런데 검정 선택 칸(`exam-navigation.tsx`)과 서열표 목록 전환(`tier-list-switcher.tsx`)은 Radix 셀렉트를 직접 써서 이 훅을 받지 않았다. 바깥 누름으로 닫힌 직후 같은 누름이 다시 열어 목록이 깜빡이며 열려 있었다.

## 결정

- 셀렉트는 모두 `useSelectOpen` 을 거친다. 두 칸에도 연결한다. 누름으로 닫은 직후 200ms 는 다시 열지 않고, Escape · 방향키 · Enter · Space · 바깥 누름 닫기는 그대로다.
- 새 움직임 · 토큰은 없다.
- 스토리 `PressTriggerCloses` 가 열린 트리거를 다시 누르면 닫힌 채로 남는 것을 지킨다.
