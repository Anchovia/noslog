# 채보 뷰어 「공유」 복사는 토스트로 알린다

- 상태: 유효
- 날짜: 2026-11-12
- 분야: 디자인 · 부품
- 고른 사람: 사용자

## 맥락

데스크톱 악곡 Figma 결정본의 상태 칸 「링크 복사됨」 을 그리다가, 가이드와 코드가 다르다는 것을 찾았다. 가이드 상태 메시지는 복사 성공을 토스트 대신 누른 버튼 글자 2초 「복사됨」 으로 적고, 채보 뷰어 무대 아래 「공유」 는 토스트 「링크 복사됨」 을 띄운다. 판 13 에서 두 쪽을 견줬다.

## 결정

1. 채보 뷰어 「공유」 로 링크를 복사하면 지금 코드대로 아래 가운데 토스트 「링크 복사됨」 으로 알린다.
2. 다른 버튼의 복사 성공 규칙(버튼 글자 2초 「복사됨」)은 그대로다.

사용자 원문: 판 13 안 2 를 붙여 「이것도 토스트 쓰자」.

## 고르지 않은 안

- 안 1 가이드 그대로, 「공유」 버튼 글자가 2초 「복사됨」: 사용자가 토스트를 고름.
