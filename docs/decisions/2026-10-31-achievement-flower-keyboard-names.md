# 업적 「FLOWER」 이름을 「리국가」로 · 「흑건 백건」을 「흑건과 백건」으로

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 기능
- 고른 사람: 사용자 지시

## 결정

1. `flower` 업적의 한국어 이름을 「리국가」 로 한다. 일본어 「全機種制覇」 · 영어 「FLOWER Everywhere」 는 그대로다. 조건 문구(「FLOWER 두 판 S 이상 N곡」)는 곡 이름을 가리키므로 그대로 둔다.
2. `keyboard` 업적의 한국어 이름을 「흑건과 백건」 으로 한다. 일본어 · 영어 이름과 조건 문구는 그대로다.
3. 데이터 키 · 곡 목록 · 단계 기준값은 바꾸지 않는다.
