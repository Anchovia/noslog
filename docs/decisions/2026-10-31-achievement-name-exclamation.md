# 업적 이름의 느낌표 예외 · 「도움이 돼요」를 「좋아요!」로

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 기능
- 고른 사람: 사용자 지시

## 맥락

「와 샌즈」를 「와! 샌즈」로, 「도움이 돼요」를 「좋아요!」로 바꾸려 했으나 한국어 카탈로그의 느낌표를 `tests/ai-tells.test.ts` 가 막았다. 사용자가 두 이름에 한해 예외를 허용했다.

## 결정

1. 한국어 업적 이름 `achievement.name.megalovania`(「와! 샌즈」) · `achievement.name.helpful`(「좋아요!」)의 느낌표를 허용한다. [AI 티 확인](../ai-check.md)의 「NosLog 에서 정한 예외」 에 적고, 검사는 이 두 키만 건너뛴다. 이름 밖 문구의 느낌표는 그대로 막는다.
2. `helpful` 업적의 조건 문구 두 곳과 기능 규칙의 낱말을 화면의 좋아요 버튼에 맞춰 「좋아요」 로 고친다(「좋아요」 N번 받기). 일본어 · 영어 문구와 데이터 키 · 단계 기준값은 그대로다.
