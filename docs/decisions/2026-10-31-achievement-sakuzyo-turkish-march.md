# 업적 「사쿠죠」 이름을 「삭제」로 · 「터키 행진곡 두 곡」 삭제

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 기능
- 고른 사람: 사용자 지시

## 결정

1. `sakuzyo` 업적의 한국어 이름을 「삭제」 로 한다. 일본어 「削除曲」 · 영어 「Sakuzyo」 는 그대로다. 조건 문구 · 곡 목록 · 단계 기준값도 그대로다.
2. `turkish-march` 업적(「터키 행진곡 두 곡」)을 곡 묶음 정의 · 아이콘 · ko ja en 이름 · 조건 문구에서 지운다.
3. 이미 얻은 사람의 `user_achievements` 행은 DB 에 남는다. 업적 목록과 프로필에는 정의가 없어 보이지 않고, 관리자 「업적 다시 판정」 의 「기준에 못 미치는 단계도 빼기」 를 체크하면 지워진다([기능 규칙 › 업적](../design/product-rules.md#업적)).
