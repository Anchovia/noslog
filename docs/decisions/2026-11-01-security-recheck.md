# 보안 재점검 수정 — 투표 표 수 · 성장 그래프 이력 · 곡 후보 전체 상한

- 상태: 유효
- 날짜: 2026-11-01
- 분야: 기능
- 고른 사람: 사용자 지시(전체 상한 값은 수정 세션이 정했다)

## 맥락

정식 배포 전 재점검에서 보통 등급으로 남은 항목 가운데 다섯 건을 고쳤다. 코드만으로 정해지지 않는 것은 비공개 범위와 곡 후보 전체 상한이다.

## 결정

- 투표 결과가 공개 조건이 되기 전에는 응답에 선택지별 표 수를 싣지 않는다. 「마감한 뒤」 투표는 표를 낸 사람에게도 마감 전에는 결과를 보이지 않는다.
- 「플레이 활동」 이 비공개면 남에게 성장 그래프의 날짜별 이력을 주지 않고 지금 값만 준다. 이 설정은 기본이 비공개라, 공개로 켜지 않은 사람의 그래프는 남에게 비어 보인다.
- 검토 대기 곡 후보는 전체 1,000개까지 만든다. 반영한 후보를 다시 봐도 검토 대기로 되돌리지 않는다.

## 고르지 않은 안

- 전체 상한을 500으로 — 전곡 579곡의 정보가 한꺼번에 바뀌면 후보가 잘린다
- 전체 상한을 더 크게 — 한 행이 최대 약 11KB 라 1,000개면 약 11MB 인데, 검토 화면이 100개씩 보여 주므로 더 쌓아도 쓸모가 없다
- 그래프를 통째로 막기 — 지금 값은 프로필 헤더에도 공개되는 값이라 막을 이유가 없다

## 근거

- 측정: 개발 DB 곡 579개. 상한에 닿아도 관리자 동기화는 후보 검토 없이 바로 반영되므로 새 곡 반영이 멈추지 않는다.
