# 채보 없는 곡 패턴 경향 카드 문구

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 디자인 · 화면(악곡 상세)
- 고른 사람: 사용자(사용자 지시)

## 맥락

[채보 없는 곡의 패턴 경향 가림](./2026-10-29-pattern-tendency-locked.md)의 카드 문구 「공개 채보가 없어 계산할 수 없어요」 가 길고 연결어미가 붙어 AI 글처럼 읽힌다.

## 결정

- 카드 한 줄은 「아직 계산되지 않았습니다」 로 한다(en 「Not calculated yet」 · ja 「まだ計算されていません」).
- 가림 모양 · 흐림 · 단추 없음은 그대로다.

## 고르지 않은 안

- 「채보 데이터가 부족해 제공되지 않습니다」 — 연결어미가 붙는다.
- 「채보 데이터가 없습니다」 · 「계산할 채보가 없습니다」 · 「공개된 채보가 없습니다」 — 사용자가 고르지 않았다.
