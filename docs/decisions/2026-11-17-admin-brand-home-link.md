# 관리자 사이드바 이름 줄을 누르면 메인 홈으로

- 상태: 유효
- 날짜: 2026-11-17
- 분야: 디자인 · 화면(관리자)
- 고른 사람: 사용자(사용자 지시)

## 맥락

관리자 사이드바 맨 위 「N · NosLog 관리자」 줄은 누를 수 없었다. 사용자가 사이트 헤더 로고처럼 누르면 메인 홈으로 가게 해 달라고 했다.

## 결정

1. 사이드바 이름 줄 전체(N 상자와 글자)는 메인 홈(`/`)으로 가는 링크다. 사이트 헤더 로고와 같이 같은 탭에서 열고, 접근성 이름은 줄의 글자다.
2. 모양은 바꾸지 않는다. 좁은 폭 메뉴 서랍에는 이름 줄이 없어 바꾸지 않는다.

## 근거

- 사용자 요청(2026-11-17): 「노스로그 관리자 있는거 저거 클릭하면 noslog 메인 홈으로 가지게 해줘 기존 헤더처럼」
