# 배포 전 보안 점검 수정의 정책 결정

- 상태: 유효
- 날짜: 2026-10-29
- 분야: 기능
- 고른 사람: 사용자(추천대로, 25개 모두)

## 맥락

정식 배포 전 보안 점검(치명 1 · 높음 3 · 중간 11 · 낮음 24)을 고치면서, 코드만으로 정해지지 않는 25개는 안을 나눠 골랐다. 남용 한도의 숫자, 비공개 설정이 맡는 범위, 파트너 연동의 폐기 규칙, 점검 중 쓰기처럼 동작이나 데이터가 보이는 방식이 바뀌는 것들이다. 파트너 알림 재시도 cron 은 Vercel 요금제가 Pro 라 5분마다로 정했다.

## 결정

- 공개판이 있는 이벤트는 투표를 새로 만들거나 지우거나 질문 · 선택지를 바꾸지 못하고, 마감만 바꾼다. 관리자 이벤트 검토 화면에 투표 질문 · 선택지를 보인다.
- 오락실 제보는 사람마다 24시간 30건, 일반 피드백은 10건이다. 공개 「신고 N건」 은 같은 기체에 한 사람 한 건으로 센다.
- 번역은 로그인하지 않은 요청에 저장된 번역만 준다. 로그인 사용자의 번역 생성은 시간당 20회, 답글은 24시간 50건이다.
- 일반 사용자 동기화는 한 번에 새 곡 후보 20개, 사람마다 24시간 100개까지 만든다. 후보에 제출자를 남긴다. 기록 스냅샷은 그대로 둔다.
- 스크립트는 요청마다 새 nonce 와 `'strict-dynamic'` 으로만 실행되게 강제하고, 나머지 CSP 지시는 Report-Only 로 지켜보며 위반 보고를 받는다.
- 방문 통계는 `Sec-Fetch-Site: same-origin` 인 요청만 센다. API 호출 수는 지금처럼 모두 세고 남용은 Vercel Firewall 로 막는다.
- 점검 중(`MAINTENANCE_MODE=true`)에는 앱의 DB 연결이 읽기 전용이다.
- 동의 action 은 화면에 보인 동의 요청(무작위 id)에만 code 를 낸다. 다르면 `/authorize` 로 다시 보낸다.
- 폐기된 refresh 토큰이 다시 오면 연결 전체를 폐기한다.
- 「플레이 점수」 · 「플레이 활동」 을 비공개로 바꾸면 nostalgia:read 가 있는 활성 연결마다 캐시 무효화를 보낸다.
- 운영(`VERCEL_ENV=production`)에서 `MUSECAT_MODE=mock` 이면 env 검증이 실패한다.
- 뮤즈캣 연결 시작은 다른 사이트에서 온 요청(Sec-Fetch-Site cross-site)이면 하지 않는다.
- 파트너 기록 응답의 출처 주소는 공유 항목이 있고 점수가 공개일 때만 프로필 주소, 아니면 사이트 주소다.
- 쓰지 않던 프로필 저장 액션과 그 스키마 · 테스트 · 메시지 키를 지운다.
- 「플레이 활동」 이 비공개면 남에게 기록 달성일을 숨기고 「최근 달성 순」 정렬을 뺀다.
- 오락실 「최근 확인」 에서 선호 오락실을 숨긴 사람은 「사용자」 로, 링크 없이 보인다.
- 공지 · 이벤트 본문 이미지와 이미지 최적화는 우리 Blob 저장소 · Discord 아바타 · X 이미지 경로만 받는다.
- 개인정보 정리 cron 이 24시간 지난, DB 어디에도 없는 avatars/ · events/ 업로드 파일을 지운다.
- 동기화 토큰은 일반 180일 · 관리자 30일 뒤 만료된다. 만료 전의 토큰은 2027-04-27 까지 받는다.
- 이벤트 · 공지 본문 이미지는 올리기 전에 브라우저에서 다시 인코딩한다(긴 변 2048, 위치 정보가 빠진다).
- 로그아웃 · 탈퇴하면 같은 브라우저의 다른 탭이 새로고침된다. 라우터 캐시 1시간은 그대로다.
- 프로필 공유 이미지는 CDN 에 10분만 둔다.
- 프리뷰 배포 우회 비밀값을 북마클릿에 싣지 않는다.
- Next 16.4 의 이미지 엔진이 webp 를 읽게 되어, 프로필 카드 테스트에서 「webp 그대로는 오류」 전제를 뺀다.
- 파트너 알림 재시도 cron(`/api/cron/partner-outbox`)은 5분마다 돈다.

## 고르지 않은 안

- 투표 작업본을 따로 두기 — 마이그레이션과 편집 흐름 변경이 크다
- 오락실 신고 수를 행 수 그대로 — 한도 안에서 부풀리기가 남는다
- 번역 실패 쿨다운 칸 — 손님 쪽 무한 호출은 한도만으로 막혀 마이그레이션을 더하지 않았다
- 곡 후보 상한만 두기 — 30초마다 20개씩 쌓일 수 있다
- CSP 를 Report-Only 로만 먼저 — 이번 배포에서 막는 층이 여전히 없다
- API 호출 수 표본 세기 — 관리자 대시보드 숫자가 추정치가 된다
- 점검 판정을 서버 액션 34곳에 하나씩 — 한 곳(연결 옵션)으로 원시 SQL 까지 막힌다
- refresh 재사용을 거절만 — 토큰을 가진 쪽을 끊지 못한다
- 동기화 토큰 만료 없음 · 관리자만 만료 — 새면 기한 없이 쓸 수 있다
- 라우터 캐시를 30초로 — 성능 점검에서 정한 1시간을 바꾸고, 공유 레이아웃 · 뒤로 가기 캐시는 그대로라 효과가 작다
- 뮤즈캣 연결 시작을 POST 로 — 링크 5곳이 버튼이 된다
