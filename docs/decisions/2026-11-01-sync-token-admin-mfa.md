# 동기화 토큰의 관리자 권한은 발급 때 2단계를 새기고, 값 검사에 걸린 채보의 기록은 남김

- 상태: 일부 대체됨(값 검사에 걸린 채보의 기록) → [2026-11-02 값이 빈 채보의 상한](./2026-11-02-sync-unknown-chart-limits.md)
- 날짜: 2026-11-01
- 분야: 기능
- 고른 사람: 사용자(보안 재확인 중간 항목 수정 지시)

## 맥락

2단계 값은 세션 쿠키에만 있어 동기화 토큰은 2단계 없이 관리자 권한을 썼다. 또 판정 합 검사에 걸려 빠진 채보가 「이번 응답에 없는 채보」 로 처리돼 기존 기록이 지워졌다.

## 결정

- 동기화 토큰에 `adminMfa` 를 넣는다. 북마클릿 화면이 2단계가 켜진 관리자 세션에서 발급할 때만 true 다. 곡 정보 즉시 반영 · 빠진 자켓 목록 · 자켓 저장은 역할이 admin 이고 이 값이 true 일 때만 된다.
- 이 값이 없는 관리자 토큰도 자기 기록은 올린다. 이미 나간 토큰은 2단계를 켠 뒤 북마클릿을 다시 받아야 관리자 권한을 쓴다.
- 값 검사에 걸린 채보는 지울 대상에서 빼고, 남긴 기록은 클리어 랭크 수에 그대로 센다.

## 고르지 않은 안

- `users` 표에 2단계 칸 추가 — 스키마가 바뀌고, 이 값도 마지막 Discord 인증 때의 값이라 더 새롭지 않다
- 2단계 없는 관리자의 토큰 재발급 막기 — 발급되는 토큰에 관리자 권한이 없어 일반 사용자와 다르게 막을 이유가 없다

## 한계

토큰의 값은 발급 때의 값이다. 뒤에 Discord 에서 2단계를 꺼도 토큰이 만료(30일)되거나 재발급될 때까지 남는다.
