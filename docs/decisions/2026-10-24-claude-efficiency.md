# Claude Code 효율 — 세션은 작게, 도구는 새로 깔지 않음

- 상태: 유효
- 날짜: 2026-10-24
- 분야: 구조
- 고른 사람: 사용자(시안 판 1–3 추천대로)

## 맥락

사용자가 Claude Code 를 더 효율적으로 쓰려고 사람들이 많이 쓰는 스킬 · 토큰 절약 도구를 찾아 달라고 했다. 별을 많이 받은 도구가 여럿 있었지만, 우리 세션의 토큰이 어디에 쓰이는지 먼저 재 보니 큰 몫은 도구가 줄여 주는 곳이 아니었다.

## 결정

1. 세션 운영: 작업 하나를 세션 하나에서 끝낸다. 작업이 바뀌면 새 세션이나 `/clear`, 넓은 조사 · 파일 훑기는 서브에이전트에 맡기고, 한 시간 넘게 쉰 긴 세션은 이어 가지 않고 요약을 넘겨 새 세션으로 연다. 모델은 세션 시작 때 정하고 중간에 바꾸지 않는다.
2. 토큰 절약 도구: 깔지 않는다. `/usage` · `/context` 로 무엇이 자리를 먹는지 보고, 사고량은 `/effort` 로 조절한다.
3. 스킬 · 플러그인: 이미 있는 `/code-review` · `/simplify` · `/noslog-check` 만 쓴다. 플러그인 · 전역 훅 · MCP 서버 · 토큰 절약 도구는 사용자 허락 없이 설치하지 않는다.

## 고르지 않은 안

- 긴 세션 + 미리 `/compact` — compact 자체가 대화 전체를 읽는 큰 요청이고 요약에서 결정 · 숫자가 빠질 수 있다.
- ponytail — 독립 측정에서 비용이 준 유일한 도구(−10.3%)지만 코딩 과제 측정이라 우리 문서 · 디자인 작업에는 확인 안 됨, 훅 스크립트 실행.
- caveman — 출력 −8.5% 측정. 우리 출력 몫 9% 에서 전체 약 0.8%, 규칙이 영어 기준.
- rtk · headroom · context-mode — rtk 는 비용 +7.6%(low effort) 측정, 프록시는 동시 세션 전부에 영향.
- Superpowers — 가장 많이 깔린 방법론 플러그인이지만 세션 시작 · clear · compact 마다 글을 넣고 `AGENTS.md` 작업 순서와 부딪힌다.
- Matt Pocock 스킬 일부(grill-me · handoff) — handoff 는 데스크톱 앱의 세션 넘기기와 겹치고, grill-me 는 「사실은 조사로 답한다」 와 부딪힌다.
- 올인원 묶음(Everything Claude Code · claude-mem · Ruflo) — 전역 훅 · 상태 파일을 동시 세션이 함께 쓰고, claude-mem 은 도구 입출력(비밀값 포함 가능)을 저장한다.

## 근거

- 측정(이 리포 세션 기록 39개 · 약 2만 7천 턴, 2026-10-24): 턴마다 다시 읽는 컨텍스트 중앙값 515k 토큰(p10 169k · p90 866k), 40만 넘는 턴 63%. 모델별 공식 단가로 가중한 비용 몫 캐시 읽기 63% · 캐시 쓰기 27% · 출력 9%. 10만 토큰 넘는 캐시 다시 쓰기 260번이 캐시 쓰기의 71%. 세션 첫 턴 중앙값 82k.
- 공식 문서: `/clear` 는 비용이 없고 `/compact` 는 큰 요청(costs). 캐시 읽기 0.05배(Opus 5.5), 모델 전환 · 컴팩트 · 한 시간 넘는 휴식은 캐시를 깸(prompt-caching). 스킬은 쓰기 전 이름 · 설명만 실림, 목록 예산 컨텍스트 1%(skills). MCP 도구는 기본으로 이름만 실림(mcp).
- 독립 측정: JetBrains(2026-07, Claude Code · Sonnet 5, 80여 짝 과제) ponytail 비용 −10.3% · caveman 출력 −8.5% · rtk 비용 +7.6%(p=0.004). Quesma rtk −5% ~ +5%.
- 대중성(2026-10-24 원문 확인): claude.com 설치 code-review 438,525 · code-simplifier 346,763 · Superpowers 1,009,371. skills.sh grill-me 1.4M. GitHub 별 Superpowers 304,162 · ponytail 174,654 · caveman 114,596 · rtk 84,382.
- 사람들이 쓴 글 56곳: 「작업이 바뀌면 /clear · 새 세션」 추천 16 · 반대 0, 「서브에이전트로 탐색」 15, 「/context 로 확인」 10. 가장 많이 추천된 도구(Playwright)도 9곳이라 설치 합의는 약함.
