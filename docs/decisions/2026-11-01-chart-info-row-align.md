# 채보 정보 줄 정렬

- 상태: 받아들임
- 날짜: 2026-11-01
- 분야: 디자인 · 화면(악곡 상세)
- 고른 사람: 사용자(시안 4안 중 안 2, 추천대로)

## 맥락

악곡 상세 「채보 정보」 는 값을 오른쪽 끝에 맞췄는데, 로그인하면 노트 수 · 길이 · 수록일 줄에 ⋯ 가, 빈 BPM 줄에 「추가」 가 값 바로 뒤에 붙었다.
그래서 값의 오른쪽 끝선이 줄마다 갈려(폰 기준 3가지) 어수선했다.

## 결정

- 라벨 열 폭은 가장 긴 라벨 하나에 맞춘다(줄마다 같은 폭, 새 값 없음).
- 값은 라벨 옆 같은 시작선에서 왼쪽 정렬로 시작한다.
- ⋯ · 「추가」 는 줄 오른쪽 끝에 맞춘다. 「검토 중」 · 「확인 전」 태그는 값 뒤에 둔다(이전과 같음).

## 고르지 않은 안

- 값 오른쪽 끝 고정 + 동작을 라벨 뒤로(네이버 증권 방식) — 그 서비스들의 라벨 뒤 동작은 설명 아이콘이고, 편집 동작을 라벨 뒤에 둔 곳은 없다.
- 값 왼쪽 두 열 + 동작을 값 뒤로(Radix · Amazon 방식) — 값 시작선은 맞지만 동작 끝선이 줄마다 갈린다.
- 라벨 위 · 값 아래(App Store 방식) — 목록 높이가 360 에서 548 로 늘어난다.

## 근거

- 실제 서비스 35곳(캡처로 확인): 값 왼쪽 두 열 19 · 라벨 위 값 아래 9 · 값 오른쪽 끝 3 · 「라벨: 값」 한 줄 2 · 오른쪽 고정 표지 2. 값을 오른쪽 끝에 두고 줄 동작을 값 뒤에 붙인 곳은 0곳.
- 줄 동작을 오른쪽 고정 열에 둔 곳: Wikidata(edit · add) · Google 지도(복사) · Flathub(링크 아이콘). 줄마다 편집 동작이 있는 구현은 이 모양을 쓴다.
- 디자인 시스템 6곳: GOV.UK Summary list 는 값 왼쪽 + Change 가 오른쪽 열(폰은 값 아래 링크로 쌓임). 나머지 5곳(Radix Themes · Chakra UI · Ant Design · PatternFly · Elastic EUI)은 값 왼쪽, 줄 동작 열은 없다.
- 한계: 로그아웃 화면만 봤다. 로그인해야 줄 동작이 뜨는 곳은 미확인이다.
- 측정(개발 서버, 360 · 390 · 1280): 모든 줄에서 값 시작선이 같고, ⋯ · 「추가」 의 오른쪽 끝이 같다.
