# 움직임 판 남은 칸과 반영 — 누름 축소 · 카드 그림 · 스켈레톤 물결 · 지도 · 서열표 끌기 · 헤더 고정

- 상태: 유효
- 날짜: 2026-11-19
- 분야: 디자인 · 기초값
- 고른 사람: 사용자(데스크톱 재설계 공통 층 3단계 움직임 판에서 칸마다 고름, 3-j 는 두 번 바꿔 처음 고른 즉시 옮김으로 돌아옴)

## 맥락

[1차 결정](./2026-11-19-motion-daangn.md)은 당근 SEED 시간 · 곡선을 뼈대로 정하고 2-a · 3-g · 3-j · 3-k · 4-b 와 헤더 숨기는 범위를 남겼다. 남은 칸을 모두 고른 뒤 1차 결정과 함께 코드 · 가이드에 한꺼번에 반영했다. 헤더는 숨기는 범위를 따로 재 본 뒤 숨기지 않기로 해 1차 결정 6번을 바꾼다.

## 결정

곡선 이름은 1차 결정과 같은 당근 SEED 값이다.

1. 떠 있는 메뉴(1-b): 1차 결정 4번 값 그대로 확정한다. 판 재생의 떨림을 고친 뒤 다시 보고 골랐다.
2. 누름 축소(2-a): 버튼을 누르는 동안 줄었다가 놓으면 돌아온다. 크기 .15s enter, 색은 .15s easing. 배율은 크기마다 고정이고(당근 xsmall .95 · small · medium .97 · large .98) NosLog 버튼에는 작은 버튼(32) .95, 기본 · 큰 버튼(40) .97 로 옮긴다. 동작 줄이기면 배율 1.
3. 올렸을 때 크기 바뀜(2-c): 당근 상품 카드처럼 카드 틀은 그대로 두고 안쪽 그림만 1 → 1.05, .3s ease. 토큰 밖 곡선 ease 를 새 토큰으로 둔다. 그림을 품은 누르는 카드 네 곳에 붙인다: 홈 이벤트 카드 · 이벤트 목록 카드 배너 · 오락실 결과 카드 사진 · 뮤즈캣 결과 썸네일. 마우스 올림이 있는 기기에서만 걸린다.
4. 스켈레톤(3-g): 당근 물결. `::after` 띠가 왼쪽 밖(−100%)에서 오른쪽 밖(100%)으로 1.5s easing 무한히 지나간다. 다크 띠는 `linear-gradient(90deg, #fff0 0%, #ffffff1a 46%, #ffffff1a 54%, #fff0 100%)`. 시작 지연은 확인하지 못해 두지 않는다. 지금의 불투명 깜빡임은 없앤다.
5. 지도 미끄러짐(3-j): 즉시 옮김(스타벅스 코리아 꼴, 실측 35곳 중 11곳으로 가장 많음). 카드를 누르면 카카오 `setCenter` 로 움직임 없이 핀으로 옮기고 확대 단계는 지금 규칙 그대로 둔다. 첫 화면 밖 매장도 즉시이고 동작 줄이기에서도 차이가 없다. 지금의 `panTo` 300ms 미끄러짐은 없앤다. 한때 고른 날아가듯 옮김(ROUND1 USA, Mapbox flyTo)은 카카오 지도가 정수 확대 단계만 지원해 낼 수 없어 사용자가 즉시 옮김으로 바꿨다.
6. 서열표 끌어 옮기기(3-k): 끄는 동안 다른 채보는 그대로 있고, 놓는 순간 한 프레임에 자리가 바뀐다. Esc 취소도 즉시다. 놓일 구간의 면 강조는 1-a 값(150ms easing)으로 바뀐다. Zap-Hosting 실측 곡선 (0.4, 0, 0.2, 1) 과 다른 것을 사용자가 골랐다. 키보드 끌기는 지금 그대로다. dnd-kit 기본 움직임(비켜남 200ms · 놓음 250ms ease)은 없앤다. 끌던 칸의 원래 자리 흐림 .4 는 투명도 값이라 4단계 부품에서 정한다.
7. 전체 악보 말풍선(4-b): 원 → 왼쪽 쓰기 줄. 원점 right center(원 높이에서 왼쪽으로만 펼침), 열림 150ms enter 불투명 0 → 1 · 크기 .95 → 1, 닫힘 100ms exit 불투명 → 0 · 크기 → .95.
8. 헤더(1-f 범위): 모든 폭 · 모든 쪽에서 헤더를 위에 고정하고 숨기지 않는다. 1055 이하에서 아래로 스크롤하면 숨던 동작(위 8px · 4px 문턱)을 없앤다. 1차 결정 6번의 숨김 움직임(숨음 300ms exit-expressive · 나타남 300ms enter-expressive)은 쓰이지 않는다.

반영하며 정한 것(새 값 없음):

- 시간은 SEED 단계 이름으로 둔다. 쓰는 단계만 토큰으로 둔다(d1 50 · d2 100 · d3 150 · d4 200 · d6 300). 스위치 바탕색 지연 20ms 는 따로 둔다.
- 1차 결정 9번대로 옛 곡선 (.4,1,.6,1) · (.6,0,.8,.6) 과 사라짐 150ms 는 위쪽 진행 막대 전용 토큰으로 남긴다.
- exit-expressive 는 헤더 숨김이 없어져 쓰는 곳이 없다. 쓰지 않는 토큰을 막는 테스트가 있어 지금은 토큰을 두지 않고, 쓰는 곳이 생기면 1차 결정의 값으로 더한다.
- 그래프 드러남(1차 결정 11번)의 swing 곡선(0.5 − cos(πt)/2)은 CSS 로 같은 꼴인 easeInOutSine `cubic-bezier(0.37, 0, 0.63, 1)` 로 둔다.
- 1차 결정 11번의 그래프 드러남은 선 그래프뿐 아니라 같은 공용 클래스를 쓰는 막대에도 그대로 걸린다.
- 스피너(1차 결정 10번)는 회전 1.2s 곡선만 반영했다. 호 길이 변화는 지금 스피너가 고정 호 마스크 그림이라 반영하지 않았다.
- 채보 뷰어 말풍선(1차 결정 15번 4-a · 이 결정 7번 4-b)은 지금 코드에 부품이 없다. 사용자가 고른 대로 값은 [기초값 — 움직임](../design/foundations.md#움직임)에 ③ 과 같은 값 · 원점 오른쪽 위(전체 악보는 오른쪽 가운데) 한 줄로 두고, 부품을 만들 때 그 줄을 쓴다.

반영 뒤 사용자가 고른 것(2026-11-20):

- 화살표만 돌던 펼침 줄 9곳(뮤즈캣 상세 · 뮤즈캣 게임 카드 · 커뮤니티 서열 투표 · 최근 플레이 · 업적 · 오락실 결과 카드 · 오락실 상세 · 프로필 2곳)도 내용을 구역 펼침(3-m2)과 같은 값(높이 · 불투명 300ms easing)으로 펼친다. 같은 동작은 같은 토큰을 쓰고 예외를 두지 않는다. 공용 판 클래스 `nl-disclosure-panel` 하나로 붙였다.
- 홈 검색 미리보기도 ③ 떠 있는 메뉴 움직임(열림 150ms enter 불투명 0 → 1 · 크기 .95 → 1, 원점 위 가운데, 닫힘 100ms exit)을 쓴다. 당근 검색어 메뉴와 같은 값이다.
- 막대 그래프 드러남은 반영한 그대로(막대도 선과 같이 1000ms swing) 둔다.
- 관리자 헤더 숨김은 채보 에디터 옛 셸에서만 쓰여 「채보 에디터는 지금 모양 그대로」 규칙대로 남긴다.
- 밝은 테마 스켈레톤 띠는 당근 SEED 밝은 값 흰 67%(`#ffffffab`)를 쓴다. 다크는 흰 10% 그대로다. 사용자 말은 「그래 나로 확정하자」, 판은 https://claude.ai/artifact/8TD5fo5v38EQS9C2r3aN6C , 출처는 당근 전역 CSS 7744행(밝은 값) · 7976행(다크 값)이다.

실제 재생을 재고 결정대로 맞춘 것(2026-11-20, 새 값 없음):

- 펼침 판 `nl-disclosure-panel` 이 세로 flex 줄 안에서 최소 높이(내용 높이)에 막혀 높이가 펼쳐지지 않고 불투명만 바뀌던 것을 최소 높이 0 으로 풀어, 높이 · 불투명 300ms easing 으로 펼친다.
- 위쪽 진행 막대가 도착하면 기본 불투명 0 때문에 곧바로 사라지던 것을, 끝 단계에서 불투명 1 로 100% 막대를 보인 뒤 150ms (.6,0,.8,.6) 로 사라지게 맞춘다.

## 고르지 않은 안

- 누름 축소 없음(2-a 가 지금) — 실제 서비스 35곳 중 4곳만 줄지만 당근 한 벌에 맞추는 쪽을 골랐다
- 올렸을 때 크기 그대로(2-c 가 지금) · 당근 지도 핀 · Spotify 버튼 · 카카오웹툰 카드 — 당근 실제 화면 값을 골랐다
- 스켈레톤 지금 깜빡임 · 다른 물결 묶음(3-g) — 당근 한 벌에 맞췄다
- 지도 날아가듯 옮김(3-j 사, ROUND1 USA · Hostelworld 2곳) — 한 번 골랐지만 카카오 지도로 낼 수 없어 바꿨다
- 지도 지금 카카오 panTo 300ms · 핀만 강조 · 새 탭 상세(3-j) — 즉시 옮김을 골랐다
- 서열표 끄는 동안 비켜남(3-k, dnd-kit 기본) — 실측 24곳이 끄는 동안 비켜나지 않았다
- 헤더 1055 이하 숨김 유지 · 당근 300ms 숨김 · 같이 올라감 · 목록만 올라감(1-f 범위) — 늘 고정을 골랐다
