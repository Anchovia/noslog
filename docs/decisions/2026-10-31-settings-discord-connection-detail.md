# Discord 연결을 뮤즈캣과 같은 줄 · 상세로

- 상태: 유효
- 날짜: 2026-10-31
- 분야: 디자인 · 화면(설정)
- 고른 사람: 사용자(뮤즈캣 형식이 더 낫다고 지정)

## 맥락

설정 「연결」 에서 Discord 줄만 버튼 둘을 줄 안에 드러내고, 뮤즈캣은 꺾쇠 줄 → 상세였다. 같은 목록에 두 모양이 섞여 있었다.

## 결정

1. Discord 도 줄 전체를 누르면 상세(`&partner=discord`)로 간다.
2. 상세는 뮤즈캣 상세의 순서를 따른다. 「NosLog 가 Discord 에서 쓰는 것」 은 OAuth `identify` 로 받아 실제로 쓰는 계정 ID · 이름 · 프로필 이미지다. 모두 읽기만 하고 누를 수 없으니 오른쪽 값은 두지 않고, 목록 선과 겹치는 구분선도 두지 않는다.
3. 로그인 계정이라 「연결 끊기」 대신 기존 두 버튼을 그 자리에 둔다. 기능과 확인 창은 그대로다.
4. 인증 뒤에는 상세로 돌아와 결과 · 오류를 거기서 보인다.
