# 곡 순위 점수 칸을 최소 폭으로

- 상태: 받아들임
- 날짜: 2026-11-01
- 분야: 디자인 · 화면
- 고른 사람: 사용자(겹침 지적, 고치는 방식은 에이전트 판단)

## 맥락

폰(Android 크롬, 다크)에서 곡 상세 랭킹 탭의 `1,000,000` 이 오른쪽 FC 상자에 맞닿았다.
점수 칸 폭이 `7ch + 0.66em` 로 고정이라, 글꼴이 숫자와 쉼표를 더 넓게 그리면 글자가 칸 밖으로 넘쳐 FC 칸 앞 간격 8 을 먹었다.

## 결정

- 점수 칸 폭을 고정 폭에서 최소 폭(`min-width`, 값은 그대로 `7ch + 0.66em`)으로 바꾼다. 글자가 더 넓으면 칸이 늘어 점수와 FC 사이 8 이 남는다.
- 새 값 · 토큰은 만들지 않는다.

## 고르지 않은 안

- 칸 폭을 더 넓게 고정 — 글꼴마다 다른 폭을 추측해야 하고, 보통 글꼴에서는 등급 아이콘과 점수 사이가 벌어진다.

## 근거

- 데스크톱 크롬(헤드리스)에서 360 · 390 · 430 · 1280 모두 `1,000,000` 글자 폭 68.9 가 칸 69.7 안이라 간격 8 이었다. 사용자 폰 글꼴의 실제 폭은 재지 못했다(미확인).
