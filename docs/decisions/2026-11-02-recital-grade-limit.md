# Recital Grd 상한은 Basic 최대의 1.25배

- 상태: 일부 대체됨(값을 모르는 채보) → [2026-11-02 값이 빈 채보의 상한](./2026-11-02-sync-unknown-chart-limits.md)
- 날짜: 2026-11-02
- 분야: 기능
- 고른 사람: 사용자(보안 재확인 수정 지시, 값은 운영 실측으로 정함)

## 맥락

동기화에 `grade_recital: 100000000` 을 넣으면 그대로 저장돼 Recital 랭킹 1위가 됐다. Recital 최대 Grd 식은 확인되지 않았다.

## 결정

전체 동기화에서 Recital Grd 가 그 채보 Basic 최대 Grd 의 1.25배를 넘는 줄은 저장하지 않는다. 노트 수나 상수를 모르는 채보는 검사하지 않는다.

## 고르지 않은 안

- Basic 최대를 상한으로 — 운영 기록 902건이 이를 넘는다
- 실측 최고 1.181배를 그대로 상한으로 — 표본 밖 상위 기록이 걸러질 수 있다

## 근거

- 운영 DB `play_data` 11,751건(2026-11-02): Basic 최대 대비 최고 1.181배, 상위 1% 경계 1.069배, 1배 초과 902건

## 한계

식이 아니라 실측에 여유를 둔 값이다. 상한 안쪽의 위조는 막지 못한다. 새 채보나 상수 정정으로 1.25배를 넘는 정상 기록이 나오면 이 값을 다시 본다.
