# 공지 글 배너를 본문과 따로 둔 칸으로

- 상태: 유효
- 날짜: 2026-10-30
- 분야: 기능 · 화면(공지 상세 · 관리자 공지 작성)
- 고른 사람: 사용자(A안, 양식은 사용자 시안 B안)

## 맥락

업데이트 · 점검 공지 글 위에 같은 양식의 배너를 넣고, 공지 편집기에서 넣고 바꾸고 싶다는 요청이었다.

## 결정

- 번역 표에 언어별 배너 주소 칸을 둔다. 본문 마크다운에는 섞지 않는다.
- 그림은 편집기가 브라우저에서 언어별 PNG로 만들어 공지 이미지 저장소에 올린다.
- 글 제목 아래, 본문 위에만 보인다. 글마다 넣거나 뺀다. 대체 글은 글 제목이다.
- 폰에서 작은 글자가 약 9px로 줄어드는 것은 양식대로 둔다.

## 고르지 않은 안

- 본문 맨 앞 이미지: 스키마를 바꾸지 않지만 세 언어 본문에 이미지 줄이 섞이고 교체가 번거롭다.
- 글자를 저장해 화면에서 그리기: 폰 글자는 커지지만 비율이 달라져 양식에서 벗어난다.

## 근거

2026-10-30 headless 실측. 실제 서비스 시도 50곳 중 글까지 확인 30곳 · 목록만 5곳 · 미확인 15곳. 글을 확인한 30곳 중 20곳이 글 상단에 글별 배너를 쓴다.
CMS · 디자인 시스템 시도 8곳 중 공식 문서 확인 5곳(WordPress · Ghost · Sanity · Webflow · Medium)이 대표 이미지를 본문과 따로 지정한다.
점검 글을 확인한 3곳(FFXIV · 메이플스토리 · 로스트아크)은 배너가 없다. 근거 약함이고, 점검에도 넣는 것은 사용자 결정이다.
