# ⓘ 의 올림

- 상태: 유효
- 날짜: 2026-10-29
- 분야: 디자인 · 부품
- 고른 사람: 사용자(추천대로 — 판 5 안 A)

## 맥락

악곡 상세 「패턴 경향 기준」 ⓘ(`nl-info-trigger`)는 누르면 대화상자를 여는데, 올려도 아무것도 바뀌지 않았다.
help.md 는 ⓘ 의 크기 · 누르는 영역만 정했고 올림을 정하지 않았다.

## 결정

1. ⓘ 는 올림 · 누름 · 키 포커스 때 아이콘 둘레에 원 24 면 `surface/control-hover` 를 깔고 아이콘을 `content/strong` 으로 바꾼다.
2. 면은 자리를 차지하지 않는다. 보이는 아이콘 16 · 누르는 영역 컨트롤 높이는 그대로다.
3. 값은 기초값 「면 없는 누르는 것」 올림과 같아 새 토큰이 없다.

## 고르지 않은 안

- B 변화 없음(Azure 계산기 · Microsoft 365 비교 · Azure VM 가격) — 「누르면 창」 ⓘ 실제 서비스 4곳 중 3곳.

## 근거

- 옮긴 구현: Spectrum 2 ContextualHelp(올리면 원 면 + 아이콘 진하게, 툴팁 없음). Fluent 2 InfoLabel · Carbon Toggletip 도 아이콘 색 · 면이 바뀐다.
- 디자인 시스템 7곳: 누르면 여는 도움말은 실측한 5곳 모두 올림 변화가 있다(1곳 미확인).
- 실제 서비스 31곳: 대부분 올리면 툴팁을 띄우는 ⓘ 이고(툴팁만 17 · 툴팁 + 아이콘 색 · 면 7), 「누르면 창」 ⓘ 는 4곳뿐이라 근거 약함. 차단 6곳은 세지 않음.
