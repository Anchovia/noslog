# 보안 추가 점검 수정 — 비공개 날짜 · 검토 판 · 기여 점수

- 상태: 유효
- 날짜: 2026-11-01
- 분야: 기능
- 고른 사람: 사용자(추천대로)

## 맥락

추가 점검에서 중간 2건 · 낮음 9건이 나왔다. 대부분 코드만으로 정해지지만, 기존 점수와 좋아요가 달라지거나 값을 새로 정해야 하는 것은 아래처럼 정했다.

## 결정

- 「플레이 활동」 이 비공개면 남에게 업적 달성일을 주지 않고, 업적을 등급 · 키 순서로 넘긴다. 파트너 기록의 `updated_at` 은 가입 시각을 준다.
- 곡 정보 제안은 운영자가 본 판(`updatedAt`)이 그대로일 때만 반영한다.
- 기체 확인 점수는 등급 계산에서 29점까지만 센다. 확인 횟수는 그대로 쌓이고, 다른 기여 없이는 이름 옆 라벨(3등급, 30점)이 붙지 않는다.
- 의견 글을 바꾸면 그 의견의 좋아요를 지운다. 평가 값만 바꾸면 그대로 둔다.
- 공개본과 같은 채보 초안은 검토를 요청할 수 없다. 초안을 만든 뒤 공개본이 바뀌었어도 운영자가 승인할 수 있다.
- 번역 동의를 끄면 진행 중이던 번역을 저장하지 않고, 목록에도 저장된 번역을 싣지 않는다.
- 검토 대기 곡 후보는 한 사람당 200개까지 만든다. 전체 상한에 닿으면 서버 로그에 남긴다.

## 고르지 않은 안

- 기체 확인 점수를 등급에서 빼기 — 이미 쌓은 사람의 등급이 크게 떨어진다
- 의견을 바꿔도 좋아요를 두고 수정 표시만 하기 — 새 화면 표시가 필요하고 업적 집계는 그대로 부풀려진다
- 공개본이 바뀐 초안의 승인을 막기 — 초안을 새 공개본 기준으로 맞출 길이 없어 그 초안을 영영 공개할 수 없다
- 제안을 대기 중에 못 고치게 하기 — 작성자가 잘못 쓴 값을 고칠 수 없다
