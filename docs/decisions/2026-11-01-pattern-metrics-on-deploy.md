# 패턴 경향 값은 배포 때 자동으로 채움

- 상태: 유효
- 날짜: 2026-11-01
- 분야: 구조 · 기능
- 고른 사람: 사용자(추천대로)

## 맥락

계산식이나 변박 기록을 바꾸면 `npm run db:backfill:pattern-metrics` 를 운영 DB 로 직접 돌려야 했다. 안 돌리면 계산식 버전이 다른 값을 쓰지 않아 개요가 막대를 가린다.
v2.17.2 배포 뒤 이 단계를 사용자에게 넘겨서 드러났다.

## 결정

- `vercel-build` 가 마이그레이션 뒤, 빌드 전에 채우기 스크립트를 돌린다. 배포 뒤에 사람이 돌릴 명령은 없다.
- 형식이 맞지 않는 채보는 건너뛰고 빌드 로그에 남긴다. 그 채보 하나로 배포를 막지 않는다. DB 연결 실패는 마이그레이션 실패와 같이 배포를 막는다.

## 고르지 않은 안

- 화면이 읽을 때 낡은 채보만 계산해 저장 — 읽는 요청이 쓰기를 하게 되고, 100% 기준이 공개 채보 전체에 걸려 채보가 일부만 새 값일 때 기준이 틀어진다.
- 수동 실행 유지 — 변박 기록을 고칠 때마다 사람이 운영 DB 에 명령을 돌려야 한다.

## 근거

- 자동 배포는 `main` 만 하므로(`vercel.json`) 이 쓰기는 운영 배포에서만 일어난다. 마이그레이션도 같은 경로로 운영 DB 에 쓴다.
- 스크립트는 채보마다 같은 줄을 덮어써서 여러 번 돌아도 결과가 같다.
