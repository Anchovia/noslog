# AI 티 확인에서 그라데이션 금지를 없앰

- 상태: 유효
- 날짜: 2026-11-23
- 분야: 구조
- 고른 사람: 사용자(사용자 지시)

## 맥락

[AI 티 확인](../ai-check.md) 화면 1번은 그라데이션을 글로우 · 색 그림자 · 유리 효과와 함께 금지했고, `tests/ai-tells.test.ts` 가 허용 목록 밖 그라데이션을 막았다. 데스크톱 재설계 색 파운데이션 판에서 이 줄 때문에 실측된 그라데이션 꼴(DEEPLOL 진행 막대, osu! 상위 순위 글자 등)이 근거와 무관하게 안에서 빠졌다. 사용자는 「그라데이션 ai티 규칙은 그냥 없애 그거때문에 계속 이상한 판단하잖아 너」 라고 지시했다.

## 결정

1. AI 티 확인 화면 1번에서 그라데이션을 뺀다. 글로우 · 색 그림자 · 유리 효과 금지는 그대로 둔다.
2. `tests/ai-tells.test.ts` 의 그라데이션 검사와 그 허용 목록을 없앤다. 흐림 · 글자 그림자 · 그림자 필터 검사는 그대로 둔다.
3. 그라데이션 규칙의 예외로만 있던 「NosLog 에서 정한 예외」 의 스켈레톤 물결 띠 줄을 뺀다. 스켈레톤 물결 자체는 [기초값 — 움직임](../design/foundations.md#움직임)대로 그대로 쓴다.
4. 감사 스킬 화면 목록에서 그라데이션 자체를 문제로 삼는 줄(장식 그라데이션 워시 · 그라데이션 글자)을 빼고, 보라 그라데이션 줄은 보라 CTA 만 남긴다.

그라데이션을 쓸지는 다른 값과 같이 실측 근거와 판에서의 사용자 선택으로 정한다.

## 고르지 않은 안

- 허용 목록에 자리를 더해 가며 규칙 유지 — 판마다 실측 꼴이 규칙에 먼저 걸러지는 문제가 그대로 남는다.
