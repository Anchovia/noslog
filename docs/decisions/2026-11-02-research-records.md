# 조사 결과를 기록으로 남겨 다시 조사하지 않음

- 상태: 유효
- 날짜: 2026-11-02
- 분야: 구조
- 고른 사람: 사용자(사용자 지시)

## 맥락

화면 시안마다 수십 곳을 새로 실측한다. 조사 결과가 세션과 함께 사라지거나 파일이 있어도 찾기 어려우면 같은 조사를 되풀이해 사용량을 쓴다.

## 결정

- 조사 기록은 [조사 기록 목록](../research/README.md)에서 찾고, 있는 내용은 다시 조사하지 않는다.
- 새 조사는 조사마다 `docs/research` 에 파일을 만들어 곳을 조사할 때마다 바로 기록하고, 목록에 한 줄을 더한다.
- 같은 주제의 기록이 있으면 새 파일을 만들지 않고 그 파일에 합친다.
- 캡처는 커밋하지 않고 `~/noslog-research/<조사 이름>/` 에 저장한다.

## 고르지 않은 안

- 캡처도 리포에 커밋하기: 조사 한 번에 수백 장이라 리포가 커진다
