# 초안 수 · 저장 · 마디 한도

- 상태: 유효
- 날짜: 2026-11-02
- 분야: 기능
- 고른 사람: 사용자([시안](https://claude.ai/artifact/7k7tD6ehAd1hAqUAN7ZAC6) 1A · 2A)

## 맥락

재점검에서 초안 저장 대기가 초안마다 걸려 한 계정이 300개 초안에 동시에 저장해 300.9MB 를 채웠다. 360바이트 초안의 타이밍 값으로 마디 표시 1,152만 개가 생겨 공개 뷰어가 첫 응답까지 8.4초 걸리고 JS 힙이 3,340MB 까지 찼다.

## 결정

- 공개 전 초안은 사람당 50개까지 연다. 한도에 닿으면 새 초안을 만들지 않고 「초안은 50개까지 열 수 있습니다.」 를 보인다. 이미 있는 초안은 그대로 열린다.
- 초안마다 초당 1회 대기는 두고, 사람당 5분 300회를 더한다. 이벤트 저장과 같은 표로 세므로 저장마다 행이 하나 늘고, 지난 기록은 정리된다.
- 유저 초안의 마디 수 합은 5,000 이하다. 저장 · 검토 요청 · 초안 읽기 · 공개가 지나는 같은 검사에 넣는다. 운영자 저장에는 넣지 않는다.

## 근거

개발 DB 실측(2026-11-02)이다. 외부 서비스 값은 조사하지 않아 근거가 약하다.

| 값                | 실측 최대 | 한도  |
| ----------------- | --------- | ----- |
| 사람당 초안       | 3         | 50    |
| 공개 채보 마디 수 | 188       | 5,000 |
| 리비전 마디 수    | 258       | 5,000 |

## 고르지 않은 안

- 초안 100개: 계정당 공간이 두 배다
- 초안 수만 제한: 50개를 계속 덮어쓰는 쓰기 부하가 남는다
- 마디 2,000개: 빠른 곡 · 짧은 박자의 긴 채보가 막힐 수 있다
- 틱과 시각 일치 검사: 에디터에서 시각만 옮긴 정상 편집을 막을 수 있다

## 한계

초안을 지우는 기능이 없어 50개가 차면 공개되기 전까지 새 곡을 열 수 없다. 틱과 시각이 어긋난 초안은 마디 5,000 안에서 저장된다.
