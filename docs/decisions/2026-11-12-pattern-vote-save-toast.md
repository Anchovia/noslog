# 체감 패턴 · 서열 투표 저장 상태는 토스트로 알린다

- 상태: 유효
- 날짜: 2026-11-12
- 분야: 디자인 · 패턴
- 고른 사람: 사용자(두 안 밖, 사용자 지시)

## 맥락

데스크톱 악곡 Figma 결정본의 상태 칸 「패턴 평가 저장 실패」 · 「서열 투표 실패」 · 「평가 저장됨」 을 그리려 했다. 정한 「체감 패턴」 상자에는 지금 코드의 기준 줄(저장 상태 자리)이 없고, 서열 투표는 저장 버튼 없는 슬라이더로 바뀌었다. 판 12 에서 가이드 「저장 방식」 그대로(목록 아래 한 곳)와 지금 코드처럼 제목 줄 오른쪽 짧은 글을 견줬다.

## 결정

1. 체감 패턴 평가 · 서열 투표는 누르는 즉시 저장하고, 저장됨 「저장했습니다.」 · 실패 「저장하지 못했습니다」 를 아래 가운데 알림 토스트로 알린다.
2. 실패하면 그 값만 되돌린다(그대로).
3. 설정 · 한 개 고르는 투표의 저장 상태 자리는 그대로다.

사용자 원문: 판 12 를 붙여 「이거는 toest 쓰자」.

## 고르지 않은 안

- 안 1 가이드 「저장 방식」 그대로, 목록 아래 한 곳: 사용자가 토스트를 고름.
- 안 2 제목 줄 오른쪽 「저장됨」(2초) · 위험 글자 + 다시 시도: 사용자가 토스트를 고름.
