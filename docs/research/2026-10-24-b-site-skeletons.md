# 조사 B — 실제 서비스 골조(뼈대) UI 실측

조사일 2026-10-24. 로그인 없이 공개 화면만 봤다.

## 방법

- headless Playwright(Chromium 1.61, 막힌 곳은 Firefox · WebKit으로 한 번 더 시도). 폭은 데스크톱 1280×800, 폰 390×844(iPhone UA · 터치), 최대 폭을 보려고 1920×1080을 한 번 더 쟀다. `prefers-color-scheme: dark` 로 열었다(다크를 따르는 사이트는 다크로 보인다).
- 페이지마다 DOM 계측(아래 「측정 정의」) + 첫 화면 스크린샷 → 판 모음 이미지로 눈으로 확인했다. 숫자는 자동 계측값이고, 「화면 확인」 이라고 적은 것은 스크린샷으로 판단한 것이다.
- 대상: 서비스 66곳, 페이지 81개(같은 서비스의 목록 · 프로필 · 상세를 따로 잼). 66곳 중 **두 폭 모두 실측 56곳**, 일부만 실측 4곳(Letterboxd 보안 겹창 · Strava 로그인 벽 · Garmin 소개 화면만 · niconico 폰은 지역 차단), **봇 차단 · 로그인 전용이라 못 잰 곳 6곳**(SteamDB · FACEIT · Liquipedia · RateYourMusic · OngekiScoreLog · Kamaitachi). 봇 확인(CAPTCHA)은 풀지 않았다.

### 근거가 약한 부분

- 카드 · 강조색 · 여백은 휴리스틱 계측이다(측정 정의 표 참고). 광고 상자, 동의 겹창(HLTB · MAL · Strava · 여러 곳)이 값에 섞였다.
- 서비스마다 1~3쪽만 봤고, 로그인 뒤 화면(내 기록 · 설정 등)은 보지 않았다.
- `prefers-color-scheme: dark` 로 열어서 라이트 · 다크 비율은 의미 없음.
- 「잘 만들었다는 평가」 는 이번 조사에서 따로 검증하지 않았다(과제에 적힌 목록을 그대로 씀).
- 상단 바 높이가 「미확인」 인 곳은 계측 조건(맨 위 고정 · 폭 90%)에 안 걸린 곳이다. 화면으로만 대략 본 값은 「≈」 로 적었다.
