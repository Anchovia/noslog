# AWS 에서 DB 까지 월 $1 안팎 구성 검토 (2026-11-18)

NosLog 를 AWS 서울(ap-northeast-2)에서 DB 까지 포함해 월 $1 안팎으로 돌릴 수 있는지 본 기록이다. 앱 호스팅(Lambda + OpenNext) 자체는 [AWS Lambda + OpenNext 호스팅 검토](./2026-11-17-hosting-lambda-opennext.md)에 있어 다시 조사하지 않았다. 이번에 본 것은 두 가지다. 하나는 AWS 안에서 무료나 거의 무료로 쓸 수 있는 DB, 다른 하나는 지난 조사가 OpenNext 를 고르지 않은 세 이유(캐시 무효화 · 콜드 스타트 · #1358)를 직접 구축으로 메우는 비용이다. 재설계 시간과 비용은 따지지 않았다.

## 방법

- 웹 조사는 다섯 갈래(Aurora DSQL · Aurora Serverless v2 와 RDS · AWS 안 SQLite 와 DynamoDB · OpenNext 약점 메우기 · AWS 밖 SQLite 와 MySQL 관리형)를 서브에이전트가 나눠 곳마다 바로 적었다. 다섯째 갈래는 조사 중에 맡긴 세션이 범위를 넓혀 더했다(엔진을 SQLite · MySQL 로 바꾸는 안과 AWS 밖 무료 관리형). 결론에 쓴 숫자는 아래 「직접 확인」 에서 다시 열어 봤다.
- 셈한 출처는 323곳이다(DSQL 60 · Aurora 와 RDS 51 · AWS 안 SQLite 와 DynamoDB 55 · OpenNext 약점 76 · AWS 밖 엔진 81). 열리지 않은 곳(23)과 검색 요약만 본 곳(29)은 세지 않았고 아래 출처에 「막힘」 「미확인」 으로 남겼다. 지난 조사에 이미 있던 출처 13곳도 세지 않았다.
- 코드 쪽은 리포를 grep 으로 셌다(아래 「코드에서 걸리는 곳」).
- 사용량은 지난 조사와 같은 운영 실측이다. 금액은 서울 단가 · USD/월 · 세금 별도 · 한 달 730시간이고, 상시 무료는 Paid 플랜 계정 기준이다.
- 한계: 요청당 DSQL DPU · Turso 읽은 행 수 · 쓰기 동작 수는 실측하지 못해 범위로 적었다. 실제 청구 사례는 Next.js + OpenNext 작은 사이트에서 찾지 못했다.
- 사용량 원문: 함수 호출 월 150,805(평균 초당 0.06) · Active CPU 월 3.5시간 · 평균 메모리 325 MB · 전송 월 4 GB · 운영 덤프 35 MB.

## 후보별 정리

### AWS 안 Postgres 계열

- Aurora DSQL: 서울 지원(2025-07-03). 상시 무료 월 10만 DPU + 1 GB, 기간 제한 없음(Free · Paid 플랜 모두). VPC · NAT 없이 퍼블릭 엔드포인트에 IAM 토큰으로 붙는다. Prisma 7.10 + `@prisma/adapter-pg` 에 `AuroraDSQLPool` 을 넘기는 AWS 예제가 있고, 마이그레이션은 `@aws/aurora-dsql-prisma-tools` 로 바꾼 뒤 `PRISMA_SCHEMA_DISABLE_ADVISORY_LOCK=1 prisma migrate deploy`. 되는 것: jsonb(2026-06) · ON CONFLICT · 외래 키(2026-08) · IDENTITY · 시퀀스(2026-02) · 부분 인덱스(2026-09) · 윈도 함수(간접). 안 되는 것: enum(CREATE TYPE) · 어드바이저리 락 · SKIP LOCKED(목록에 없음) · 배열 칼럼 · PL/pgSQL. FOR UPDATE 는 잠그지 않고 커밋 때 충돌로 실패. 트랜잭션 3,000행 · 10 MiB · 5분, DDL 은 트랜잭션에 하나. 40001 재시도 필수. 공식 산식 예시는 점 조회 0.00675 DPU · 한 줄 INSERT 0.062 DPU. 이 앱의 읽기를 요청당 0.05–0.5 DPU 로 잡으면 월 7,500–75,000 DPU, 쓰기는 1 GB 마다 약 52,000 DPU(실측 안 함).
- Aurora Serverless v2 0 ACU: 서울 PG 17.4+ 지원. 켜져 있으면 0.5 ACU 바닥 월 $73. 재개 약 15초(후기 10–13초). 자동 정지까지 최소 300초 유휴인데 요청 간격 평균 17초 · 5분 크론이라 사실상 정지하지 못한다. Lambda 를 VPC 에 넣어야 해 NAT 월 $43.07 또는 인터페이스 엔드포인트 AZ 당 $9.49. RDS Proxy 는 최소 8 ACU 과금 월 $146. Data API 는 100만 건 $0.42, Prisma 어댑터는 커뮤니티 것뿐.
- RDS PostgreSQL db.t4g.micro: 월 $18.25 + gp3 20 GB = $20.87, 퍼블릭 IPv4 $3.65. 예약 1년 선결제 없음 $17.07 · 3년 전체 선결제 $11.70. t4g.nano 는 RDS 에 없다. 옛 12개월 무료는 2025-07-15 전 계정만, 새 Free 플랜은 6개월 뒤 계정이 닫힌다.
- EC2 t4g.nano 에 직접 설치: $3.80 + EBS $0.73 + IPv4 $3.65 = 월 $8.18. Lightsail 관리형 DB 서울 $15.

### AWS 안 SQLite · DynamoDB

- Lambda + EFS 위 SQLite: EFS 서울 Standard $0.33/GB-월이라 저장은 약 $0.01. 하지만 EFS 는 Lambda 를 VPC 에 넣어야 하고, 외부 API(뮤즈캣 · Gemini)로 나가려면 NAT 게이트웨이 월 약 $43(+$0.059/GB) 또는 NAT 인스턴스 t4g.nano 월 약 $7.4 가 든다. IPv6 egress-only 게이트웨이는 무료지만 외부 API 의 IPv6 지원은 미확인. 네트워크 파일시스템에서는 WAL 을 쓸 수 없고, Lambda 동시 10 으로 INSERT 50건 중 39건이 「database is locked」 로 실패한 실험이 있다.
- S3 기반(Litestream v0.5.18 · LiteFS · /tmp 내려받기): 모두 쓰기자가 하나라는 전제라 여러 Lambda 가 동시에 쓰는 이 앱에는 맞지 않는다.
- DynamoDB: 프로비전 25 RCU · 25 WCU · 25 GB 상시 무료(온디맨드 요청엔 무료 없음), VPC 불필요. Prisma 미지원(이슈 #1676, 2020년부터 열림). 77모델 · 외래 키 144 · 조인 · 랭킹 · ILIKE 검색을 다시 짜야 하고 트랜잭션은 100항목 상한. DynamoDB 에서 Postgres 로 되돌아간 후기 2건.
- PGlite · DuckDB: 연결 하나 또는 쓰기 프로세스 하나라 맞지 않는다.

### AWS 밖 관리형

- Supabase 무료: Postgres 그대로(`@prisma/adapter-pg`), 서울 · 도쿄 리전 있음(무료에서 서울을 고를 수 있는지는 미확인). DB 500 MB · egress 5 GB(DB 에서 앱으로 가는 전송이 드는지 미확인) · 공유 CPU 500 MB RAM · 1주 활동이 모자라면 정지(앱 요청도 활동으로 친다) · 자동 백업 없음.
- Turso(libSQL): 무료 5 GB · 월 읽기 5억 행 · 쓰기 1천만 행, 넘으면 막힘. 서울 없음, 도쿄(AWS ap-northeast-1) 있음. 서울↔도쿄 왕복 약 36 ms(검색 요약, 미확인)라 순차 쿼리마다 늦어진다. 읽기는 스캔한 행으로 세므로 호출당 평균 약 3,300행을 넘으면 한도를 넘는다(실측 안 함). `@prisma/adapter-libsql`, 마이그레이션은 `prisma migrate diff` 뒤 Turso CLI. 2026-10-02 Supabase 가 인수를 발표했고 요금 언급은 없다.
- Cloudflare D1: Lambda 에서는 REST 로만 부를 수 있고 계정 전체 5분에 1,200요청 한도. 앱을 Workers 로 옮기면 무료 CPU 10 ms/요청인데 지금 평균 약 84 ms 라 유료 $5 가 필요하다. Prisma D1 어댑터는 Preview 이고 트랜잭션을 무시한다(56곳이 원자성을 잃는다). sharp · `readFile(public/...)` 도 고쳐야 한다.
- TiDB Cloud Starter(MySQL 호환): 인스턴스마다 5 GiB · 월 5천만 RU, 도쿄 있음. SKIP LOCKED 미지원. Prisma 어댑터 표가 6.17 까지라 v7 은 미확인. Postgres 호환 TiDB 는 2026-10-15 미리보기 · us-east-1 만.
- PlanetScale MySQL: 무료 Hobby 는 2024-04-08 에 끝났고 최저가 $39(맡긴 세션의 기억이 맞다).
- 맞지 않는 곳: Aiven 무료(리전 못 고름) · Prisma Postgres 무료(월 20만 operations) · CockroachDB(새 조직 무료 없음) · Neon · Xata(서울 · 도쿄 없음 또는 무료 없음).

### 엔진을 바꿀 때 코드 범위

- 공통(SQLite · MySQL): `String[]` 6곳 → JSON 칼럼이나 별도 표 · `mode: "insensitive"` 5파일 10곳 · jsonb 연산 6파일 14곳 → JSON 함수 · ILIKE 3파일 12곳 → LIKE(대소문자는 콜레이션) · 어드바이저리 락 5파일 · `Timestamptz` 6 · 마이그레이션 96개를 새 기준선으로. enum 은 Prisma 가 SQLite · MySQL 모두에서 받는다(에이전트 확인, Prisma 스키마 문서).
- SQLite 추가: FOR UPDATE · SKIP LOCKED 대체(쓰기가 한 번에 하나라 잠금 대신 `BEGIN IMMEDIATE`), `skipDuplicates` 9곳 미지원(에이전트 집계), Prisma 8 문서는 SQLite 를 experimental 로 표시.
- MySQL 추가: ON CONFLICT → ON DUPLICATE KEY UPDATE · RETURNING 없음 · 부분 유니크 인덱스 없음(생성 칼럼으로 대체) · GET_LOCK 은 커밋해도 풀리지 않음.
- 맡긴 세션의 짐작 확인: `String[]` 6곳은 맞다(arcades 3 · musecat 2 · partner 1). EFS 는 VPC 가 필요하고 외부 API 로 나가는 길에 NAT 가 붙는다는 것도 맞다. D1 을 쓰면 앱도 Workers 로 옮겨야 한다는 것은 공식 길로는 맞다(REST 는 한도가 작다).

## 앱 쪽 약점 메우기 (Lambda + OpenNext)

- 캐시 무효화: S3 증분 캐시 + DynamoDB 태그 캐시 `dynamodb-nextMode` + `cdnInvalidation` 기본값 dummy. 캐시 읽기 1번 = S3 GET 1 + BatchGetItem 1(태그당 0.5 RRU), 무효화 1번 = 태그당 2 WRU(SST 태그 표의 GSI). SQS 는 페이지 단위 ISR 일 때만이고 이 앱은 `app/sitemap.ts` 하나. 이 앱 크기로 S3 $0.28–1.22 + DynamoDB $0.10–0.74 = 월 약 $0.4–2.0. original 모드는 넓은 태그를 비울 때 항목 수만큼 써서 월 수십 달러가 될 수 있고, CloudFront 무효화를 켜면 경로당 $0.005. 쓰기 실패가 로그만 남기는 조용한 실패라 CloudWatch 지표 필터 · 알람이 따로 필요하다(10개까지 무료).
- 콜드 스타트: warmer 1개(5분) = 월 8,640회, 무료 안(빼도 약 $0.02). 동시 요청 · 배포 직후 · 처음 부르는 경로는 여전히 콜드. Provisioned Concurrency 1개(1 GB) 월 x86 $13.47 · arm64 $10.78. SnapStart 는 zip Node.js 미지원, 컨테이너로 1 GB 약 $5.7/월. 콜드 시간은 묶음 크기가 좌우하고 메모리 차이는 약 15 ms.
- #1358: 열림 · 관리자 답 없음. 4.1.15 부터는 Function URL 이 아니어도 실패한다(작성자 댓글)라 API Gateway HTTP API(월 $0.18)를 앞에 둬도 안 된다. 0원 우회는 `@opennextjs/aws` 4.1.14 고정 + `encodeURI` 패치(4.1.14 peer 가 next >=16.4.1). 리포의 동적 경로 액션 6파일이 실제로 「전달」 되는지는 미확인.
- Lambda Web Functions: 서울 없음(가격표에 SKU 만 있음). 환경 메모리 2 GB 가 쉬는 시간에도 과금돼 하루 종일 두면 메모리만 월 약 $24. 인스턴스끼리 캐시를 공유해 주지 않는다.
- 무료 밖 줄: Route 53 영역 $0.50(DNS 를 Route 53 에 둘 때) · S3 정적 자산 몇 센트 · CloudWatch 로그 보관 몇 센트 · 비밀값은 SSM Parameter Store 표준 $0(Secrets Manager 면 비밀 하나 $0.40) · X-Ray 끄면 $0 · 고객 관리 KMS 키를 만들면 $1. 기본 구성 합계 월 약 $1.0–2.6.
- 실제 청구: Next.js + OpenNext 작은 사이트의 청구는 찾지 못했다. Next.js 가 아닌 Lambda + DynamoDB SaaS 첫 달 $0.74(88% 가 DNS 영역 · KMS 키).
