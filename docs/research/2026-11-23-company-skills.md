# 기업이 AI 코딩 에이전트용 스킬 · 플러그인 · 규칙 파일을 직접 만들어 쓰는 방식

조사일 2026-11-23. 내려받은 페이지는 세션 임시 폴더에만 두었고 실행하지 않았다. [AI 티를 막는 스킬 · 규칙 파일 조사](./2026-10-24-f-claude-skills.md)(F)와 [Claude Code 효율 조사](./2026-10-24-g-claude-efficiency.md)(G)에 이미 있는 공식 문서 사실(스킬 500줄 · description 1,024자 · 훅 exit 2 · 점진 공개 등)은 다시 조사하지 않고 「F #번호」 로만 가리킨다. 이 조사는 거기에 없는 것, 곧 회사가 자기 스킬을 어떻게 만들고 나누고 배포하고 재는지를 본다.

이 리포의 지금 스킬(`.claude/skills/`, 훑기만 함): `e2e-local` · `noslog-check` · `release`. 절차 스킬 둘과 검사 목록 스킬 하나다.

## 읽는 법

- 「회사」 = 자기 조직의 엔지니어링 글 · 공개 리포로 자기 운영을 밝힌 곳. 「공식」 = 도구 제작사(Anthropic · GitHub · Cursor)의 문서나 열린 규격(agentskills.io). 커뮤니티 개인 프로젝트는 따로 센다.
- 「열람」: 본문 = 원문을 직접 읽음 / 2차 = 검색 요약만 봄(원문 미확인).
- 근거가 3곳 안팎이면 「근거 약함」. 확인 못 한 것은 「미확인」.
- 안 후보는 곳 하나의 방식을 옮긴 것이다. 조합하지 않았다.
