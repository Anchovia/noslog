# V1 면 · 회색 · 상호작용 값 후보 재료 (2026-11-25)

색 값 단계 판 V1(면 · 회색 · 상호작용) 재료다. 캡처 · 원자료 · 스크립트는 공유 메모 폴더 `common-layer/stage3/color/` 아래 `values/v1-surface/` 에 있고, 아래 `values/v1-surface/caps/…` 경로는 그 폴더 안이다. 자리마다 실제 서비스와 디자인 시스템이 쓰는 값 꼴을 실측 그대로 적는다. 추천 · 판 그리기 · 결정은 하지 않는다. 당근 SEED 3.2.1 다크가 베이스이고, 「SEED 로 옮길 때」 는 가장 가까운 SEED 토큰을 적은 것이며 서비스 값은 바꾸지 않았다(값 단계 master 답 0: SEED 팔레트로 옮긴 값과 실측 값 그대로를 모두 적는다). 대비는 WCAG 2 비, 이 문서가 대는 바탕은 #000(쪽) · #16171b(구역 면) · #2b2e35(면 위의 면)다.

## 취합 대조 (2026-11-25, 취합 세션)

캡처를 열고 원자료 JSON 과 맞춰 본 결과다. 아래 고침은 이 문서의 해당 표에 이미 반영했다.

- 고침 2, G10 무신사는 밝게 열린 쪽 위에 뜬 어두운 이벤트 창 안의 스켈레톤이다(캡처 p2-musinsa). 팝업 캡처라 셈에서 뺐다. 스켈레톤은 7곳(국내 4).

## 방법과 표본

- 새 실측은 세 묶음이다. headless Playwright · `permissions: []` · colorScheme dark · ko-KR · 1440×900 · 쪽 열기 전 `~/noslog-research/wait-capacity.sh` · 브라우저 하나에 쪽 하나 · 로그인 · 쓰기 · 제출 없음. 값은 `getComputedStyle` 계산값이고 알파는 부모 면 위에 합성했다.
    - 1차(검색칸 면 · 올림 · 눌림 · 점선 · 진행 막대 트랙): 71곳 시도, 다크로 열려 읽은 곳 54곳(국내 22). 곳마다 첫 화면 한 쪽이다. 눌림은 `mousedown` 을 500ms 누른 채 읽고 버튼 밖에서 놓아 눌림이 실행되지 않게 했다.
    - 2차(스켈레톤): 같은 71곳을 열되 `fetch` · `xhr` 요청을 끝내지 않고 붙들어 로딩 상태를 만들고, 12초 안에 스켈레톤 · 시머 요소가 잡히면 읽었다. 잡힌 곳은 캡처를 열어 로딩 막대가 실제로 보이는 8곳만 센다.
    - 3차(차트 · 업로드 칸): 막대 묶음 · 격자 · 기준선 · 점선 테두리가 있을 법한 20쪽을 열었다. 막힌 곳(Cloudflare · 403 · 404)은 세지 않는다.
- 재지 않고 기존 조사에서 가져온 것은 줄 위치를 적었다: [기타 색 역할](./2026-11-24-color-misc-roles.md)(올림 · 입력 면 · 비활성 · 로고) · [누름 움직임](./2026-11-19-motion-press.md) · [색 규칙 근거](./2026-11-24-color-rules19.md)(줄무늬 · 점선 · 비활성) · [진행 막대 · 슬라이더](./2026-11-21-color-feature-ui.md) · [상태색](./2026-11-20-color-status.md)(위험 버튼) · [선](./2026-11-20-color-line.md) · [차트 색](./2026-11-20-color-chart.md)(격자 · 빈 칸 · 남은 몫).
- 디자인 시스템 값은 소스 파일을 읽었다: SEED `daangn-tokens.md` · Primer `primer-dark.css` · Atlassian `atlaskit-dark.js` · Carbon g100 `@carbon/themes` · Polaris `polaris-tokens` · MUI 6.4.0 `Skeleton.js` · `createPalette.js` · Bootstrap 5.3 변수. 문서 사이트 화면을 열어 읽은 곳은 아래에 따로 적었다.
- 곳마다 한 쪽만 열었으므로 「안 잡힘」 은 「없음」 이 아니다. 캡처는 `values/v1-surface/caps/` 에 있다(`p1-<곳>.jpg` · `p2-<곳>.jpg` · `p3-<곳>.jpg` · `f02-daangn-*.png`), 원자료 JSON 은 `raw/`.
