# 1단 탭 칸 폭 — 줄 폭 균등 대 글자 폭 (2026-11-28)

물음: 쪽 구역을 나누는 1단 밑줄 탭의 칸 폭을 줄 폭 균등으로 할지 글자 폭으로 할지. 공통 층 4단계 판 g2 의 재료다. 추천은 판에 있고 이 기록에는 쓰지 않는다.

이미 있는 기록을 합쳤다. 같은 서비스를 다시 재지 않았고, 오늘 새로 잰 곳만 아래에 따로 적었다.

- 프로필 머리 탭 위치 20곳([프로필 조사 2026-11-02 「머리와 탭」](./2026-11-02-desktop-profile.md)): 왼쪽 붙임 14 · 오른쪽 붙임 2(Quaver · MLB.com) · 가운데 2(TMDB · Velog) · 전폭 균등 2(Bluesky · Substack). Velog 는 공지 목록 34곳에도 들어 있어 한 번만 센다.

## 합계

- 실제 서비스 59곳(공지 · 소식 34 + 프로필 20 − 겹침 1 + 오늘 6): 글자 폭이나 고정 폭 칸으로 줄을 채우지 않는 곳 50, 줄 폭 균등 9(상자 모양 7 · 밑줄 2: Bluesky · Substack).
- 밑줄 탭만 따로 보면 균등 2곳(Bluesky · Substack, 프로필) 대 글자 폭이나 고정 폭 밑줄(메이플스토리 · 던전앤파이터 · 명조 · 하스스톤 · velog · GitHub · YouTube · Chess.com 등) 다수다. 밑줄 균등 2곳은 근거 약함.
- 오락실 상세 탭 같은 좁은 패널(폭 389)의 균등 3칸은 Figma 결정본(오락실 상세 탭 3칸)에서 읽은 값이다. 서비스 쪽 같은 용법은 오늘 잡은 Quaver 패널 탭 1곳이다(근거 약함).
