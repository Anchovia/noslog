# 점수 자 「다른 사람 핀」 테두리 실측 (2026-11-24, worker)

추천 · 판 · 결정 없음. 서비스 꼴 그대로 적는다. 결론: **근거 약함**. 기준(실제 서비스 30곳 · 국내 15곳 · DS 5곳) 중 DS 5곳은 채웠고, 실제 서비스는 20곳(국내 8)에서 멈췄다.

## 먼저 알아 둘 것

- 「다크 화면 위에서 차트 · 자 · 분포 · 지도에 얹는 사진(아바타) 핀」 은 공개 화면에서 거의 찾을 수 없다. 로그인 없이 열 수 있는 곳 가운데 지도 위 사진 마커는 Mapillary 한 곳만 잡혔고(라이트 지도), 차트 · 자 위 사진 핀은 0곳이다.
- 그래서 같은 뜻 인접 꼴(사진 원이 바탕 위에서 다른 원과 겹치거나 홀로 놓일 때 둘레를 어떻게 처리하나)을 보조로 쟀다. 지도 · 차트 위 핀 자체와 섞어 세지 않고 칸을 나눠 적는다.
- 이미 잰 지도 핀 기록(`docs/research/2026-11-20-color-map-pin.md` · q13 핀 그림자)은 색 채움 핀이라 사진 핀 둘레와 다르다. 다시 재지 않았다. 참고: 그 기록의 흰 테두리 핀(네이버 지도 · 직방 · 따릉이 등)은 사진이 아니라 색 채움이다.
- 방법: headless Playwright(`colorScheme: dark`, 권한 없음, 로그인 없음, 1440×900). 동그란 사진(IMG · 배경 이미지)을 찾아 자기 · 부모 · 조부모의 `border` · `box-shadow` · `outline` 계산값과 가장 가까운 불투명 바탕색을 읽었다. 같은 크기 원이 겹치는 쌍을 겹침(스택)으로 봤다. 많은 사이트가 다크 선호를 무시하고 라이트로 열려 「다크 여부」 를 칸에 적었다. 캡처는 `caps/`, 원본 JSON 은 `probe/`.
- 한계: 캡처를 눈으로 확인한 곳은 Mapillary(확대) · Cursor · somoim · GitHub · Linear · cal.com 이고, Resend · GitHub 크롭은 아바타를 놓쳐 값만 계산값이다. 대비비는 WCAG 2 상대 휘도, 반투명은 바탕과 섞어 계산.
