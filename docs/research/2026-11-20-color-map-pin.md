# 지도 핀 색 — 국내 · 해외 지도 서비스 실측 · 지도 SDK 공식 값

2026-11-20. 공통 층 3단계 색 파운데이션의 「지도 핀」 판 재료다. 오락실 지도 핀 모양은 네이버 지도 꼴로 이미 정했고 색 토큰은 정하지 않았다(공유 메모 `arcades-map-pin-color-token.md`). 여기에는 잰 값과 곳 수만 둔다. 추천 · 판단은 적지 않는다.

## 재는 법

- headless Playwright 1.61.1(Chromium), 1440×900, `colorScheme: 'dark'`, `permissions: []`, `locale: ko-KR`, 로그인 없음. 페이지를 열기 전마다 `~/noslog-research/wait-capacity.sh`, 브라우저 하나에 페이지 하나. 다크를 따르는지 보려고 같은 주소를 라이트로도 연 곳이 있다.
- 핀은 DOM(마커 div · svg · img) 계산값을 먼저 읽고, 지도 캔버스 안이면 캡처 픽셀로 읽어 「픽셀」 이라 적었다. 대비 비는 WCAG 2.
- 캡처 · 원문: 공유 메모 폴더 `common-layer/stage3/color/color-chart-pin/`(`caps/pin-korea/` · `caps/pin-global/`, 결과 원문 `parts/pin-korea.md` · `parts/pin-global.md`). 커밋하지 않는다.
- 옮긴 곳: [데스크톱 오락실 뼈대 실측](./2026-11-02-desktop-arcades.md) 「지도 핀과 이름」 과 [지도 미끄러짐](./2026-11-19-motion-map.md) 에 이미 있는 곳은 다시 재지 않고 출처를 달아 옮겼다. 그때 다크로 찍었는지 모르는 곳은 「다크 여부 미확인」.
- 캡처를 직접 열어 대조한 곳: 네이버 지도(산호 핀 · 같은 색 묶음 「2」) · Pinball Map(다크 지도, 범례 1대 흰 · 2–9 파랑 · 10+ 분홍).

## 핀 그림자 (2026-11-24, 오락실 지도 핀 그림자 물음 13)

오락실 핀의 `drop-shadow(0 1px 2px rgb(0 0 0 / 40%))` 를 둘지 뺄지 정하려고 다시 읽었다. 이미 잰 곳은 캡처(`color-chart-pin/caps/`)를 핀 둘레만 키워 다시 읽었고, DOM 마커는 `box-shadow` · `filter` 계산값을 새로 읽었다. 캡처 · 원문은 공유 메모 폴더 `common-layer/stage3/color/q13-pin-shadow/`(`RESEARCH.md` 가 같은 내용). 추천 · 판단은 적지 않는다.

- Flightradar24(다크 지도, 검은 윤곽)는 네 꼴 어디에도 넣지 않았다(31곳 = 16 + 11 + 2 + 1 + 1).
- 핀이 흰 바탕 알약이거나 상자인 곳(Airbnb · 네모 · 여기어때 · 다이닝코드 · Google 호텔)에서는 그림자가 A(없음, 선으로 구분)와 C(box-shadow)로 갈린다. 색 채운 물방울 · 원은 A 와 B 가 대부분이다.
- 지금 NosLog(`filter: drop-shadow(0 1px 2px rgb(0 0 0 / 40%))`, 흰 테두리 물방울)는 꼴로 B 에 가깝고 번짐은 더 작다. 비교용일 뿐 근거 아님.
- 다크 지도에서 그림자를 쓴 곳은 읽힌 2곳 모두 없음(뮤즈캣 없음, Flightradar24 윤곽만). 다크 지도 위에서 핀을 어떻게 띄우는지는 근거가 2곳이라 근거 약함.

### 근거 약함 · 미확인

- 근거 약함: 다크 지도 2곳(뮤즈캣 · Flightradar24). 「약함」 으로 적은 곳은 눈으로 겨우 보이는 정도라 같은 쪽에 두기 애매.
- 미확인: NOL · 캠핏 · Waze 핀 몸통(기록엔 이름 상자 `rgba(0,0,0,.3) 0 0 8px` 만) · Pinball Map 핀 · Radio Garden · 옛 기록에서 옮긴 13곳 · Google Maps JS PinElement · Apple MapKit · Mapbox 소스 직접 확인.
- Booking · 오피넷은 기록의 문장을 옮긴 것이라 이번 캡처에서 직접 확인하지 못했다.
- 눈으로 읽은 곳(국내 16 · 해외 11)은 번짐 · 불투명도를 숫자로 못 읽었다. 숫자가 있는 곳은 Airbnb · 네모(실제 서비스 2) · SDK(Mapbox · MapLibre · Uber · HERE · Leaflet 그림).
- 캡처는 1440×900 한 폭, 쪽마다 한 상태(평소 핀)만 봤다. 고른 핀 · 올림에서 그림자가 바뀌는지는 카카오맵 하나만 봤다.
