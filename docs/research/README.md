# 조사 기록

같은 조사를 다시 하지 않도록 조사 결과를 모아 두는 곳이다. 지금 규칙은 [디자인 가이드](../design/README.md)에, 결정 이유는 [결정 기록](../decisions/README.md)에 있고, 여기에는 조사에서 잰 값과 출처만 둔다.

## 쓰는 법

- 조사를 시작하기 전에 아래 목록과 해당 파일을 먼저 읽는다. 필요한 내용이 있으면 그 기록을 쓰고 다시 조사하지 않는다.
- 기록에 없는 화면 · 값만 새로 조사한다. 기록이 낡아 다시 재야 하면 사용자에게 먼저 묻는다.
- 조사 하나에 파일 하나. 이름은 `YYYY-MM-DD-짧은-이름.md`.
- 같은 주제의 기록이 있으면 새 파일을 만들지 않고 그 파일에 합친다. 옛 파일끼리 합쳐 파일을 지워야 하면 사용자에게 먼저 묻는다.
- 곳마다 URL · 확인 날짜 · 잰 값 · 캡처 경로를 적는다. 캡차 · 로그인 벽에 막힌 곳도 막혔다고 적는다.
- 곳을 조사할 때마다 바로 덧붙인다. 세션이 멈춰도 기록이 남게 끝까지 미루지 않는다.
- 캡처는 커밋하지 않고 `~/noslog-research/<조사 이름>/` 에 저장한다.
- 파일을 만들면 아래 목록에 `../research/파일이름.md` 꼴의 링크로 한 줄을 더한다. 여러 세션이 함께 고치는 표이므로 내 줄만 더한다.
