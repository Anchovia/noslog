- `admin-ui/notes.md` · `admin-ui/shots/` · `admin-ui/data/` — 어드민 UI 실측(서비스 35곳 · 디자인 시스템 12곳). 아래 1절에 곳별 기록 전문을 실었다.

근거의 무게

- UI: 라이브 DOM 실측 11곳, 공식 스크린샷 픽셀 측정 3곳, 스크린샷 관찰만 21곳(px 는 「미확인」). 다크로 확인한 서비스는 13곳이다. 로그인 없이 보이는 화면만 봤기 때문에 편집 폼 · 홈 · 피드백은 표본이 작다(13 · 13 · 8곳).
- 공지 틀: 업데이트 10곳 · 점검 11곳 · 장애 9곳은 표본 8곳을 채웠고, 이벤트 5곳 · 약관 개정 6곳 · 기능 종료 6곳은 「근거 약함」 이다.

- 한 벌 후보(Medusa · Laravel Nova · GitLab)의 캡처는 직접 열어 화면이 제대로 찍힌 것을 확인했다.

## 1. 어드민 UI 실측 — 곳별 기록

찍은 날 2026-11-17. headless Playwright(Chromium), 뷰포트 1440×900, colorScheme dark. 로그인 · 계정 만들기 없음.
캡처는 `shots/`(원본 PNG), 훑어보기용 축소본은 `thumbs/`, DOM 측정 원본은 `data/<캡처 이름>.json`, 지침 글 원문은 `data/txt-*.txt`.
「DOM」 줄은 `getComputedStyle` · `getBoundingClientRect` 자동 측정값이고, 나머지 줄은 캡처를 직접 열어 본 관찰이다. 문서 스크린샷만 있는 곳은 px 값을 재지 않았다(「미확인」).

### 1 업데이트

- 짧은 한 건짜리 꼴(바뀐 것 → 어디서 · 누구에게 → 문서 링크, 130–140단어) 2/10(GitHub · Vercel). 제목이 곧 바뀐 내용 한 문장.

- 제목 꼴: 날짜 + 종류(「# 10/30 - Patch Note」 · 「11월 4일(수) 업데이트 내역 안내」 · 「DPC 2026 Update (2026.10.19)」).

- 완료 알리기: 같은 글에 상태 갱신 4(Discord · Atlassian · GitHub · Vercel), 제목 머리표만 바꿈 1(메이플 [점검] → [점검완료]), 새 글 1(로스트아크, 끝난 시각 + 반영 내용).
