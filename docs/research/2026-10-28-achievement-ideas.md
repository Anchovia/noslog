바꾼 근거가 뚜렷한 것

- 「결의」 → 「의지」: 한국어 언더테일 한글패치가 Determination 을 「의지」로 고정했다(디시 언더테일&델타룬 갤 43911). 갤 안 「의지로 가득」 19 · 「결의로 가득」 5. 일본어는 공식 번역 「ケツイがみなぎった」.
- 「악성」 → 「운명」: 디시 클래식 · 피아노 갤의 「악성」 231건이 모두 「악의적」 뜻이고 「악성 베토벤」 은 0건.
- 「蠍火」 → 「헐화」: 노스텔지어 갤 275건, 「갈화」 는 리듬게임 뜻으로 0건. 「~의 후계」 는 일본어 꼴이라 뺐다.
- 「노스탤지어」 → 「Nostalgia」: 노스텔지어 갤 「노스텔지어」 419 · 「노스탤지어」 44. 곡 제목이 모두 「… Nostalgia」 라 로마자로 썼다.
- 「할로윈」 → 「핼러윈」: 표준 표기, 조건 글과 맞췄다.
- 일본어 「削除曲」 · 「倉野川市民」 · 「全機種制覇」 는 5ch · 위키에서 쓰는 말, 「還る場所」 · 「幻想郷を彩る演奏会」 는 NOSTALGIA 공식 장 · 이벤트 이름이다.
- 영어 「Revival」 은 Stack Overflow 배지와 조건이 거의 같다. 「Cat Person」 은 다른 게임 업적 3곳의 이름이다.
- 근거 약함: 「이름만 Normal」 · 「Normalとは」 · 「Not So Normal」(세 언어 모두 해당 밈을 찾지 못함), 일본어 雨 · 食べ物 · 全譜面制覇 · 埋もれた楽譜.
