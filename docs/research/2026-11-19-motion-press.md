# 움직임 — 누름 쪽 실측(눌림 축소 · 올림 · 누름 색 · 떠 있는 메뉴)

공통 층 3단계 움직임 판 2 · 3 의 「다른 실측 서비스 안」 근거 중 누름 쪽이다. 실제 서비스가 어떻게 움직이는지 잰 값과 출처만 둔다. 디자인 시스템 문서 값은 [디자인 시스템 모션 지침](./2026-11-19-motion-design-systems.md), 대화상자 · 토스트는 [떠 있는 면](./2026-11-19-motion-overlay.md), 탭 · 펼침은 [고름 · 펼침](./2026-11-19-motion-selection.md), 그래프 · 로딩은 [데이터 · 로딩](./2026-11-19-motion-data-loading.md) 기록이 맡는다.

- 확인 날짜: 2026-11-19
- 방법: headless Chromium(Playwright 1.61) · `colorScheme: dark` · 1440×900 · `ko-KR` · `permissions: []`. 쪽을 열고 5초 뒤
    - 눌림: 버튼 위로 올려 0.45초, `mousedown` 뒤 0.4초 동안 `document.getAnimations()` 와 계산값(`transform` · `scale` · 폭)을 읽고, 버튼 밖에서 놓아 눌림이 실행되지 않게 했다.
    - 색: 버튼 계산값 `transition-property · duration · timing-function`, 올렸을 때 잡힌 `background-color` 전환.
    - 메뉴: `aria-haspopup` · `aria-expanded=false` · 「더보기 · 정렬 · 언어 · 메뉴 · 카테고리」 버튼과 머리 내비 항목에 올리고 누른 뒤 0.9초, Esc 로 닫은 뒤 0.7초 동안 애니메이션과 새로 붙은 요소의 계산값을 프레임마다 적었다.
- 값 출처: 「애니」 = `getAnimations()` 가 준 CSS 전환 · 애니메이션 · Web Animations 값, 「계산값」 = 프레임마다 읽은 `getComputedStyle`, 「캡처」 = 열린 모습을 캡처로 확인.
- 캡처 · 영상 · 원 기록: `~/noslog-research/motion-usage-2026-11-19/` 의 `shot/<곳>-<자리>.png`, `video/<곳>/*.webm`(곳마다 전 과정 녹화), `json/<곳>.json` · `json/press-<곳>.json` · `json/menu-<곳>.json` · `json/menu2-<곳>.json`.
- 「즉시」 는 메뉴가 열린 것을 캡처나 열린 판 크기로 확인했는데 움직임이 하나도 잡히지 않은 경우다.
