# 색 · 모서리 · 포커스 자리별 조사 (2026-10-26)

[결정](../decisions/2026-10-26-geist-color-radius.md)의 근거 원문이다.

## 방법

- 출처 105곳(앞선 [체계 묶음 조사](./2026-10-25-design-system-cluster.md)와 같은 디자인 시스템 · 구현 라이브러리 · 실제 사이트)에서 자리 107곳을 적었다. 자리 = 바탕 · 카드 · 메뉴 · 대화상자 · 입력 · 보조 버튼 · 고른 세그먼트 · 고른 칩 같은 부품의 면 · 선 · 모서리 · 포커스 모양.
- 디자인 시스템 · 라이브러리는 다크 테마 토큰 원본과 부품 소스, 사이트는 headless Playwright 로 다크 화면을 쟀다.
- 「구조」 는 값이 아니라 관계(카드가 바탕과 다른가, 메뉴가 카드와 같은가 등)다. 칸마다 값을 아는 곳만 분모로 센다.
- 원자료(출처별 JSON · 캡처)는 세션 임시 폴더에 있고 리포에는 없다.
