# 패턴

여러 화면이 같은 모양으로 쓰는 묶음이다. 화면 문서는 이 패턴을 링크하고 다시 적지 않는다.

## 제목

- 페이지 제목 `nl-page-title`, 페이지 구역 제목 `nl-section-title`, 상자 안 제목 `nl-component-title`.
- 제목 아래 설명 · 메타 글줄(홈 태그라인 · 로그인 부제 · 동의 부제 포함)은 `nl-metadata` 흐림, 항목 사이 「 · 」, 좁으면 항목 단위로 줄바꿈.
- 페이지 제목 줄이 넘치면 줄임표로 한 줄(채보 뷰어 폰 머리) 또는 끝 페이드(악곡 상세 머리) — 화면 문서가 정한다.

## 제목 줄

`nl-heading-row` — 제목 · ⓘ · 메타가 열 8 · 행 4 로 줄바꿈한다.

- 오른쪽 끝 이동은 제목 링크 `nl-heading-link`: 글자 `nl-control` + 꺾쇠 16 · 간격 4 · 광학 −4 · 누르는 영역 위아래 +12. 「모두 보기 ›」 · 「평가하기 ›」.
- 같은 자리의 동작(「선택 해제」 · 「다시 시도」)은 제목 링크가 아니라 고스트 M 버튼. 줄 높이를 늘리지 않게 위아래를 당기고, 잉크가 오른쪽 선에 서게 오른쪽 12 를 당긴다.

## 로그아웃 상태

- 구역 동작을 권할 때는 제목 줄 오른쪽 끝 제목 링크 「로그인하고 ○○ ›」(보기 · 투표하기 · 의견 남기기 · 내 순위 확인).
- 공개된 결과는 그대로 보인다. 흐림으로 가리지 않는다. 흐림은 입력 영역 잠금(악곡 상세 패턴 투표)에만.
- 폼 창 · 연결이 필요한 동작은 [로그인 안내](./components/dialog.md#로그인-안내).
- 자격이 없는 입력은 숨긴다. 자격 설명 문장을 두지 않는다.

## 값이 없을 때

- 그래프 · 막대 · 수치의 자리는 틀을 유지하고 값 자리만 흐린 「—」(`content/subdued`). 「0」 으로 채우지 않는다.
- 값이 없는 수치 띠 칸은 만들지 않는다([수치 띠](./components/stat-strip.md#값이-없을-때)).
- 화면이 이미 말하는 것을 문장으로 다시 설명하지 않는다(「집계 데이터가 부족합니다」 · 「기록이 1건이라…」 · 「참가자 N명」 같은 줄을 두지 않는다).
- 빈 목록은 흐린 `nl-body-secondary` 한 줄 안내.

## 목록 화면의 머리

악곡 목록 · 서열표 · 빙고 · 업적이 같은 문법을 쓴다.

| 폭      | 구성                                                                                                                                                     |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 좁은 폭 | 검색줄(검색이 남은 폭 + 오른쪽 ☰ 필터 아이콘 버튼 · 적용 개수 배지) →12→ 결과 줄(왼쪽 정렬 `SortMenu` 고스트 M · 오른쪽 보기 전환 세그먼트 M) →12→ 목록 |
| 넓은 폭 | 검색 전체 폭 → 레일(필터 그룹) \| 정렬(L) · 보기 전환(L) → 결과 수 → 목록                                                                                |

- 결과 수는 좁은 폭에서 제목 아래 메타 글줄(「579곡」), 넓은 폭에서 결과 쪽.
- 화면마다 다른 점(빙고 상태 칩 · 서열표 띠 값 셀렉트 · 업적 분류 칩)은 화면 문서에 적는다.
- 오락실만 예외로 좁은 폭에서 필터가 검색줄 오른쪽 아이콘 버튼, 정렬은 시트 요약 줄 오른쪽([오락실](./pages/arcades.md)).

## 더 불러오기

- 악곡 · 채보 발견 · 서열표는 끝이 240px 안에 들어오면 20개씩 자동으로 세 번(80개)까지, 그 뒤는 「더 보기」 버튼.
- 다른 목록(빙고 전부 · 프로필 기록 20개씩 「더 보기」 등)은 화면 문서에 적는다.

## 저장 방식

| 방식                   | 쓰는 곳                                                                                   |
| ---------------------- | ----------------------------------------------------------------------------------------- |
| 누르는 즉시 저장       | 스위치 · 한 개 고르는 투표 · 패턴 투표 · 설정 공개 설정 · 설정 프로필 칸(창에서 「적용」) |
| 칸 옆 「저장」         | 설정 닉네임(중복 확인이 필요한 글자 칸)                                                   |
| 발 · 아래 바의 주 버튼 | 폼 창 · 글쓰기 · 투표 만들기                                                              |

- 즉시 저장은 저장 상태(저장 중 · 저장됨 · 실패 + 다시 시도)를 한 곳에 보이고, 실패하면 그 값만 되돌린다.
- 바쁜 버튼은 [버튼 — 상태](./components/button.md#상태).
