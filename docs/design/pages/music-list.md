# 악곡 목록 · 채보 보기

주소 `/music` · 코드 `features/music/components`(`discovery-page.tsx` · `music-result-card.tsx` · `chart-result-group.tsx`)

악곡 목록은 곡 단위 「악곡」 보기와 채보 단위 「채보」 보기 두 가지다. 아래 「발견 공통」 은 서열표(→ [서열표](./tiers.md))에도 그대로 쓴다.

## 구성

### 발견 공통

넓은 폭(1056 이상)은 왼쪽 필터 레일, 그 아래 폭은 전체 화면 필터 창이다(→ [필터](../components/filter.md)).
레일 폭은 내용 폭의 1/4, `calc((100% - 3 * 16px) / 4)` 다(셸 1200 에서 272).

결과는 목록 끝이 240px 안에 들어오면 20개씩 자동으로 불러오고, 3번(80개)까지 그렇게 한다. 그 뒤는 「더 보기」 버튼이다.

넓은 폭의 정렬 트리거는 기준만 보인다. 접근 이름에는 「정렬:」 을 넣는다(→ [메뉴](../components/menu.md)).

### 머리 · 결과 줄

결과 수는 제목 아래 메타 글줄(「579곡」)에 쓴다.

| 폭                 | 순서                                                        |
| ------------------ | ----------------------------------------------------------- |
| 좁은 폭(672 미만)  | 검색줄 →12→ 결과 줄 →12→ 목록                               |
| 넓은 폭(1056 이상) | 검색 전체 폭 → 레일 \| 정렬(L) · 보기 전환 → 결과 수 → 목록 |

좁은 폭의 검색줄은 검색 + 오른쪽 ☰ 필터 아이콘 44 다. 아이콘에 적용 개수 배지를 붙인다.
결과 줄은 왼쪽 정렬 `SortMenu` 고스트 M, 오른쪽 보기 전환 세그먼트 M 이다(→ [세그먼트](../components/segmented-control.md)).

### 악곡 카드

카드는 상자(`surface`)다. 보기는 목록 · 격자 · 촘촘한 격자(`view=dense`) 셋이다.

| 칸        | 목록             | 격자             | 촘촘한 격자              |
| --------- | ---------------- | ---------------- | ------------------------ |
| 자켓      | 64               | 정사각           | 정사각                   |
| 이름      | `entity-title`   | `emphasis-label` | `emphasis-label` 한 줄만 |
| 아티스트  | `body-secondary` | `metadata`       | 없음                     |
| 난이도 판 | 24               | 20               | 20                       |
| 카드 안쪽 | —                | 12               | 8                        |

난이도 판 `DifficultyLevels` 는 고정 순서 4칸(Normal · Hard · Expert · Real)이다.
판은 모서리 `radius/control` · 면 `raised` · 사이 4 이고, 숫자는 `metric-value` + 난이도 글자색이다.
없는 난이도는 자리만 비운다(테두리 없음).

### 악곡 격자 열

열 수는 결과 영역의 container query 로 정한다.

| 결과 영역 폭 | 격자 | 촘촘한 격자 |
| ------------ | ---- | ----------- |
| 288 이상     | 2열  | 3열         |
| 536 이상     | 3열  | 4열         |
| 672 이상     | 4열  | 5열         |

격자는 4열이 상한이다(셸 1200 에서 카드 200). 카드 최소 폭은 156 이다.
촘촘한 격자는 단계마다 한 열 더 둔다.

### 채보 보기

채보마다 한 줄이고, 한 줄은 링크 하나다. 같은 곡의 다른 난이도는 줄이 따로다. 곡 단위로 보려면 「악곡」 보기를 쓴다.
정렬 · 페이지 · 개수 · 필터 적용 버튼의 수는 모두 채보 단위다.

줄은 악곡 목록 줄 틀(`nl-music-card--list`, 줄 사이 8)을 쓴다.

| 자리      | 내용                                                                                                       |
| --------- | ---------------------------------------------------------------------------------------------------------- |
| 왼쪽      | 자켓 80 정사각(자켓 카테고리 배지 그대로)                                                                  |
| 가운데    | 이름 `entity-title` / 아티스트 `body-secondary` 흐림 두 줄. 모두 한 줄 말줄임 · 위아래 4 로 자켓 안 가운데 |
| 오른쪽 끝 | 난이도 칩 `nl-chart-chip` 「Real 3」                                                                       |

난이도 칩은 레벨 판(`nl-level`)을 이름까지 넓힌 것이다.
높이 24 · 모서리 `radius/control` · 면 `raised` · 이름 `control` + 레벨 `metric-value` · 난이도 글자색.

## 폭별

좁은 폭(672 미만)은 필터를 검색줄 아이콘으로 열고, 정렬 · 보기 전환은 M 이다.
중간 폭(672–1055)도 필터는 전체 화면 창이다.
넓은 폭(1056 이상)은 레일이 나타나고, 정렬 · 보기 전환은 L 이다.

## 상태

로딩은 결과 카드 · 채보 묶음 스켈레톤이다.

## 동작

자동 불러오기 · 「더 보기」 는 위 「발견 공통」 대로다. 촘촘한 격자는 주소 `view=dense` 다.

## 하지 않는 것

격자에 5열 단계를 두지 않는다. 중간 폭 끝에서 레일이 나타나며 열 수가 뒤집힌다.
채보 보기에는 보기 전환 · 노트 · BPM · 길이 열 · 채보 미리보기를 두지 않는다.
채보 줄에 작성자 · 출처 · 공개일 메타 줄을 두지 않는다. 뷰어에서 본다.
