# 소식 · 공지사항

주소 `/announcements` · `/announcements/[slug]` · 코드 `features/announcements`

## 구성

### 소식 입구

공지 목록과 이벤트 목록은 같은 머리를 쓴다.

| 순서 | 내용                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 1    | 뒤로 링크 「홈」 →24→                                                      |
| 2    | 제목 「소식」 →16→                                                         |
| 3    | 1단 탭 「공지사항 · 이벤트」(`NewsTabs`, [탭](../components/tabs.md)) →24→ |
| 4    | 필터 칩. 공지는 분류, 이벤트는 상태([이벤트](./events.md))                 |

두 탭은 각 페이지의 주소를 그대로 쓴다. 게시판과 데이터는 따로 두고, 유저 글과 공식 공지를 한 목록에 섞지 않는다.
헤더 메뉴는 그대로 둔다.

### 공지 목록

| 순서 | 내용                                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------------------------ |
| 1    | 「소식」 머리(위 소식 입구) →24→                                                                                   |
| 2    | 분류 필터 칩 「전체 · 업데이트 · 점검 · 데이터 · 안내」(`FilterChipLinks` M, [필터](../components/filter.md)) →24→ |
| 3    | 고정 줄 →24→                                                                                                       |
| 4    | 날짜 목록                                                                                                          |

고정 줄은 활성 중대 공지이고 1쪽에만 나온다. 모양은 목록 항목 카드다. 면 `surface/surface` · 모서리 `radius/control` · 안쪽 12이고,
날짜 앞에 핀 16을 둔다(핀 →4→ 날짜). 고정 줄이 여럿이면 사이 8. 고정 줄에 나온 글은 날짜 목록에서 뺀다.

### 공지 줄

목록의 한 줄은 이렇게 놓는다. 위아래 12, 줄 아래 `border/row`.

| 폭                | 배치                                                                                           |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| 672 이상          | 분류 태그 →12→ 제목 `entity-title`(남는 폭, 넘치면 줄바꿈) →12→ 오른쪽 날짜 `metadata` subdued |
| 좁은 폭(672 미만) | 「분류 태그 … 날짜」 한 줄 →4→ 제목                                                            |

고정 글은 날짜 앞에 핀 16을 붙이고, 핀의 이름은 화면 읽기로 알린다.
홈 공지 카드와 이벤트의 「내 글」 도 같은 줄 부품을 쓴다. 홈 공지 카드는 제목 굵기와 고정 표시를 바꾸지 않는다.

### 상세 머리

| 순서 | 내용                                                                        |
| ---- | --------------------------------------------------------------------------- |
| 1    | 뒤로 링크 「공지사항」 →24→                                                 |
| 2    | 분류 태그 · 「게시일」 날짜 · 「수정일」 날짜 한 줄(`metadata` subdued) →8→ |
| 3    | 제목 `page-title` →16→ 공지 배너(있을 때) →24→ 본문                         |

한 줄 안 항목 사이는 8 이다. 「수정일」 은 그 언어의 글을 게시한 뒤에 고쳤을 때만 둔다. 이벤트 상세도 같은 머리를 쓴다([이벤트](./events.md#상세)).

### 공지 배너

글마다 언어별 그림 한 장을 넣거나 뺀다. 만드는 곳은 [관리자 공지 작성](./admin-announcements.md#공지-배너)이다.
폭은 읽기 본문과 같고 높이는 비율대로 줄어든다. 대체 글은 글 제목이다. 공지 목록 · 공유 미리보기에는 쓰지 않는다.

### 상세 본문

공지 · 이벤트 본문과 편집기 미리보기, 같은 렌더러를 쓰는 개발자 문서(`/developer`)에만 읽기 본문 `nl-body-reading`(16, 줄 높이 `--nl-type-line-height-body`)을 쓴다.

- 폭은 읽기 폭 `--nl-container-reading` 그대로다.
- 문단 사이 16. 점 목록과 번호 목록은 모두 들여쓰기 24.
- 본문 안 굵게는 같은 크기 · 같은 행간에 굵기만 올린다. 한국어 · 일본어는 `--nl-type-weight-semibold`(600), 영어는 `--nl-type-weight-strong`(700)이다.
- 본문 안 링크는 `content/default` 에 늘 밑줄이다. 올리거나 키 포커스가 가면 `content/strong` 이다.
- 본문 표는 줄 높이가 컨트롤 높이(글자 14 · 줄 높이 ui)이고 줄 아래 `border/row` 다. 머리 칸은 `content/subdued` 에 `--nl-type-weight-strong`.
- 소제목 h2는 구역 값을 쓴다. 앞 문단과 `--nl-section-gap`, 첫 내용까지 `--nl-section-title-gap`.
- 소제목 h3는 상자 제목처럼 내용까지 8.
- 본문 이미지는 [이벤트](./events.md#상세)와 같은 렌더러 규칙을 따른다.

### 라벨 항목

`**라벨:** 설명`(또는 `**라벨**: 설명`) 문단이 둘 이상 이어지면 렌더러가 목록(`dl`)으로 그린다.
라벨은 `component-title`(「:」 를 뺀다) →8→ 설명, 항목 사이 16. 하나뿐이면 문단 그대로 둔다. 글 쓰는 방식은 바뀌지 않는다.

### 상세 끝

| 순서 | 내용                                                      |
| ---- | --------------------------------------------------------- |
| 1    | 본문 →24→                                                 |
| 2    | 이전 글(더 오래된 글) · 다음 글(더 새 글) 두 칸 →16→      |
| 3    | 「목록으로」 보조 버튼 L([버튼](../components/button.md)) |

두 칸은 목록 항목 카드이고 사이 8. 칸 안은 라벨 `metadata` subdued →4→ 제목 `body-secondary`. 다음 글 칸은 오른쪽 정렬이다.
없는 쪽은 빈 칸으로 두고, 둘 다 없으면 칸째 없앤다.
글에 투표가 있으면 본문 →24→ 투표([투표](../components/poll.md)) →24→ 두 칸이다.

## 동작

분류 필터 칩은 주소 `?category=` 로 상태를 갖는다.

## 하지 않는 것

- 공지 줄에 요약을 붙이지 않는다.
- 날짜 목록을 월 제목으로 나누지 않는다.
- 유저가 쓴 이벤트 글을 공지 목록에 섞지 않는다.
