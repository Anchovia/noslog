# 파트너 동의 · 개발자 문서

주소 `/authorize`(동의 화면) · `/developer`(개발자 문서) · 코드 `features/partner`

## 구성

### 동의 화면

| 순서 | 내용                                                                               |
| ---- | ---------------------------------------------------------------------------------- |
| 1    | 파트너 표시 40 · 제목 「○○에 내 NosLog 기록 보내기」 · 부제 「고른 기록만 보내요」 |
| 2    | 계정 줄. 아바타 · 이름 · 고스트 M 「다른 계정」                                    |
| 3    | 「항상 보내요」. 기본 프로필 글                                                    |
| 4    | 「골라서 보내요」. 「모두 선택」 아래 구분선, 그 아래 항목마다 체크                |
| 5    | 법정 고지 표. 펼친 채로 둔다                                                       |
| 6    | 버튼. 세로로 쌓는다                                                                |
| 7    | 돌아갈 곳 · 운영 주체 두 줄                                                        |

- 「골라서 보내요」 의 체크는 모두 기본 꺼짐이다([폼 조작](../components/form-controls.md)).
- 보낼 수 없는 항목은 목록 맨 아래에 한 줄로 적는다.
- 묶음 제목(「항상 보내요」 · 「골라서 보내요」 · 법정 고지) · 항목 설명 · 보낼 수 없는 항목 줄은 `metadata` 흐림이다.
- 부제 끝 → 첫 내용은 16, 폼 묶음 사이는 24 다([기초값 — 간격](../foundations.md#간격)).

### 개발자 문서

공지 본문 부품을 읽기 폭으로 쓴다([소식 › 상세 본문](./news.md#상세-본문)). 머리도 공지 글 머리(설명 `metadata` 가 제목 위)를 쓴다.
