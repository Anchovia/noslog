# 오락실

주소 `/gamecenter` · `/gamecenter/[slug]` · 코드 `features/arcades`(뮤즈캣 연동이 꺼졌을 때) · `features/musecat`(켜졌을 때)

`MUSECAT_MODE`(off · mock · live)가 켜졌을 때만 뮤즈캣 연동 화면을 쓴다. 꺼져 있으면 오락실은 아래 뮤즈캣 연동이 꺼졌을 때 절 그대로다.
두 절의 규칙을 섞지 않는다.

## 뮤즈캣 연동이 꺼졌을 때

### 구성

목록

- 지도와 목록이 한 화면이다. 목록 지도 크기는 부품 고유 크기 절을 따른다.
- 672 이상은 다른 목록과 같은 정렬 | 필터 툴바를 쓴다. 필터 그릇은 팝오버다([필터](../components/filter.md)).

상세

이름 아래에 상태 줄 없이 바로 정보 행(주소 · 영업시간 · 요금)이 온다. 정보 행 다음, 위치 앞에 「시설」 구역을 둔다.

영업시간을 펼치면 7일 표가 나온다. 토요일 줄 전체(요일 · 날짜 · 시간)는 `judgement/near` 파랑, 일요일 줄 전체는 `feedback/destructive` 빨강이다. 휴무 줄도 주말 색을 따른다.

사진

- 모든 폭에서 밀어 넘긴다. 좌우 가장자리 세로 가운데에 ‹ › 44 와 카운터를 두고, 키보드 ← → 로도 넘긴다. 끌기만으로 조작하지 않게 하려는 것이다.
- 넓은 폭(1056 이상)에서 사진이 2장 이상이면 모자이크다. 큰 사진 하나와 작은 사진 최대 2장, 순서는 고정이다.
- 모자이크에는 ‹ › 와 카운터가 없다. 오른쪽 아래에 「사진 N장 모두 보기」 를 둔다. 카운터와 같은 어두운 판이고 높이는 컨트롤 작게(M)다.
- 어느 사진을 눌러도 [사진 뷰어](../components/photo-viewer.md)가 그 사진으로 바로 열린다. 격자 단계는 없다.

시설

- 있다 / 없다는 아이콘 + 글자로, 정도는 정해진 보기의 키-값으로 쓴다. 입력한 것만 보이고, 없으면 자리도 없다.
- 시설 구역은 아이콘 20 흐림 + 글자 `body-secondary` 두 열이다. 좁은 폭에서도 두 열이다. 사이는 세로 12 · 가로 16.

기체 카드

기체 한 대가 카드 하나다. 면 카드(1px 테두리 · 안쪽 16 · 카드 사이 8, [면 카드](../components/surface-card.md))다.

| 순서 | 내용                                                          |
| ---- | ------------------------------------------------------------- |
| 1    | 이름 · 상태 줄                                                |
| 2    | 태그. 아이콘 16 흐림 + `metadata` 흐림, 사이 가로 12 · 세로 4 |
| 3    | 특징 판                                                       |
| 4    | 버튼 「가동 확인」 · 「고장 신고」                            |

- 이름 · 상태 줄은 두 열이다. 왼쪽은 이름(`control`) / 위치 메모(`metadata`), 오른쪽은 상태(`control`) / 확인 시각(`metadata`)이다. 열 안 사이는 4.
- 상태 앞에 기체 색 점을 단다. 늘 글자와 함께다([태그 › 상태 점](../components/tag.md)).

    | 상태        | 점        |
    | ----------- | --------- |
    | 가동 · 양호 | 성공 초록 |
    | 보통        | 경고 노랑 |
    | 주의        | 위험 빨강 |
    | 이용 불가   | 위험 빨강 |
    | 미확인      | 빈 원     |

- 특징 판은 `surface/surface` · 모서리 `radius/small` · 안쪽 8/12 다. 키는 흐리게, 값은 기본색 `body-secondary` 로 두 열에 쓴다. 모르는 항목은 줄이 없다. 기타 글은 판 안 구분선 아래에 쓴다.
- 「가동 확인」 은 흰 주 버튼, 「고장 신고」 는 보조 버튼이다. 둘 다 글자만이고 카드 안 버튼이라 M 이다([버튼](../components/button.md)).

「길찾기」 도 글자만 쓴다. 아이콘은 글자 없는 버튼(하트 · 제보)에만 쓴다.

### 폭별

| 폭                    | 목록                                                                                                                                                     |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 좁은 폭(672 미만)     | 필터는 검색줄 오른쪽 아이콘 버튼(컨트롤 L, 적용 개수는 오른쪽 위). 정렬은 시트 요약 줄 오른쪽 고스트 `SortMenu`. 지도 · 시트는 좌우 끝까지, 시트 안쪽 16 |
| 672 이상              | 정렬 \| 필터 툴바. 좁은 폭의 배치는 오락실에만 있는 예외다                                                                                               |
| 1056 미만 · 이상      | 1056 미만은 지도 + 아래 시트. 1056 이상은 목록 \| 지도 1:1 · 사이 16, 지도는 sticky(헤더 + 24) · 최소 높이 320                                           |
| 상세 1056 미만 · 이상 | 1056 미만은 아래 고정 바(위아래 12 · 좌우 16, 672 이상 24). 1056 이상은 본문 \| 레일 2:1 · 사이 24, 레일 sticky(헤더 + 24) · 아래 바 없음                |

상세 사진은 넓은 폭에서 2장 이상이면 모자이크, 그 밖에는 밀어 넘김이다.

### 상태

- 지도를 띄우지 못하면 짧은 위험 알림과 「다시 시도」 를 둔다. 목록은 그대로 둔다([상태 메시지](../components/status-message.md)).

### 동작

- 마우스 휠 확대는 목록 지도에만 쓴다.
- 카드 · 핀 선택만 바뀔 때는 기존 핀의 선택 표시와 겹침 순서만 바꾸고 키보드 포커스를 지킨다.
- 지도 이동 · 크기 · 검색 결과가 바뀔 때 핀 묶음을 다시 계산한다.
- 오락실 제보 창은 `ResponsiveDialog` 로 연다(672 미만 전체 화면, 이상 가운데 창, [대화상자](../components/dialog.md)).

### 하지 않는 것

- 상세 이름 아래에 상태 줄을 두지 않는다.
- 글자 있는 버튼(「가동 확인」 · 「고장 신고」 · 「길찾기」)에 아이콘을 달지 않는다.

## 뮤즈캣 연동이 켜졌을 때

### 구성

상세

| 순서 | 내용                                                                                                              |
| ---- | ----------------------------------------------------------------------------------------------------------------- |
| 1    | 뒤로 · 이름 `page-title`                                                                                          |
| 2    | 지역 · 게임 수 `body-secondary` 흐림                                                                              |
| 3    | 영업 상태. 「영업 중 / 영업 종료」 `emphasis-label` + 흐린 「· 24:00에 영업 종료 / 10:00에 영업 시작」. 점은 없다 |
| 4    | 사진 줄                                                                                                           |
| 5    | 정보 줄 `IconRows`                                                                                                |
| 6    | 게임                                                                                                              |
| 7    | 공지 · 메모                                                                                                       |
| 8    | 시설                                                                                                              |
| 9    | 위치 지도                                                                                                         |

정보 줄 다음부터는 구역이다. 구역 사이는 쌓기 16 + 구분선이다.

- 사진 줄은 정사각 160 · 모서리 `radius/control` · 사이 8 이다. 옆으로 밀고, 오른쪽은 화면 끝까지 간다. 사진이 0장이면 같은 높이의 「이미지는 준비 중」 칸을 둔다. 출처 칩을 단다.
- 정보 줄은 [아이콘 정보 줄](../components/surface-card.md)이다. 주소(+ 노선 보조 줄) · 고스트 M 「복사」, 영업 상태 글 · 끝 펼치기(요일별 표 · 현지 시간 주석), 소셜 계정 · 바깥 링크, 전화 · 「복사」 순이다. 구역 제목은 화면 읽기에만 둔다.

게임

- 제목은 「게임」 `section-title` 이고 개수는 쓰지 않는다.
- 뮤즈캣이 보낸 모든 게임을 `border/row` 선 줄로 보인다. NOSTALGIA 가 먼저다.
- 줄은 이름 `entity-title` · 오른쪽 대수, 요금 · 위치 흐림, 고장 상태 글자, 폭 가득 옅은 「자세히 ∨」 순이다.
- 고장 상태는 「고장 신고 n건 · 정도」 위험 표시색, 「고장 신고 없음」 성공 표시색 글자다.
- 「자세히」 를 펼치면 고장 내용 · 해결 투표 · 새 버전 확인 · 기체 특징(NOSTALGIA) · 보조 버튼 「고장 신고」(아이콘 없이 글자)가 나온다.
- 줄에는 버튼을 두지 않는다.
- 4개 뒤에는 폭 가득 「게임 더보기 (n)」 를 둔다.
- 뮤즈캣을 연결하지 않은 사람에게는 끝에 한 줄 + 보조 M 「로그인 · 연결」 을 둔다.

공지 · 메모

- 공지는 줄 목록이다. 줄은 본문 두 줄 · 날짜 · 종류다. 누르면 펼치고 「홈페이지 ↗」 를 보인다.
- 메모를 그 뒤에 둔다.

시설은 묶음 이름 `metadata` 아래에 있는 것만 태그로 보인다.

위치 지도는 높이 160 이다.

하단 바는 길찾기 · 뮤즈캣 즐겨찾기 · 기체 정보 고치기다. 꺼졌을 때의 하단 바 자리 그대로다.

연결 안내

연결이 필요한 동작을 누르면 연결 안내가 열린다. 공용 로그인 안내 그대로다([대화상자 › 로그인 안내](../components/dialog.md)).

| 자리 | 내용                                                                |
| ---- | ------------------------------------------------------------------- |
| 머리 | 동작 이름                                                           |
| 본문 | 「로그인하면 / 뮤즈캣을 연결하면 ○○를 쓸 수 있어요」 →4→ 한 줄 설명 |
| 발   | 취소 · 로그인(연결)                                                 |

길찾기 창

| 순서 | 내용                                                         |
| ---- | ------------------------------------------------------------ |
| 1    | 주소 + 고스트 M 「복사」                                     |
| 2    | 앱 줄. 앱 첫 글자 표시 24 · 이름 · 바깥 링크, 줄 사이 구분선 |

- 앱은 국내 오락실이면 네이버 · 카카오 · Google · Apple, 해외면 Google · Apple 이다.
- 폐업한 오락실이면 먼저 확인 창을 띄운다.

목록

오락실 찾기와 같은 지도 + 아래 시트 틀을 쓴다(공용 `ArcadeMapSheet`). 배치는 폭별 절에 적는다.

시트 · 패널 머리는 「◎ 위치 ○○」 한 줄이다.

- 조준선 16, 「위치」 는 굵게 정보 파랑이다.
- 기준 위치는 내 위치 / 검색어 / 시 · 구 · 동 이름이다.
- 개수 문장은 두지 않는다.
- 나라가 하나면 나라 칩 줄이 없다. 칩에 개수를 쓰지 않는다.

목록 줄

| 자리   | 내용                                                                                                                             |
| ------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 왼쪽   | 썸네일 96. 사진이 없으면 회색 칸 + 핀 →12→                                                                                       |
| 오른쪽 | 이름 `entity-title` + 이름 오른쪽 뮤즈캣 로고 16 + 거리(내 위치가 기준일 때)                                                     |
|        | 태그(NOSTALGIA 대수 · 고장 신고 · 폐업)                                                                                          |
|        | 주소 한 줄                                                                                                                       |
|        | 영업 상태. 「영업 중」 성공 초록 · 「영업 종료」 위험 빨강 + 「n시에 영업 종료/시작」. 영업시간이 없으면 흐린 「영업 정보 없음」 |

줄 위아래는 16, 줄 사이는 1px `border/row` 선이다.

핀

- 핀은 이름 판을 단다. 떠 있는 면 · `metadata` · 핀 오른쪽 위다. 이름 판이 겹치면 뒤에 그린 것을 숨긴다.
- 핀을 누르면 고른다. 고른 핀은 흰 핀이다. 좁은 폭에서는 시트에 그 줄 하나만 보이고, 넓은 폭에서는 패널의 그 줄로 간다. 고른 줄은 고르기 줄 고른 면(`surface/control`)이다.
- 지도 바탕을 누르면 고르기가 풀린다. 줄을 누르면 상세로 간다.
- 묶음 버블은 지름 32 에서 48 까지다. 누르는 자리는 44 그대로다.
- 「이 지역에서 검색」 은 패널을 뺀 지도의 가운데에 둔다. 떠 있는 버튼이다(모서리 `radius/control` · 컨트롤 높이).

위치 버튼

- 지도 오른쪽 아래 원(`radius/full`) 버튼 묶음이다. 내 위치 조준선이 위, 범례 「?」 가 아래, 사이 8.
- 누를 때 권한을 묻고 바로 적용한다. 확인 버튼이나 방식 고르기는 없다.
- 상태는 조준선(평소) · 빈 조준선(찾는 중) · 정보 표시색 채운 조준선(내 위치) · 사선(거부)이다. 거부되면 검색칸 아래에 한 줄을 쓴다.
- 처음 기준은 이 기기의 마지막 위치다. 없으면 접속 지역(IP), 그것도 없으면 서울이다.

### 상태

- 위치 지도를 띄우지 못하면 위치 구역이 없다.
- 시설이 없으면 시설 구역이 없다.
- 사진이 0장이면 「이미지는 준비 중」 칸을 둔다.
- 영업시간이 없으면 목록 줄에 흐린 「영업 정보 없음」 을 쓴다.

### 동작

- 정보 수정 창에서 저장하면 토스트 「뮤즈캣에 반영했어요(· 기체 특징은 확인 뒤 반영돼요)」 를 띄운다([토스트](../components/status-message.md)).
- 특징 칸을 저장하면 「기체 상태」 오락실 제보로 보낸다. 제보만 실패하면 다시 저장할 때 제보만 보낸다.

### 하지 않는 것

- 상세에 모름 개수 · 출처 · 갱신 줄을 두지 않는다.
- 상세에 구역 칩 줄을 두지 않는다.
- 지도 화면에 사이트 푸터 · 출처 글자를 두지 않는다.
- 위치를 고를 때 확인 버튼 · 방식 고르기를 두지 않는다.
- 시트 · 패널 머리에 개수 문장을 두지 않는다.
