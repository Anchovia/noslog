# 관리자 공지 작성

주소 `/admin/announcements/new` · `/admin/announcements/[id]` · 코드 `features/announcements/components`(`announcement-editor` · `tier-rebalance-image-builder` · `tier-change-image-builder`)

## 구성

### 편집 화면

| 순서 | 내용                                                                                 |
| ---- | ------------------------------------------------------------------------------------ |
| 1    | 언어 1단 탭(`AreaTabs`, [탭](../components/tabs.md)). 오류가 난 언어 탭 글자 뒤에 점 |
| 2    | 제목                                                                                 |
| 3    | 본문 `MarkdownEditor`([마크다운 입력](../components/markdown-editor.md))             |
| 4    | 펼침 칸 「서열 변경 이미지」 · 「서열 전체 재배치 요약 이미지」(아래 두 절)          |
| 5    | 글에 딸린 투표 구역([투표](../components/poll.md))                                   |
| 6    | 아래 바                                                                              |

분류 · 종류 · 노출 기간 · 우선순위 · 공개 주소는 편집 화면에 두지 않고 「게시」 를 누르면 뜨는 창에 넣는다.
창은 672 이상에서 기본 크기(600) 창, 좁은 폭(672 미만)에서 전체 화면이다([대화상자](../components/dialog.md)).

아래 바 왼쪽에는 고스트 「나가기」 · 「삭제」 · 「공개 페이지」, 오른쪽에는 저장 상태 · 보조 「임시저장」 · 주 「게시」 를 둔다([마크다운 입력 — 아래 고정 바](../components/markdown-editor.md#아래-고정-바)).
공개 중인 글이면 「임시저장」 이 「비공개로 전환」, 「게시」 가 「업데이트」 가 된다.

### 전체 재배치 요약 이미지

공지 편집기의 따로 된 펼침 칸에서 만든다.

- 날짜와 서열표마다 채보 수를 넣고, 네 서열표마다 변경 수 · 신규 수 · 구간별 최대 채보 수(전 · 후)를 넣는다.
- 합계와 유지 수는 계산해서 채운다. 네 표가 같은 채보 묶음이라고 보고, 서로 맞지 않는 입력은 받지 않는다.
- 이미지는 정해진 PNG 양식이다. 1200 × 960, 원본 팔레트, Pretendard JP, 한글 제목과 라벨을 쓴다.
- 네 줄에 서열표마다 변경 수 · 신규 수 · 구간별 최대 채보 수의 전후 비교를 보여 준다.
- 그림은 한글판 하나를 모든 언어에 쓰고, 대체 설명은 한국어 · 일본어 · 영어로 붙인다.
- 이번 재배치 수치는 버튼으로 직접 불러온다. 다음 공지에 저절로 들어가지 않는다.
- 전체 곡 내역은 CSV 파일로 안내한다([전체 변경 파일](../../ui/tier-change-images.md#대규모-재배치의-전체-변경-파일)).

### 서열 변경 공지 이미지

공지 편집기에 기존 펼침 부품으로 「서열 변경 이미지」 칸을 둔다. 순서는 이렇다.

1. 모드 · 목표 · 날짜를 고른다.
2. 곡을 검색해 넣고 난이도와 전후 값을 적는다.
3. 브라우저 안에서 미리보기를 만든다.
4. 지금 언어의 본문 끝에 붙인다.

이미지는 2026-09 서열 변경 공지 양식을 그대로 따른다.

- 폭 1200, 바탕 #111.
- 제목, 날짜와 곡 수.
- 올라간 곡 묶음 다음에 내려간 곡 묶음, 사이에 구분선.
- 줄마다 곡 이름 · 난이도 · 레벨, 전후 값(소수 한 자리) · 화살표 · 분홍색 새 값.
- 끝에 NosLog 표기.
- 두 곡짜리 예시는 1200 × 706이다. 긴 제목은 줄바꿈하고 그만큼 높이를 늘린다.

이미지 안의 고정 크기 · 색은 그림 양식의 값이다. 화면 토큰으로 더하지 않는다.
쓰는 법과 검증은 [서열 변경 공지 이미지](../../ui/tier-change-images.md)를 따른다.

## 동작

- 저장할 때 오류가 있으면 그 자리로 데려간다. 번역 칸의 오류면 창을 닫고 그 언어 탭을 연다. 창 안 칸의 오류면 창을 연다.
- 공개 주소가 비어 있으면 저장할 때 제목으로 만든다.
- 두 이미지 칸 모두 미리보기는 브라우저 안에서만 만들고, 본문에는 첨부 버튼을 눌렀을 때만 붙인다.
- 두 생성기는 동시에 돌지 않게 서로 막는다.
- 첨부는 시작한 언어의 가장 최근 본문에 붙인다. 올리는 동안 쓴 글이나 다른 언어 본문을 덮어쓰지 않는다.
- 이미지를 올리는 동안에는 공지 저장을 막는다.
- 이미지 칸은 공지 게시 · 저장, 서열 데이터와 따로 움직인다. 이미지를 붙여도 서열표는 바뀌지 않는다.
