# 가입 온보딩 · 로그인

주소 `/onboarding` · `/login` · 코드 `features/auth/components` · `features/profile/components/onboarding-form.tsx` · `onboarding-form-view.tsx`

## 구성

### 로그인

| 순서 | 내용                                                                                          |
| ---- | --------------------------------------------------------------------------------------------- |
| 1    | 제목 「NosLog」 `page-title` · 부제                                                           |
| 2    | (돌아갈 화면이 있을 때) 「로그인하면 ○○ 화면으로 돌아갑니다」 `body-secondary` 흐림           |
| 3    | 「Discord로 계속하기」                                                                        |
| 4    | (오류가 있을 때) 오류 글자 한 줄. 아이콘 없이 `body-secondary` 오류색(`feedback/destructive`) |
| 5    | 「로그인 없이 둘러보기」 글자 링크                                                            |

제목에 `display` 글자는 쓰지 않는다. 오류 줄은 「Discord로 계속하기」 바로 아래에 둔다([상태 메시지](../components/status-message.md)).

화면 아래(로그인 · 동의)에는 개인정보처리방침 안내 한 줄 `metadata` 흐림(글 안 링크는 밑줄)과 언어 `CompactSelect`(면 없는 기본)를 사이 12 로 가운데에 둔다. 가입 온보딩은 언어만 둔다. 언어를 바꾸지 못하면 그 아래 오류 한 줄(`StatusMessage`)이다.

### 가입 온보딩

두 단계다. 저장은 2단계에서 한 번만 한다.

1단계 프로필

| 순서 | 내용                                                                                 |
| ---- | ------------------------------------------------------------------------------------ |
| 1    | NosLog · 제목 「프로필 설정」                                                        |
| 2    | 「1 / 2 · 프로필」 `metadata`                                                        |
| 3    | (돌아갈 화면이 있을 때) 그 화면을 쓰려면 설정을 마치라는 한 줄 `body-secondary` 흐림 |
| 4    | 연결된 로그인 계정                                                                   |
| 5    | 닉네임                                                                               |
| 6    | 국가                                                                                 |
| 7    | 「다음」                                                                             |

2단계 공개 설정

| 순서 | 내용                         |
| ---- | ---------------------------- |
| 1    | 제목 「공개 설정」           |
| 2    | 「2 / 2 · 공개 설정」        |
| 3    | 안내                         |
| 4    | 체크박스 6개                 |
| 5    | 「계정 설정 완료」 →12→      |
| 6    | 「이전」. 보조 버튼, 폭 가득 |

칸 · 체크박스 모양은 [입력](../components/field.md) · [폼 조작](../components/form-controls.md)을 따른다.
온보딩 그릇은 `--nl-container-narrow` 폭에 위 48 · 아래 24 다. 제목 · 설명 끝 → 첫 내용은 16 이다(2단계도 같다, [기초값 — 간격](../foundations.md#간격)). 닉네임 설명은 칸 →8→ 아래에 둔다.
두 단계 모두 폼 아래 →16→ 「로그아웃하고 둘러보기」 글자 버튼을 둔다.

## 상태

- 닉네임은 칸을 떠날 때 쓸 수 있는지 확인한다. 쓸 수 있으면 `FormField success`(성공 표시색), 아니면 칸 오류로 알린다.
- 2단계에서 저장할 때 1단계 칸의 오류가 돌아오면 1단계로 돌아가 그 칸에 포커스를 둔다.

## 동작

- 단계를 옮기면 그 단계 제목에 포커스를 둔다.
- 국가는 미리 고르지 않는다.
