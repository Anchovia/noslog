# 검정

주소 `/exams` · `/exams/{slug}` · 코드 `features/exams/components`(`exam-page.tsx` · `exam-navigation.tsx` · `exam-stages.tsx` · `exam-practice.tsx` · `exam-proof-upload.tsx` · `exam-dashboard.tsx` · `exam-status.tsx`)

## 구성

위에서부터 페이지 제목 · 종류 · 급 · 급 머리 · 과제곡 · 합격까지 · 합격 인증이다. 제목 아래 설명 줄은 두지 않는다.

### 종류 · 급 고르기

종류는 세그먼트(Basic · Recital · Event)다(→ [세그먼트](../components/segmented-control.md)). 세그먼트 →32→ 급 고르기이고 1056 이상은 16 이다. 구역 사이가 아니라 한 묶음 안의 간격이다.
급은 좁은 폭 · 중간 폭에서 셀렉트, 넓은 폭(1056 이상)에서 레일이다. 레일 폭은 [악곡 목록](./music-list.md)과 같은 1/4 이다.
셀렉트 목록 줄 · 레일 줄은 높이 L 이고 「급 · 상태」 두 칸이다(명판 없음). 셀렉트 트리거는 급만 보인다. 고른 급의 상태는 급 머리 태그가 말한다.
셀렉트 위 칸 라벨 「검정 선택」 은 `control` 흐림이고 라벨 → 셀렉트 4 다.
셀렉트 목록은 메뉴 한 모양에서 오른쪽 체크 대신 상태 칸을 두는 변형이다. 판 폭은 트리거 폭이고, 고른 줄은 [메뉴](../components/menu.md) 고른 항목과 같은 `surface/control` 면 · 600 이다. 키로 옮긴 줄은 [메뉴](../components/menu.md) 항목과 같다.
레일 줄은 메뉴 항목 모양이다. 글자 medium 이고, 올림 · 누름 · 키 포커스 때 면 `surface/control-hover` · 글자 `content/strong` 이다. 고른 줄은 셀렉트 목록과 같은 `surface/control` 면 · 600 이다.
처음 여는 급은 그 종류에서 합격하지 않았고 응시할 수 있는 가장 낮은 급이다. 없으면 합격하지 않은 가장 낮은 급, 그것도 없으면 맨 끝 급이다.

| 상태                       | 표시                                                                      |
| -------------------------- | ------------------------------------------------------------------------- |
| 합격                       | 체크 16(성공 표시색) + 흐린 글자                                          |
| Grd. 부족                  | 자물쇠 16 + 흐린 글자                                                     |
| 응시 가능 · 심사 중 · 반려 | 상태 점 8(성공 · 경고 · 위험, → [태그](../components/tag.md)) + 기본 글자 |
| 데이터 동기화 필요         | 흐린 글자만                                                               |

로그아웃 · Event 는 상태가 없다. Event 는 셀렉트 위에 「참고용」 한 줄을 둔다.

### 급 머리

제목 `section-title` + 상태 태그 →`--nl-section-title-gap`→ 수치 띠(→ [수치 띠](../components/stat-strip.md))다.
상태 태그는 [상태 태그](../components/tag.md#상태-태그)(`nl-tag--status`)이고 아이콘 · 점 없이 글자만이다. 합격 · 응시 가능은 성공, 심사 중은 경고, 반려는 위험 표시색이고 Grd. 부족 · 데이터 동기화 필요는 기본 글자색이다. Grd. 부족은 모자란 값까지 쓴다.
수치 띠는 요구 Grd. · 검정료 · 합격 보상이다. 요구 Grd. 가 없는 검정은 그 칸을 만들지 않는다.
요구 Grd. 를 넘었으면 값을 합격 체크와 같은 `feedback/success-marker` 로 쓴다. 라벨에 내 값을 넣지 않는다.
합격 보상이 칭호면 검정 명판 풀 이름형(「BASIC | 2급」)으로 보인다. 칭호가 아닌 보상(곡 해금 등)은 띠 칸에 넣지 않고 띠 아래 한 줄 「합격 보상 · …」(`body-secondary` 흐림)로 쓴다.
Recital 은 급 머리 아래에 채점 방식 한 줄(`body-secondary` 흐림)을 둔다.

### 과제곡

과제곡 곡 카드 사이에 통과선 줄을 둔다.

곡 카드는 자켓 · 순서 · 난이도 · 곡 이름 · 오른쪽 내 베스트다. 카드는 면 `surface/surface` · 둘레 없음 · 그림자 `--nl-card-shadow` · 모서리 `radius/large` 이고, 자켓 왼쪽 모서리도 `radius/large` 다. 누를 수 있는 카드만 올리면 `interaction/row` 를 겹친다.
난이도 줄 · 곡 이름 줄은 한 줄이고 넘치면 끝 페이드라, 카드 높이는 자켓 64 다.
내 베스트 숫자는 그 아래 통과선 기준으로 색을 입힌다. 통과는 `feedback/success-marker` 초록, 미달은 `feedback/info-marker` 파랑이다. 기록이 없으면 값 자리만 흐린 「—」 다.

통과선 줄은 M 높이다. 자켓 가운데를 지나는 1px 세로선 위에 ✓/✗ 16 을 두고(✓ 성공 · ✗ 위험 표시색), 합격선 글자를 `metadata` 로 쓴다(「1st 925,000」 · 「누적 1,875,000」).
누적은 앞 곡 기록이 모두 있어야 비교한다. 없으면 합격선만 쓴다.

### 합격까지

로그인한 점수형 검정에만 둔다. 누르지 않는 묶음 상자(면 `surface/surface` · 둘레 없음 · `--nl-card-shadow` · 모서리 `radius/large` · 안쪽 16 · 사이 12)다.

| 자리        | 내용                                                                                                                                                                    |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 제목        | 「합격까지 N점」(기록이 모자라면 「합격까지」, 넘으면 「합격이 가능합니다」) + 오른쪽 「베스트 기준」(`metadata` 흐림)                                                  |
| 막대        | 진행 막대 트랙([그래프](../components/charts.md#진행-막대)) 위에 곡별 베스트 조각(`nl-chart-reveal` · `nl-chart-bar`). 차트 범주 색을 곡 순서대로 1부터, 조각 사이 2 틈 |
| 합격선 눈금 | 2 × 16 기본 글자색                                                                                                                                                      |
| 눈금 아래   | 「N차 / 합격」 + 그 합격선 대비 여유(±). 모두 눈금 왼쪽에 오른쪽 맞춤                                                                                                   |
| 범례        | 「색 · 곡 · 베스트 점수」 늘 둔다. 기록이 없는 곡은 흐린 「—」                                                                                                          |
| 아래        | 합격선 아래면 「먼저 연습할 곡 · 곡 · 연습 기준까지 N점」, 그 아래 베스트 한계 안내 한 줄은 늘 둔다(둘 다 `metadata` 흐림, 아이콘 없음)                                 |

여유(±) 색은 내 베스트와 같은 초록 · 파랑이다. 비교하지 못하면 여유 대신 합격선 값을 쓴다.

### 합격 인증

위에서부터 구역 제목 · 안내 한 줄 · 찍을 것 다섯 줄 · 주 버튼 L(카메라 20)이다.
찍을 것 다섯 줄은 번호 목록(`1.` ~ `5.` 글자 번호, 들여쓰기 24)이고, 사진을 고르기 전부터 보인다.
사진을 고르면 미리보기 · 파일 정보 · 보관 기간 · 이름 동기화 안내(각 `metadata` 흐림 한 줄) · 「제출」 주 버튼 · 「교체 · 취소」 보조 버튼 두 칸이 사이 12 로 이어진다.
반려된 급은 찍을 것 아래에 상태 메시지(위험)로 「인증이 반려되었습니다.」 + 반려 사유를 둔다.
합격한 급과 자격이 없는 급(Grd. 부족 · 데이터 동기화 필요)에는 인증 구역이 없다. 설명 문장 · 동기화 버튼도 두지 않는다. 상태는 머리 태그가 말한다.

## 폭별

좁은 폭 · 중간 폭(1055 이하)은 급을 셀렉트로 고르고 위 「구성」 순서대로 한 열이다.

넓은 폭(1056 이상)은 급을 레일로 고른다.
합격 인증은 합격까지와 두 열로 같은 상자에 놓는다. 상자 안이라 제목도 상자 제목(`component-title`) → 내용 8 이다.

## 상태

로그아웃이면 급 상태 · 합격까지가 없고, 합격 인증은 제목 줄 오른쪽 끝 제목 링크 「로그인하고 인증하기 ›」 하나다([패턴 — 로그아웃 상태](../patterns.md#로그아웃-상태)).
인증 결과는 상태 메시지 `inline` 글자로 보인다(→ [상태 메시지](../components/status-message.md)). 완료는 성공, 심사 중은 안내, 실패는 오류다.

## 하지 않는 것

통과선 줄에 여유 숫자를 두지 않는다.
급 셀렉트 목록 · 레일 줄에 명판을 두지 않는다.
수치 띠 요구 Grd. 라벨에 내 값을 넣지 않는다.
