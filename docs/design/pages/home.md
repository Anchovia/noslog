# 홈

주소 `/` · 코드 `features/home/components`(홈 전용 UI 는 여기에 둔다)

## 구성

검색 · 목적지 · 공지 · 공식 소식은 안쪽 최대 `--nl-container-compact`(640) 안에 둔다.

| 순서 | 자리                                                                                          | 다음 자리까지              |
| ---- | --------------------------------------------------------------------------------------------- | -------------------------- |
| 1    | 머리 — 고양이 원 아이콘(→ [foundations](../foundations.md)) →12→ 이름 「NosLog」 →8→ 태그라인 | 태그라인 →24→ 검색         |
| 2    | 검색                                                                                          | 검색 →16→ 목적지 타일      |
| 3    | 목적지 타일                                                                                   | 목적지 →48→ 새 소식        |
| 4    | 새 소식 — 공지 · 진행 중인 이벤트 · 공식 소식                                                 | 셋 사이 `--nl-section-gap` |

검색과 목적지 타일은 한 묶음이다. 새 소식은 다른 덩어리라 48 떨어진다.
새 소식 구역의 제목 → 내용은 `--nl-section-title-gap` 이다.

머리의 이름 「NosLog」 은 사이트 글꼴 글자로 쓰고 `page-title` 이다. 그 위 고양이 원 아이콘은 40 이다.
이름 아래 태그라인은 페이지 머리 설명이라 `nl-metadata` 흐림이다([패턴 — 제목](../patterns.md#제목)).

### 공지

홈 공지 줄은 공지 목록 줄과 같은 부품이다(→ [소식](./news.md)). 제목은 목록과 같은 16/600 이다.
줄은 3개까지다. 활성 중대 공지(고정 줄)가 먼저 오고, 나머지는 최근 공지로 채운다. 공지가 하나도 없으면 공지 구역을 두지 않는다.
고정 줄은 면 없이 날짜 앞에 핀 16 을 둔다. 홈 공지 카드는 제목 굵기 · 고정 표시를 바꾸지 않는다.
홈 공지 줄은 폭과 상관없이 「분류 태그 →12→ 제목 →12→ 날짜」 한 줄이다. 좁은 폭(672 미만)에서도 두 줄로 나누지 않고, 제목이 넘치면 한 줄에서 말줄임(…)으로 자른다.

### 진행 중인 이벤트

공지 바로 아래에 둔다. 이벤트로 가는 길이라 늘 보인다.
진행 중인 이벤트가 있으면 끝나는 순으로 2장을 보인다.

카드는 큰 배너 카드다. 한 덩어리로 누르는 카드라 [면 카드](../components/surface-card.md#면-카드)와 같은 면 · 그림자 · 모서리를 쓰고 둘레는 없다. 비율 2.4 : 1 · 카드 사이 8. 배너가 없으면 같은 비율의 빈 카드 면이다.
배너 위에 제목 `entity-title` · 기간 `body-secondary` 를 흰 글자(`content/on-media`)로 얹는다.
글자 자리는 `surface/media-scrim` 층을 깔고, 층의 위 32 는 투명에서 번진다.

진행 중인 이벤트가 없으면 안내 한 줄(`body-secondary` 흐림)만 둔다.
진행 중인 이벤트를 불러오지 못하면 빈 안내와 구별해 소식 상태 상자에 「진행 중인 이벤트를 불러오지 못했습니다.」 를 둔다.

### 공식 소식

준비된 원문 · 번역만 읽고, 수집 · 번역을 기다리지 않는다. 수집 동작은 [기능 규칙](../product-rules.md#공식-x-소식)을 따른다.

소식 카드는 [면 카드](../components/surface-card.md#면-카드)의 한 단계 면이다. 면 `surface/surface` · 둘레 · 그림자 없음 · 모서리 `radius/control` 이다. 소식 상태 상자도 이 카드 자리를 대신하므로 같은 면이다.

## 폭별

모든 폭에서 위 묶음과 안쪽 최대 폭이 같다.
푸터는 840 이상에서 한 줄, 그 아래 폭에서는 가운데로 쌓는다.

## 상태

진행 중인 이벤트가 없을 때는 위 「진행 중인 이벤트」 의 안내 한 줄, 불러오지 못했을 때는 소식 상태 상자다.

## 하지 않는 것

홈 맨 위에 중대 공지 배너를 두지 않는다. 같은 글이 공지 목록 맨 위 고정과 두 번 나오게 된다.
이벤트가 없을 때 빈 상자나 「이벤트 글쓰기」 링크를 두지 않는다. 제목 줄 「전체 이벤트 ›」 와 겹친다.
