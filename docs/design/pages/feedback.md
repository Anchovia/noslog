# 피드백 · 오류 제보 창

주소 없음(메뉴 「피드백」 줄에서 여는 창) · 코드 `features/feedback`

창 규격은 폼 창을 따른다([대화상자](../components/dialog.md)).

## 구성

로그인했을 때 창 안에 1단 밑줄 탭 「새로 쓰기 · 내 제보」(`AreaTabs`, [탭](../components/tabs.md))를 둔다. 탭 →24→ 폼 또는 내 제보 목록.

### 새로 쓰기

| 순서 | 칸                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------ |
| 1    | 종류. 셀렉트 L, 선택지 「오류 제보」 · 「제안 · 의견」([입력](../components/field.md))           |
| 2    | 내용. 입력칸 5줄, 자리표시자 없음. 아래 도움말 줄 왼쪽에 종류별 안내, 오른쪽에 「쓴 수 / 1,000」 |
| 3    | 이미지 「(선택)」. 보조 L 버튼([버튼](../components/button.md))                                  |

이미지를 붙이면 버튼 자리에 같은 높이의 파일 줄이 들어선다. 파일 줄은 썸네일(줄 높이 − 8) · 이름 · 크기 · 지우기 × 순서다.

### 내 제보

| 순서 | 내용                        |
| ---- | --------------------------- |
| 1    | 상태 태그 · 날짜 · 종류 →4→ |
| 2    | 내용 `body-secondary` →8→   |
| 3    | 답변 상자                   |

줄은 위아래 12 · 아래 1px `border/row` 다(첫 줄은 위 0).
상태 태그는 접수 = 경고, 처리 완료 = 성공이다([태그 — 상태 태그](../components/tag.md#상태-태그)).
답변 상자는 면 `surface` · 모서리 `radius/control` · 안쪽 12이다. 안은 「NosLog 답변 · 날짜」 `metadata` →4→ 답변.

내 제보 탭에는 발을 두지 않는다. 닫기는 머리 × 가 맡는다.

## 상태

- 로그아웃이면 탭이 없다. 로그아웃으로 열 때의 모양은 로그인 안내를 따른다([대화상자](../components/dialog.md)).
- 새 답변이 있으면 메뉴 「피드백」 줄과 「내 제보」 탭 글자 뒤에 점 8을 붙인다. 위험 표시색이고 접근 이름은 「새 답변」 이다(`nl-unread-dot`).
- 보낸 뒤에는 창 안에 결과 한 줄 · 설명과 「닫기」 를 둔다. 체크 표시 없이 글자만 쓴다([상태 메시지](../components/status-message.md)).
