# 업적

주소 `/profile/[id]/achievements` · 고르기는 `/settings?category=profile` · 코드 `features/achievements` · `features/profile/components/pinned-records-picker.tsx`

## 구성

### 업적 그림

그림은 육각 안의 Lucide 아이콘이다. 업적마다 하나씩 `ACHIEVEMENT_ICONS` 에 둔다.

등급은 다섯이다. 업적마다 가진 등급이 다르다(다섯 모두 · 동 · 은 · 금 셋만 · 다이아 하나만). 알약 숫자는 로마 숫자로 등급을 뜻한다.

| 등급     | 숫자 | 색                                     |
| -------- | ---- | -------------------------------------- |
| 동       | I    | `exam/tier-mid`(검정 명판 금속 사다리) |
| 은       | II   | `exam/tier-high`                       |
| 금       | III  | `exam/tier-top`                        |
| 플래티넘 | IV   | `judgement/good`(청록)                 |
| 다이아   | V    | `judgement/s-just`(분홍)               |

테두리는 그 등급 색이다. 못 얻은 업적은 `border/row` 선에 `content/subdued` 그림 · 이름이다.
조건은 늘 공개하고 숨긴 업적은 없다.

크기는 세 단계다.

| 단계      | 육각    | 선                    | 그림 | 숫자 알약                                                  |
| --------- | ------- | --------------------- | ---- | ---------------------------------------------------------- |
| 목록      | 44 × 48 | `--nl-stroke-strong`  | 24   | 오른쪽 아래 16. 금속 면 + `surface/canvas` 글자 `metadata` |
| 한 줄     | 22 × 24 | `--nl-stroke-default` | 16   | 없음. 이름은 접근 이름과 `title` 로만 둔다                 |
| 정보 카드 | 58 × 64 | `--nl-stroke-strong`  | 32   | 없음                                                       |

### 프로필 머리

명판 · 기여 라벨 뒤에 한 줄 육각 3개만 이어서 둔다. 설정에서 고른 것이고, 고른 것이 없으면 높은 단계 순, 같으면 달성 인원이 적은 순으로 자동으로 고른다. 개수 글자는 없다.
명판 줄이기 폭 계산에는 넣지 않고, 넘치면 다음 줄로 간다([프로필 › 머리](./profile.md#머리)).

배지마다 올리거나 누르면 정보 카드가 열린다. 동작은 기여 라벨과 같은 `TermHelp plain` 이고, 창 안은 `content` 다([도움말](../components/help.md)).
카드는 [떠 있는 창](../foundations.md#떠-있는-창) 모양이고, 폭 240 · 안쪽 16 · 가운데 정렬이다.

| 순서 | 내용                                      |
| ---- | ----------------------------------------- |
| 1    | 분류 `metadata` →8→                       |
| 2    | 큰 육각 58 × 64(숫자 알약 없음) →8→       |
| 3    | 「이름 III」 `component-title` →8→        |
| 4    | 조건 `body-secondary`                     |
| 5    | 구분선 `border/divider`. 창 끝까지 긋는다 |
| 6    | 「N명 달성」 · 「날짜 달성」 `metadata`   |

업적 탭의 입구는 프로필 「업적」 구역 제목 줄의 링크다.

### 프로필 「업적」 구역

개요 옆 열에서 기여 위에 둔다. 좁은 폭에서도 기여 위다([프로필 › 폭별](./profile.md#폭별)).

| 순서 | 내용                                                                    |
| ---- | ----------------------------------------------------------------------- |
| 1    | 구역 제목 + 오른쪽 「얻은 수 / 전체 ›」(`nl-heading-link`, 업적 탭으로) |
| 2    | 얻은 업적 육각 44 × 48 한 줄 →12→                                       |
| 3    | 「최근 달성 · 이름 III」 `metadata` 한 줄(가장 최근 하나)               |

- 구역 제목과 육각 줄 사이는 `--nl-section-title-gap` 이다.
- 육각 줄은 늘 한 줄이다. 높은 단계 순, 같으면 최근 순으로 구역 폭에 들어가는 만큼 둔다. 폭 356 이면 7칸, 408 이면 8칸이다.
- 더 있으면 마지막 칸이 「⋯」(아이콘 20, 면 없는 고스트, `content/default`)이고, 누르면 업적 탭으로 간다. 올림 · 누름 · 키 포커스는 [고스트 버튼](../components/button.md)과 같다.

### 업적 탭

프로필 머리 · 구역 탭 아래에 둔다. 돌아가기와 페이지 제목은 없다.

| 순서 | 내용                                                                                               |
| ---- | -------------------------------------------------------------------------------------------------- |
| 1    | 구역 제목 「업적 n / N」 `section-title`(다른 탭 첫 제목과 같음)                                   |
| 2    | 분류 칩 한 줄 `FilterChips row`. 칸마다 얻은 단계 / 전체 →12→                                      |
| 3    | 결과 줄. 왼쪽 정렬 `SortMenu` 고스트, 오른쪽 보기 전환 `SegmentedControl`(목록 · 촘촘한 격자) →12→ |
| 4    | 목록 또는 촘촘한 격자                                                                              |

- 제목과 분류 칩 사이는 `--nl-section-title-gap` 이다.
- 결과 줄은 악곡 · 서열표와 같은 문법이다. 좁은 폭 · 중간 폭은 M, 넓은 폭은 L([필터](../components/filter.md) · [세그먼트](../components/segmented-control.md)).
- 보기는 목록과 촘촘한 격자 둘이다. 일반 격자는 없다.

정렬은 분류 순(기본) · 높은 등급 순 · 최근 달성 순 · 희귀한 순 · 다음 단계에 가까운 순(본인만)이다. 희귀한 순은 얻은 등급의 달성 인원이 적은 순이다. 못 얻은 업적은 늘 뒤로 보낸다.

목록 줄은 `border/row` 선 목록이다. 한 열 목록 줄과 같은 글자를 쓴다.

| 자리   | 내용                                                                                                                              |
| ------ | --------------------------------------------------------------------------------------------------------------------------------- |
| 왼쪽   | 육각 44 × 48 →12→                                                                                                                 |
| 가운데 | 이름 `entity-title`. 상태 글자는 없다                                                                                             |
|        | 조건 줄 `body-secondary` 흐림. 본인은 다음 단계 조건 「현재 / 목표」, 남의 프로필은 얻은 단계 조건 · 달성일                       |
|        | (본인) 진행 막대([그래프](../components/charts.md#진행-막대)), 채움은 쫓는 다음 등급의 색, 그래프 움직임(드러남 · 옮겨 감)을 탄다 |
| 오른쪽 | 펼침 화살표(그림만)                                                                                                               |

머리 줄 전체(육각 · 이름 · 조건 · 막대 · 화살표)가 하나의 펼침 단추다. 올림 · 포커스는 [펼침](../components/disclosure.md) 줄과 같고, 펼친 사다리를 눌러도 접히지 않는다.

펼치면 단계 사다리가 열린다. 단계마다 한 줄 육각 · 「I · 조건」 · 달성일 또는 (본인) 진행 · 「N명 달성」 을 둔다. 달성한 사람 명단은 없다.

촘촘한 격자는 육각 44 × 48 만 놓는다. 줄 사이 12 · 칸 사이 8.
누르거나 올리면 머리와 같은 정보 카드가 열린다. 못 얻은 업적은 첫 단계 조건을 보인다.

### 진열 고르기

설정 「프로필」 분류에서 선호 오락실 칸 아래에 「프로필 업적」 칸을 둔다. 선호 오락실 칸과 같은 모양이다([설정](./settings.md)).

- 값 자리에 한 줄 육각 3개를 둔다. 고른 것이 없으면 높은 단계 순으로 자동으로 채우고 글자 설명은 달지 않는다.
- 오른쪽에 보조 「변경」 을 둔다.
- 아래 도움말 한 줄은 「프로필에 3개까지 전시 가능합니다.」 다.

「변경」 을 누르면 설정 창과 같은 부품의 창이 열린다([대화상자](../components/dialog.md)).

| 순서 | 내용                                            |
| ---- | ----------------------------------------------- |
| 1    | 고른 3칸(고른 순서). 빈 칸은 `border/ring` →16→ |
| 2    | 소제목 「얻은 업적」 →8→                        |
| 3    | 격자. 칸 = 육각 44 × 48 + 이름                  |
| 발   | 보조 「자동으로」 + 주 「적용」                 |

- 격자 칸은 최소 88 · 사이 8, 칸 안쪽 12 / 4 다.
- 칸은 적용 조건 알약과 같은 `surface/canvas` 면 + `border/input` 선, 고른 칸은 `surface/control` 면 · 선 없음이다. 올림 · 누름 · 키 포커스는 면 `surface/control-hover` · 글자 `content/strong` 이다.
- 3칸이 차면 나머지 칸은 비활성이다. 그림을 품은 칸이라 선을 빼고 칸 전체를 `--nl-disabled-opacity` 로 흐린다.
- 얻은 업적이 없으면 값 자리에 「아직 얻은 업적이 없습니다」 를 쓰고 「변경」 을 두지 않는다.
- 「적용」 을 누르는 순간 저장된다(설정 프로필은 칸마다 바로 저장, [설정](./settings.md#프로필)).

### 고정 기록 고르기

같은 분류의 「프로필 업적」 칸 아래에 「고정 기록」 칸을 둔다. 모양은 같다.

- 값 자리에 고른 곡 이름을 「 · 」 로 이어 쓴다. 고른 것이 없으면 비운다. 이때 프로필은 베스트 상위 3곡을 자동으로 보이고, 칸에 글자 설명은 달지 않는다.
- 오른쪽에 보조 「변경」 을 둔다.
- 아래 도움말 한 줄은 「프로필에 3개까지 고정 가능하며, 기록마다 소감을 적을 수 있습니다.」 다.

창

| 순서 | 내용                                                     |
| ---- | -------------------------------------------------------- |
| 1    | 고른 3칸 →16→                                            |
| 2    | (칸을 누르면) 그 곡의 소감 칸 →16→                       |
| 3    | 기록 찾기. 선호 오락실 창과 같은 검색칸 · 결과 수 · 목록 |
| 발   | 「초기화 · 적용」                                        |

- 칸은 고르기 창의 고른 것 칩이다([대화상자](../components/dialog.md)). 「n · 곡 이름」 · 난이도 레벨 `metadata`(난이도 글자색) · 빼기 × 이고 점수는 쓰지 않는다.
- 칩을 누르면 그 곡의 한 줄 소감 칸 하나가 아래에 열린다. 칸 라벨이 곡 이름이다. 소감은 80자까지, 선택이다.
- 목록 줄 이름은 모두 600(`emphasis-label`)이고, 고른 줄은 오른쪽 체크로 보인다. 3칸이 차면 나머지는 비활성이다.
- 「적용」 을 누르는 순간 저장된다.

### 동기화 결과

동기화 결과 수치 띠에 「새 업적」 칸을 둔다. 새 업적이 있을 때만이다([동기화](./sync.md)).
그 아래 한 줄에 「새 업적」 · 한 줄 육각 + 「이름 II」 3개까지 · 「외 N개」 · 「업적 보기」 밑줄 링크를 둔다.

## 폭별

- 결과 줄의 정렬 · 보기 전환은 좁은 폭 · 중간 폭 M, 넓은 폭(1056 이상) L 이다.
- 프로필 「업적」 구역의 육각 칸 수는 구역 폭에 따라 정해진다.

## 상태

- 점수 비공개 프로필을 남이 보면 실력 · 수집 · 곡 묶음 · 계절 업적은 머리 · 구역 · 업적 탭 어디에도 없다. 분모도 보이는 업적만 센다.
- 진행 값(진행 막대 · 다음 단계 조건 · 다음 단계에 가까운 순)은 본인에게만 보인다.
- 검정 업적과 한 곡을 S → 풀콤보 → Pianist 로 올리는 곡 묶음 업적은 「현재 / 목표」 숫자 없이 조건만 쓴다.
- 남의 프로필에서 얻은 업적이 없으면 「업적」 구역이 없다.

## 동작

- 배지 정보 카드는 올리거나 누르면 열린다. 여는 · 닫는 규칙은 [도움말](../components/help.md)을 따른다.
- 진행 막대는 그래프 움직임 `nl-chart-reveal` · `nl-chart-bar` 를 쓴다.

## 하지 않는 것

- 금 · 은 · 동 개수를 두지 않는다.
- 목록 줄에 핀 · 고르기 버튼을 두지 않는다. 고르기는 설정에서만 한다.
- 목록 줄 이름 옆에 상태 글자를 두지 않는다.
- 머리 배지 줄에 개수 글자를 두지 않는다.
