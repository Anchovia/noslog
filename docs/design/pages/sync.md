# 데이터 동기화

주소 `/bookmarklet` · 코드 `features/sync`

## 구성

페이지는 읽기 폭 768 에 가운데 정렬이다(`PageContainer width="reading"`).

### 로그인했을 때

| 순서 | 내용                     |
| ---- | ------------------------ |
| 1    | 1단계 설치               |
| 2    | 2단계 공식 사이트 로그인 |
| 3    | 3단계 북마클릿 실행      |

- 단계마다 번호 원 24 를 단다. 숫자는 `emphasis-label` 이다.
- 단계의 예시 이미지는 펼침 안에 둔다. 예시 이미지 상자는 높이 64–240 이다.
- 결과와 도움말은 펼침이다([펼침](../components/disclosure.md)).
- 동기화 결과의 새 업적 칸 · 줄은 [업적 › 동기화 결과](./achievements.md#동기화-결과)를 따른다.

### 로그아웃일 때

「진행 과정」 구역에 세 단계를 상자 없는 세로 목록으로 보인다.

- 줄은 번호 원 24 →12→ 제목 `component-title` 이다. 줄 사이는 12.
- 번호 원은 테두리 `border/divider`, 숫자는 `emphasis-label` subdued 다. 로그인했을 때의 단계 번호 원과 크기 · 숫자 글자가 같다.

## 상태

최근 기록 연동은 Pass 여부와 관계없이 기존 프로필 · 악곡 · 서열 화면을 그대로 쓴다.

- 수집되지 않은 값은 「—」 로 쓴다.
- 연동 도움말에서 최근 플레이 누적과 전체 연동 보정을 설명한다.

## 하지 않는 것

- 점수별 출처 배지를 두지 않는다.

## 부품 고유 크기

| 이름             | 값     | 쓰는 곳                                              |
| ---------------- | ------ | ---------------------------------------------------- |
| 예시 이미지 상자 | 64–240 | 동기화 단계 예시 이미지                              |
