# 데이터 동기화

주소 `/bookmarklet` · 코드 `features/sync`

## 구성

페이지는 읽기 폭 768 에 가운데 정렬이다(`PageContainer width="reading"`).

### 로그인했을 때

설치 단계는 세 장이다.

| 순서 | 내용                     |
| ---- | ------------------------ |
| 1    | 1단계 설치               |
| 2    | 2단계 공식 사이트 로그인 |
| 3    | 3단계 북마클릿 실행      |

- 단계 하나는 누르지 않는 묶음 상자다. 면 `surface/surface` · 둘레 없음 · 그림자 `--nl-card-shadow` · 모서리 `radius/large` · 안쪽 16(1056 이상 24)이다. 카드 사이는 16.
- 672 이상에서는 번호 원 칸 24 →16→ 내용 두 칸이다. 672 미만에서는 번호 원이 카드 왼쪽 위(안쪽 16)에 붙고, 단계 제목이 원 24 + 12 만큼 들여 쓴다.
- 단계마다 번호 원 24 를 단다. 면은 `primary/default`, 숫자는 `emphasis-label` · `on-primary` 다.
- 단계 제목 `component-title` →8→ 내용이고, 내용끼리는 16 이다.
- 단계의 예시 이미지는 펼침 안에 둔다. 예시 이미지 상자는 높이 64–240 · `surface/canvas` 면 · 1px `border/divider` · `radius/control` 이고, 올리면 경계가 `border/ring` 이다. 누르면 큰 창(`size="large"`)으로 연다.
- 「북마클릿 주소 복사」 는 누르면 글자가 2초 「복사됨」 이다. 설치 카드의 북마클릿 버튼은 끌어서 북마크로 만드는 대상이라 글자가 북마크 이름이 되므로, 눌러 복사했을 때 글자를 바꾸지 않고 토스트로 알린다.
- 결과와 도움말은 펼침이다([펼침](../components/disclosure.md)).
- 동기화 결과의 새 업적 칸 · 줄은 [업적 › 동기화 결과](./achievements.md#동기화-결과)를 따른다.

첫 사용이면 제목 → 「처음 동기화하기」(`section-title` →8→ 설명 `body` 흐림) → 단계 세 장이고, 두 번째 칸에 「제한 사항」 · 「도움말 · 보안」 이 온다.

다시 온 사용자는 위에서 아래로 이렇다.

| 순서 | 내용                                                                                                                                              |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 「북마클릿 등록」 펼침(안에 단계 세 장)                                                                                                           |
| 2    | 상태 줄(처리 중 · 지연 · 실패 · 시간 초과일 때만). 상태 `emphasis-label` · 시작 시각 흐림 → 주 버튼 「다시 동기화」(대기 중이면 비활성 + 남은 초) |
| 3    | 「최근 동기화 결과」 펼침. 범위 · 걸린 시간 → 결과 줄(확인한 최근 플레이 · 새로 저장된 플레이 · 갱신된 베스트 기록) · 일부 제외 안내              |
| 4    | 「이번에 달라진 기록」. 링크 줄 최대 3(곡 이름 · 점수 `metric-value` → 난이도 · 레벨 · 갱신 종류 `metadata` 흐림)                                 |
| 5    | 「동기화 이력」 펼침. 줄마다 시각 · 상태 → 범위 · 걸린 시간 · 라벨 붙은 숫자 셋(`metadata` 흐림, 항목 단위로 줄바꿈)                              |
| 6    | 「도움말 · 보안」 펼침. 보안 설명 → 보조 「기존 북마클릿 무효화」(확인 창의 확정만 채운 빨강)                                                     |

- 넓은 폭(1056 이상)에서 주 버튼은 내용 폭 · 왼쪽이다([버튼 — 크기](../components/button.md#크기)). 폰은 폭 가득.
- 「이번에 달라진 기록」 줄은 면 없는 구분선 목록 줄이라 올림은 좌우 12 를 넓혀 칠한다([기초값 — 올림](../foundations.md#올림--누름)).

### 로그아웃일 때

구성은 로그인 첫 사용과 같다. 제목 → 「처음 동기화하기」 → 단계 세 장이고, 두 번째 칸에 「제한 사항」 · 「보내는 정보」 가 온다.

- 1단계 설치 카드의 북마클릿 버튼 자리에 주 버튼 「로그인」 을, 드래그 안내 자리에 로그인 안내 한 줄을 둔다.
- 「북마클릿 주소 복사」 는 비활성이다.

## 상태

최근 기록 동기화는 Pass 여부와 관계없이 기존 프로필 · 악곡 · 서열 화면을 그대로 쓴다.

- 수집되지 않은 값은 「—」 로 쓴다.
- 동기화 도움말에서 최근 플레이 누적과 전체 동기화 보정을 설명한다.
- 화면 이름과 문구는 「데이터 동기화」 한 낱말로 부른다(「연동」 을 섞지 않는다).

## 하지 않는 것

- 점수별 출처 배지를 두지 않는다.
