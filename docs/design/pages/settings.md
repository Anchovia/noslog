# 설정

주소 `/settings`(분류 `?category=experience · profile · privacy · connections · account`, 연결 상세 `&partner=discord · musecat`) · 코드 `features/settings` · `features/partner/components/musecat-connection-settings.tsx`

## 구성

### 틀

왼쪽 분류 목록과 오른쪽 상세 두 칸이다. 1056 미만에서는 목록을 먼저 보이고, 분류를 누르면 상세로 간다.

- 1056 미만의 분류 목록 줄은 이름 `entity-title` →4→ 요약 `body-secondary` 흐림 · 오른쪽 꺾쇠, 줄 아래 1px `border/row`, 위아래 12 · 좌우 16 이다.
- 1056 이상의 분류는 레일 줄(컨트롤 높이 · 좌우 16 · `radius/control`)이다. 글자는 `control`, 지금 분류는 면 없이 `emphasis-label` 이다.
- 분류 줄의 올림은 지금 분류까지 모두 `interaction/row` 겹침이다.
- 로그아웃이면 분류는 화면 설정 하나만 보이고 자격 설명 문장은 두지 않는다([패턴 — 로그아웃 상태](../patterns.md#로그아웃-상태)).

### 줄 목록

상세는 줄 목록이다.

- 목록 위와 줄마다 아래에 1px `border/row` 를 긋는다.
- 줄 안쪽은 위아래 12 · 좌우 16 이다. 누르는 줄이든 아니든 목록의 모든 줄이 같아 글자 시작선이 한 줄로 맞는다.
- 줄 전체를 누르는 줄(회원 탈퇴 · Discord · 뮤즈캣 연결)은 올리면 줄 상자 전체에 `interaction/row` 를 겹친다. 면 = 줄 폭 = 구분선 폭이고 모서리 0 이다.
- 왼쪽에 라벨(`control`) →4→ 설명(`metadata` subdued), 오른쪽에 조작부를 둔다. 사이는 16.
- 글 입력칸(닉네임)만 라벨을 위에 둔다.

### 화면 설정

화면 설정과 국가/지역은 줄 오른쪽 `CompactSelect outlined` 다([입력](../components/field.md)).

### 프로필

칸마다 바로 저장한다.

- 선호 오락실 · 업적 · 고정 기록 · 사진은 고르거나 창에서 「적용」 하는 순간 저장한다.
- 국가/지역은 고르면 확인 창(제목 「국가/지역 변경」 · 랭킹 비교 대상이 바뀐다는 설명)이 먼저 뜬다. 발은 「취소 · 국가/지역 변경」 이고, 확정하면 저장한다. 취소하면 셀렉트로 포커스가 돌아간다.
- 닉네임만 바꿨을 때 칸 옆에 보조 L 「저장」 을 둔다. Enter 는 저장, Esc 는 되돌림이다. 나갈 때 확인 창은 이때만 띄운다.
- 실패하면 그 칸을 되돌린다. 닉네임은 쓴 글자를 남긴다.
- 저장 상태(저장 중 · 저장됨 · 실패 + 고스트 M 「다시 시도」)는 목록 아래 한 곳에 보인다([패턴 — 저장 방식](../patterns.md#저장-방식)). 「다시 시도」 는 네트워크 · 서버 문제로 실패한 칸만 같은 값을 다시 보낸다.
- 맨 아래는 「내 프로필 보기」 한 줄(글자 링크)이다.

「프로필 업적」 · 「고정 기록」 칸과 창은 [업적 › 진열 고르기](./achievements.md#진열-고르기) · [고정 기록 고르기](./achievements.md#고정-기록-고르기)를 따른다.

### 공개 설정

스위치 줄이다([폼 조작](../components/form-controls.md)).

- 누르면 바로 저장한다. 저장 버튼은 없고 한 번에 하나씩 저장한다.
- 실패하면 스위치를 되돌린다. 저장 상태는 프로필과 같이 목록 아래 한 곳이고, 실패하면 「다시 시도」 가 같은 스위치를 다시 보낸다.
- Discord 줄 라벨은 「Discord 태그 및 닉네임 공개」 다.
- 마지막 줄은 공개 설정이 아니라 동의인 「의견 · 답글 번역 허용」 이다. 처음 상태는 꺼짐이고, 아래에 Google 학습 이용과 끄면 번역도 지운다는 설명 한 줄을 둔다.

### 연결

| 순서 | 줄                                                                                                          |
| ---- | ----------------------------------------------------------------------------------------------------------- |
| 1    | Discord. 로고 원 40 · 「Discord」 · 「로그인 계정 · 표시 이름」 · 꺾쇠. 누르면 Discord 상세                 |
| 2    | 뮤즈캣([상태](#상태)). 로고 원 40 「M」 · 이름 · 「연결됨 · 계정 · 마지막 사용」 · 꺾쇠. 누르면 뮤즈캣 상세 |

### Discord 상세

뒤로 「‹ 연결」 만 설정 틀이 그린다. 나머지는 상세가 그린다.

| 순서 | 내용                                                                              |
| ---- | --------------------------------------------------------------------------------- |
| 1    | 로고 + 「Discord」 `section-title` + 연결 줄과 같은 메타 줄                       |
| 2    | 인증 오류 또는 완료 문장. 있을 때만                                               |
| 3    | 「NosLog 가 Discord 에서 쓰는 것」 [줄 목록](#줄-목록). 라벨만 둔다               |
| 4    | Discord 색 「Discord 정보 새로고침」 · 보조 「로그인 계정 변경」 위아래로 폭 가득 |

「로그인 계정 변경」 은 확인 창을 거친다. 로그인 계정이라 「연결 끊기」 는 없다.

### 뮤즈캣 상세

뒤로 「‹ 연결」 만 설정 틀이 그린다. 나머지는 상세가 그린다.

| 순서 | 내용                                                                                                                                    |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 로고 + 이름 `section-title` + 연결 줄과 같은 메타 줄                                                                                    |
| 2    | 상태 태그(글자만, 점 없음) + 한 줄 설명. 다시 연결 필요 · 해제 중 · 반영 중일 때만                                                      |
| 3    | 「뮤즈캣에 보내는 기록」 [줄 목록](#줄-목록). 오른쪽에 `content/default` 「보냄」, 또는 `content/subdued` 「안 보냄」(둘 다 `metadata`) |
| 4    | 공개 설정이 그대로 적용된다는 한 줄 `metadata` 흐림                                                                                     |
| 5    | 「보낼 항목 바꾸기」 폭 가득                                                                                                            |
| 6    | 구분선                                                                                                                                  |
| 7    | 「NosLog 가 뮤즈캣에서 쓰는 것」 [줄 목록](#줄-목록). 오른쪽에 「보기」 또는 「내 이름으로 올림」 `metadata` 흐림                       |
| 8    | 「다시 연결까지 n일」 `metadata` 흐림(다시 연결 필요면 그 자리에 「다시 연결 필요」 버튼 폭 가득)                                       |
| 9    | 구분선                                                                                                                                  |
| 10   | 「연결 끊기」 폭 가득                                                                                                                   |

연결이 하나도 없으면 1 아래에 설명 한 줄 `body-secondary` 흐림 →8→ 주 버튼 「뮤즈캣 연결」 폭 가득만 둔다. 뮤즈캣 계정만 없으면 7 자리에 보조 「뮤즈캣 연결」 폭 가득을 둔다.

「연결 끊기」 는 보조 버튼이다. 누르면 확인 창이 열리고, 창 안 확정 버튼만 채운 빨강이다([대화상자](../components/dialog.md) · [버튼](../components/button.md)).
상태 태그는 [태그](../components/tag.md)의 상태 태그다.

### 계정

| 순서 | 내용                                                          |
| ---- | ------------------------------------------------------------- |
| 1    | 보조 L 「로그아웃」(폰 폭 가득 · 1056 이상 내용 폭 · 왼쪽)    |
| 2    | 회원 탈퇴 줄([줄 목록](#줄-목록)). 설명이 달린 보통 줄에 꺾쇠 |
| 3    | 「개인정보처리방침」 글자 링크 `control`                      |

회원 탈퇴 줄을 누르면 탈퇴 창이 열린다. 창 모양은 [대화상자 › 창 안 내용](../components/dialog.md)의 회원 탈퇴를 따른다. 「지워지는 것」 상자는 창 면 위의 판이라 `surface/control` 이다.
채운 빨강 버튼은 그 창의 확정 버튼에만 쓴다.

## 폭별

- 좁은 폭(672 미만)에서는 버튼이 있는 줄(프로필 이미지)의 버튼을 아래 줄로 내린다.
- 넓은 폭(1056 이상)에서 왼쪽 분류는 레일 폭이다([기초값 — 셸](../foundations.md#셸)). 레일 →16→ 오른쪽 상세 열이고, 상세 열은 최대 `--nl-container-reading`(768)이다.

## 상태

- 뮤즈캣 줄과 뮤즈캣 상세는 `MUSECAT_MODE` 가 켜져 있거나, 꺼져 있어도 연결 기록(뮤즈캣 계정 · 기록 보내기)이 있으면 보인다. 연결한 사람이 끊을 곳을 남기기 위해서다. 꺼져 있고 연결이 없으면 설정은 뮤즈캣이 없던 때 그대로다.

## 동작

- 공개 설정 스위치와 프로필 칸은 바로 저장된다. 저장 버튼은 닉네임에만 있다.
- 실패하면 바꾼 칸만 되돌리고, 저장 상태 자리에 실패와 「다시 시도」 를 보인다.

## 하지 않는 것

- 공개 설정 줄 위에 안내 문장을 두지 않는다.
- 채운 빨강 버튼을 줄에 두지 않는다. 확인 창의 확정 버튼에만 쓴다.
