# 설정

주소 `/settings`(분류 `?category=experience · profile · privacy · connections · account`, 뮤즈캣 상세 `&partner=musecat`) · 코드 `features/settings` · `features/partner/components/musecat-connection-settings.tsx`

## 구성

### 틀

왼쪽 분류 목록과 오른쪽 상세 두 칸이다. 1056 미만에서는 목록을 먼저 보이고, 분류를 누르면 상세로 간다.

### 줄 목록

상세는 줄 목록이다.

- 목록 위와 줄마다 아래에 1px `border/row` 를 긋는다.
- 줄 안쪽은 위아래 12 다.
- 왼쪽에 라벨(`control`) →4→ 설명(`metadata` subdued), 오른쪽에 조작부를 둔다. 사이는 16.
- 글 입력칸(닉네임)만 라벨을 위에 둔다.

### 화면 설정

화면 설정과 국가/지역은 줄 오른쪽 `CompactSelect outlined` 다([입력](../components/field.md)).

### 프로필

칸마다 바로 저장한다.

- 국가 · 선호 오락실 · 업적 · 고정 기록 · 사진은 고르거나 창에서 「적용」 하는 순간 저장한다.
- 닉네임만 바꿨을 때 칸 옆에 보조 L 「저장」 을 둔다. Enter 는 저장, Esc 는 되돌림이다. 나갈 때 확인 창은 이때만 띄운다.
- 실패하면 그 칸을 되돌리고 알린다. 닉네임은 쓴 글자를 남긴다.
- 성공하면 바뀐 값으로 보이고, 알림은 화면 읽기에만 보낸다.
- 맨 아래는 「내 프로필 보기」 한 줄이다.

「프로필 업적」 · 「고정 기록」 칸과 창은 [업적 › 진열 고르기](./achievements.md#진열-고르기) · [고정 기록 고르기](./achievements.md#고정-기록-고르기)를 따른다.

### 공개 설정

스위치 줄이다([폼 조작](../components/form-controls.md)).

- 누르면 바로 저장한다. 저장 버튼은 없고 한 번에 하나씩 저장한다.
- 실패하면 스위치를 되돌리고 알린다.
- Discord 줄 라벨은 「Discord 태그 및 닉네임 공개」 다.

### 연결

| 순서 | 줄                                                                                                                          |
| ---- | --------------------------------------------------------------------------------------------------------------------------- |
| 1    | Discord. 왼쪽에 로고 원 40 · 이름 · 「Discord · 로그인 계정」, 오른쪽에 버튼                                                |
| 2    | 뮤즈캣(`MUSECAT_MODE` 가 켜졌을 때만). 로고 원 40 「M」 · 이름 · 「연결됨 · 계정 · 마지막 사용」 · 꺾쇠. 누르면 뮤즈캣 상세 |

### 뮤즈캣 상세

뒤로 「‹ 연결」 만 설정 틀이 그린다. 나머지는 상세가 그린다.

| 순서 | 내용                                                                                    |
| ---- | --------------------------------------------------------------------------------------- |
| 1    | 로고 + 이름 `section-title` + 연결 줄과 같은 메타 줄                                    |
| 2    | 상태 태그(글자만, 점 없음) + 한 줄 설명. 다시 연결 필요 · 해제 중 · 반영 중일 때만      |
| 3    | 「뮤즈캣에 보내는 기록」 줄 목록. 오른쪽에 「보냄」, 또는 `content/subdued` 「안 보냄」 |
| 4    | 「보낼 항목 바꾸기」 폭 가득                                                            |
| 5    | 구분선                                                                                  |
| 6    | 「NosLog 가 뮤즈캣에서 쓰는 것」 줄 목록. 오른쪽에 「보기」 또는 「내 이름으로 올림」   |
| 7    | 구분선                                                                                  |
| 8    | 「연결 끊기」 폭 가득                                                                   |

「연결 끊기」 는 보조 버튼이다. 누르면 확인 창이 열리고, 창 안 확정 버튼만 채운 빨강이다([대화상자](../components/dialog.md) · [버튼](../components/button.md)).
상태 태그는 [태그](../components/tag.md)의 상태 태그다.

### 계정

회원 탈퇴는 설명이 달린 보통 줄에 꺾쇠를 단다. 누르면 탈퇴 창이 열린다. 창 모양은 [대화상자 › 창 안 내용](../components/dialog.md)의 회원 탈퇴를 따른다.
채운 빨강 버튼은 그 창의 확정 버튼에만 쓴다.

## 폭별

- 좁은 폭(672 미만)에서는 버튼이 둘인 줄(프로필 이미지 · 연결 계정)의 버튼을 아래 줄로 내린다.
- 넓은 폭(1056 이상)에서 왼쪽 분류는 레일 폭이다([기초값 — 셸](../foundations.md#셸)). 레일 →16→ 오른쪽 상세 열이고, 상세 열은 최대 `--nl-container-reading`(768)이다.

## 상태

- 뮤즈캣 줄과 뮤즈캣 상세는 `MUSECAT_MODE` 가 꺼져 있으면 없다. 꺼져 있으면 설정은 뮤즈캣이 없던 때 그대로다.

## 동작

- 공개 설정 스위치와 프로필 칸은 바로 저장된다. 저장 버튼은 닉네임에만 있다.
- 실패하면 바꾼 칸만 되돌리고 알린다.

## 하지 않는 것

- 공개 설정 줄 위에 안내 문장을 두지 않는다.
- 채운 빨강 버튼을 줄에 두지 않는다. 확인 창의 확정 버튼에만 쓴다.
