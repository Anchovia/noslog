# 빙고

주소 `/bingo` · `/bingo/{id}` · 코드 `features/bingos/components`(`bingo-catalog-page.tsx` · `bingo-catalog-card.tsx` · `bingo-detail-page.tsx`)

## 구성

| 2    | 검색          | 12            | 전체 폭                                                                                          |

| 4    | 결과 줄       | 12            | 왼쪽 정렬 `SortMenu`(로그인만) 고스트, 오른쪽 보기 전환 `SegmentedControl`                       |

상태 칩 한 줄은 줄을 바꾸지 않고, 넘치면 가로로 스크롤한다.
결과 줄의 정렬 · 보기 전환은 폰 M, 1056 이상 L 이다.
목록은 한 번에 전부 보인다.

### 보기

보기는 격자(기본) · 목록형 둘이다.

격자 카드는 자켓 1:1(모서리 `radius/container`) +4+ 이름 `emphasis-label` · 상태 `metadata` 다. 이름 · 상태는 한 줄씩 말줄임이다.
로그인하면 자켓 오른쪽 아래에 미니 판, 아래에 진행 트랙 4 를 둔다.
미니 판은 칸 6 · 사이 2 · 판 안쪽 4 · `surface/media-scrim` 이고, 아래 트랙 위 8 에 선다. 자켓 카테고리 레이블과 같은 자리다.
격자 카드는 면 없는 그림 카드라 올림은 제목 밑줄이다(→ [foundations](../foundations.md)).

목록형 행은 서열표 목록 행 규격이다(자켓 48 · 모서리 `radius/control` · 사이 12 · 위아래 8 · 아래 divider).
위에서부터 이름 · 상태 · 진행 막대(위 4, 상세 진행 막대 규격)이고, 오른쪽 끝에 미니 판(바탕 없이 칸만)을 둔다.

상태 글은 「칸 n/25」 · 「해금 완료」 · 「풀보드 완료」 중 하나다. 찬스가 있으면 「빙고 찬스 n」(기본 글자색)을 더한다.
게스트에게는 버전 · 보상을 쓴다.

### 상세

위에서부터 정체성 · 보상 한 줄 · 판 · 미션이다.

| 자리       | 내용                                                      |
| ---------- | --------------------------------------------------------- |
| 정체성     | 자켓 96 · 제목 · 버전 · 진행                              |
| 보상 한 줄 | `metadata` — 필요 줄 · 줄당 · 풀보드 · 총 보상. 펼침 없음 |
| 판         | 칸마다 미션 글                                            |
| 미션       | 펼침(기본 열림) 안에 필터 칩 + 판 순서 한 목록            |

판 칸에는 미션 글을 쓴다. `metadata` 12/16 · 안쪽 4 이고, 칸 높이만큼 말줄임한다.
칸 위치는 화면 읽기로 「n행 m열」 이라고 읽는다.

| 폭        | 판 칸 줄 수 |
| --------- | ----------- |
| 375 미만  | 2줄         |
| 폰        | 3줄(칸 68)  |
| 1056 이상 | 5줄         |

미션 필터 칩은 전체 · 미완료 · 완료 · 찬스다. 목록은 판 순서 하나이고 줄(행) 묶음이 없다.
미션 행 왼쪽에는 칸 위치 미니 판을 둔다. 그 칸만 `content/default`, 나머지는 `border/empty-slot` 이다.
찬스 줄 이름은 번호다(「5행 · 1열 · 대각선」).
상세 초기화 버튼은 미션 열 전체 폭이고 확인 창을 거친다.

빙고 문구의 판정 용어는 `BingoTermHelp` 가 대소문자를 무시하고 찾아 판정 이름 표기로 보인다(→ [판정](../components/judgement.md)).

## 폭별

| 폭                 | 격자                         | 목록형         | 칸을 누르면               |
| ------------------ | ---------------------------- | -------------- | ------------------------- |
| 좁은 폭(672 미만)  | 3열 · 사이 8                 | 한 열          | 칸 팝오버(334)            |
| 중간 폭(672–1055)  | auto-fill 최소 156 · 사이 16 | 한 열          | 칸 팝오버(334)            |
| 넓은 폭(1056 이상) | auto-fill 최소 156 · 사이 16 | 두 열(사이 16) | 판 \| 오른쪽 선택 칸 상세 |

격자 카드 최소 156 은 악곡 격자 카드 최소와 같다.

넓은 폭 상세는 판 | 오른쪽 1:1 이고 열 사이 16 이다. 악곡 상세 개요와 같은 비율이다.
오른쪽 선택 칸 상세는 미션 행과 같은 면이고, 칸을 고르기 전에는 안내 한 줄이다.

넓은 폭 · 로그인이면 판 가장자리에 12줄 진행을 둔다. 왼쪽에 가로줄, 위에 세로줄, 두 모서리에 대각선이다.
칸은 `spacing-32` 이다. 완성은 ✓, 4/5 는 기본 글자색, 나머지는 `content/subdued` 다. 굵기는 모두 `metadata` 400 이다.

## 상태

로딩은 빙고 카드 스켈레톤이다.
저장 실패는 상태 메시지 `inline` 오류 글자 + 고스트 M 「다시 시도」 다(→ [상태 메시지](../components/status-message.md)).
게스트는 상태 칩 · 정렬이 없고, 상태 글 자리에 버전 · 보상을 쓴다.

## 동작

보기는 주소 `view=list` 다.
상세 진행 막대는 값이 바뀌므로 공용 클래스 `nl-chart-reveal` · `nl-chart-bar` 로 움직인다. 목록 카드의 진행 트랙은 움직이지 않는다.

## 하지 않는 것

필터 창 · 팝오버를 두지 않는다.
목록에 「더 보기」 를 두지 않는다.
판 칸에 좌표(A1)를 쓰지 않는다. 원본 빙고처럼 미션 글만 둔다.
보상 한 줄을 펼침으로 만들지 않는다.
