# 서열표

주소 `/tiers` · 코드 `features/tiers/components`(`tier-browser-page.tsx` · `tier-browser-bands.tsx` · `tier-browser-card.tsx` · `tier-export-dialog.tsx`)

필터 레일 · 전체 화면 필터 · 결과 불러오기 · 정렬 트리거는 [악곡 목록](./music-list.md) 「발견 공통」 을 따른다.

## 구성

### 제목 줄

제목이 곧 서열표 셀렉트다(「S 서열표 ⌄」). 서열표 페이지만의 예외다.
글자는 `page-title`, 꺾쇠는 24 · `content/subdued` 이고 테두리가 없다. 잉크는 왼쪽 선에 선다.
올리거나 누르거나 키 포커스가 가거나 목록이 열려 있으면 면 `surface/control-hover` 를 깔고 꺾쇠가 `content/strong` 이 된다.
누르면 셀렉트 목록에 Basic(S · 990k · Pianist) · Recital 두 묶음 소제목이 나온다. 접근 이름은 「서열표 선택」 이다.

제목 줄 오른쪽 끝은 ⋯ 더보기 메뉴다(→ [메뉴](../components/menu.md)). 공용 `ActionMenu` · 고스트 아이콘 L · 접근 이름 「서열표 더보기」 이고 제목 글줄 가운데에 선다.

| 메뉴 항목              | 하는 일                                     |
| ---------------------- | ------------------------------------------- |
| 「이미지로 내보내기」  | 이미지 내보내기 창을 연다                   |
| 「링크 복사」          | 지금 주소를 복사하고 토스트 「링크 복사됨」 |
| 「{목표} 서열표 안내」 | 메타 줄 「안내」 와 같은 창을 연다          |

프로필 카드 공유는 제목 줄 오른쪽 아이콘 그대로다.

### 메타 글줄

제목 →8→ 메타 글줄 →16→ 검색이다.
메타 글줄은 `metadata` 흐림이고 항목 사이는 「 · 」 다. 좁으면 항목 단위로 줄을 바꾼다.

| 폭                        | 메타 글줄                                           |
| ------------------------- | --------------------------------------------------- |
| 1056 미만                 | 「2,159곡 · 9월 2일 업데이트 · 안내」               |
| 1056 이상(레일이 있는 폭) | 「9월 2일 업데이트 · 안내」. 곡 수는 결과 쪽에 쓴다 |

업데이트는 배치 · 구간이 바뀐 날이다. 서울 기준 월 · 일이고, 올해가 아니면 연도까지 쓴다.
「안내」 는 밑줄 글자 링크(`nl-link` + `nl-text-link--underlined`, 접근 이름 「{목표} 서열표 안내」)다.
정보 창(기본 크기 600, → [대화상자](../components/dialog.md))을 열고, 창에는 표 설명 · 쓰는 법 · 업데이트 · 목표 기준을 담는다.
표 설명은 운영자가 한국어로 쓰는 글이라 화면 언어와 상관없이 `lang="ko"` 로 낱말 단위 줄바꿈을 한다.

### 머리 · 결과 줄

| 폭                 | 순서                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| 좁은 폭(672 미만)  | 검색줄 →12→ 결과 줄 →24→ 구간                                                                     |
| 넓은 폭(1056 이상) | 제목 아래 검색 전체 폭 → 레일(필터 그룹) \| 정렬(L) · 띠 값(L) · 보기 전환(L) →12→ 결과 수 → 구간 |

좁은 폭 머리 두 줄은 악곡 목록 폰 머리와 같은 틀이다.
검색줄은 검색(남는 폭, 자리 글 「악곡 제목·아티스트 검색」) + ☰ 필터 아이콘 버튼(컨트롤 높이 정사각, 적용 개수 배지)이다.
결과 줄은 왼쪽에 정렬 `SortMenu` 고스트 M, 그 옆에 띠 값 `CompactSelect size="sm"`(공용 M 크기, 로그인 · 격자 보기일 때만), 오른쪽에 보기 전환 세그먼트 M(격자 · 목록, 아이콘)이다.

### 구간

구간 머리는 sticky 이고 아래에 `--nl-stroke-default` `border/divider` 선을 긋는다. 로그인하면 오른쪽에 「달성 N/M」 을 쓴다.
선 →`section-title-gap`(12/16)→ 첫 카드 · 행이다. 간격은 제목 글자가 아니라 선에서 잰다.
구간 머리 숫자(13.5 · 13.0 …)는 악곡 상세 머리와 같은 서열 값 그라데이션 색(`lib/music/tier-value-color.ts`)이다.

결과 불러오기 한도(20개씩 3번 뒤 「더 보기」)는 구간마다 적용한다.

### 격자

| 폭       | 열                                           |
| -------- | -------------------------------------------- |
| 672 미만 | 4열 · 사이 8                                 |
| 672 이상 | auto-fill 최소 약 111(`111.333px`) · 사이 16 |

카드는 자켓 1:1 + 오른쪽 아래 난이도 판이다. 375 미만은 난이도 약칭 N · H · EX · R 을 쓴다.
자켓에는 늘 `--nl-stroke-default` `border/divider` 윤곽을 긋는다.
로그인하면 아래에 점수(달성하면 목표 색)를 두고 달성 테두리(`--nl-stroke-strong`)를 긋는다. 테두리 색은 점수 목표 색 `--nl-score-goal-*` 이다.
달성하고 풀 콤보면 테두리가 왼쪽 위 `achievement/full-combo` 에서 오른쪽 아래 목표 색으로 바뀐다(가운데 절반에서 전환). Pianist 는 풀 콤보여도 목표 색 하나이고, 달성하지 못한 풀 콤보는 달성 테두리가 없다.
로그인하면 목표 미달성 곡(미플레이 포함)은 자켓 그림만 흑백(`grayscale`)이다. 판 · 띠 · 점수 글자 · 누름 반응은 그대로라 disabled 가 아니다. 목록 행 자켓도 같다.
그림만 있는 서열 칸의 올림은 테두리다. 윤곽이 `border/ring` 으로 바뀌고, 달성 테두리가 있는 카드는 자켓 바깥에 `--nl-stroke-default` `border/ring` 선을 더한다.

자켓 위 띠는 로그인 · 격자 보기에서 자켓 위 전체 폭에 둔다.
바탕 `surface/media-scrim` · 글자 `content/on-media` `metadata` · 안쪽 2 · 4(난이도 판과 같은 규격) · 테두리 아래다.
값은 결과 줄 셀렉트로 고른다. 공식 Grd(기본, 「+41.26」) · NosLog 레이팅(「+36.5」) · 표시 안 함 셋이고, 목록 보기 기여와 같은 형식이다.
고른 값이 없는 곡은 띠가 없다. 다른 값으로 채우지 않는다.

### 목록

행은 자켓 48 · 모서리 `radius/small` · 사이 12 · 위아래 8 이라 높이 64 이고, 아래에 `border/row` 선을 긋는다.
왼쪽은 곡 이름 `emphasis-label` / 난이도 `metadata` 난이도 색(+ 번역 제목)이고 한 줄씩 말줄임이다.
로그인하면 오른쪽에 점수 / 공식 Grd 기여를 둔다. 점수는 달성하면 목표 색, 미플레이는 흐림이다. 기여가 없으면 NosLog 레이팅을 쓴다.
행의 올림은 목록 줄 `interaction/row` 겹침이다. 좌우 12 를 넓혀 칠하고 자켓 · 글자 선 · 아래 선은 그대로 둔다.

### 이미지 내보내기

프로필 카드와 같은 창(`nl-image-share`, → [대화상자](../components/dialog.md))이다.

| 순서 | 자리        | 내용                                                                                                                            |
| ---- | ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 담기는 범위 | 「담기는 것 · {서열표 · 조건} · N구간 M곡」. 지금 필터 · 검색 그대로 + 창에서 고른 구간. 줄 오른쪽 끝 「구간 고르기」 밑줄 링크 |
| 2    | 구간 목록   | 「구간 고르기」 로 펼친다. 레일과 같은 구간 체크 목록(지금 조건의 구간만)                                                       |
| 3    | 남은 수     | 구간 목록 →8→ 「선택 N곡 / 500곡 · N곡 남음 · 넘음」(`metadata`)                                                                |
| 4    | 미리보기    |                                                                                                                                 |
| 5    | 체크박스    | 곡 이름 표시 · 로그인하면 내 달성 표시. 이 브라우저에 기억한다                                                                  |
| 6    | 버튼        | 이미지 저장(주) · 클립보드 복사 · 공유(안 되면 X 공유)                                                                          |

한 장에 500곡까지 담는다. 넘으면 구간 목록을 펼친 채 열고, 위(높은 구간)부터 이어서 500곡 안까지 미리 체크한다.
고른 구간은 이미지에만 쓰고 페이지 필터는 그대로 둔다. 넘게 고르면 저장을 막고 경고한다.

이미지는 폭 1200 · 한 줄 자켓 12 · JPEG(복사만 PNG)이다. 브라우저 캔버스로 지금 페이지 토큰을 읽어 그린다.
위에서부터 머리(서열표 · 조건 `page-title` 크기 · 줄 높이 · 굵기 · `content/strong` · 달성 요약 · 오른쪽 NosLog · 날짜), 구간 행, 구분선 · 주소다.
날짜 같은 메타 줄은 `metadata` 값(12 · medium · 자간 `--nl-type-tracking-detail`)이다.
「NosLog」 는 사이트 글꼴 20 · 600 · `content/default` 다.
구간 행은 왼쪽에 서열 값 색 · 달성 수, 오른쪽에 자켓 격자다. 자켓 격자는 화면 카드와 같은 테두리 · 흑백 · 띠 · 난이도 판이고, 자켓이 없으면 음표를 그린다.
파일 이름은 `noslog-{모드}-{목표}-{조건}-{날짜}.jpg` 다.

## 폭별

좁은 폭(672 미만)은 머리 두 줄(사이 12)이고 격자 4열이다.
중간 폭(672–1055)은 격자 auto-fill 이고 필터는 전체 화면 창이다.
넓은 폭(1056 이상)은 레일이 나타나고, 메타 글줄에서 곡 수가 빠져 결과 수로 간다. 정렬 · 띠 값 · 보기 전환은 L 이다.

## 상태

화면 밖 구간은 기존 카드 스켈레톤 6개만 둔다. 전체 곡 수만큼 DOM 을 미리 만들지 않는다.
검색 결과가 없으면 `ResultState` 한 줄 「「검색어」에 맞는 곡이 이 서열표에 없습니다.」 + 「검색어 지우기」 보조 버튼이다(→ [상태 메시지](../components/status-message.md)).
로그아웃이면 띠 값 셀렉트 · 달성 표시 · 점수 정렬이 없다.

## 동작

정렬은 구간 안 곡 순서만 바꾼다. 구간 순서는 그대로다.

| 정렬           | 순서                        |
| -------------- | --------------------------- |
| 서열표 순      | 기본                        |
| 레벨 순        | 높은 레벨 먼저 · Real 끝    |
| 일본어 읽기 순 | 가나, 없으면 원제           |
| 점수 낮은 순   | 로그인만. 기록 없는 곡 먼저 |

레벨 순에서 Real 은 레벨 숫자 단위가 달라 맨 끝 한 묶음이고, 그 안에서 높은 레벨 먼저다.
같은 값은 서열표 순이다. 구간은 곡 전체를 한 번에 받으므로 20개씩 그리기 전에 정렬한다.
주소는 `sort=` 이고 기본이면 생략한다. 로그아웃이면 점수 순은 서열표 순으로 읽는다.

검색은 악곡 목록 검색과 같은 필드(곡 코드 · 제목 · 가나 · 아티스트 · 승인된 번역 제목)다.
대소문자를 무시한 부분 일치이고, 300ms 쉬면 반영한다. 한글 조합 중에는 기다린다. 주소 `q=` 는 기록을 덮어쓴다.
지금 목록 · 필터 안에서 좁히고, 맞는 곡이 없는 구간은 숨긴다.

필터 창 · 레일의 구간 목록은 지금 조건에서 0곡인 구간을 뺀다. 이미 고른 구간은 남기고, 범위 선택은 보이는 구간 안에서 한다.

보기는 주소 `view=list` 다. 예전 `view=detailed` 는 목록으로 읽는다.
띠 값은 주소 `strip=` 이다. 기본 Grd 면 생략하고 `rating` · `off` 를 쓴다.

⋯ 메뉴에서 연 창을 닫으면 포커스는 ⋯ 로 돌아간다.

## 하지 않는 것

제목 뒤에 ⓘ 를 두지 않는다. 꺾쇠와 아이콘 둘이 붙는다. 서열표만 「기준 설명」 ⓘ 대신 「안내」 링크를 쓴다.
띠 값이 없는 곡을 다른 값으로 채우지 않는다.
