# 공개 채보 뷰어

주소 `/music/[index]/[difficulty]/pattern` · 코드 `components/chart-pattern` · `features/contributions`(채보 의견 · 초안 입구)

## 구성

### 배치

| 순서 | 내용                                           |
| ---- | ---------------------------------------------- |
| 1    | 돌아가기                                       |
| 2    | 보기 방식 세그먼트 「낙하형 · 전체 악보」 →12→ |
| 3    | 무대(조작 줄이 위에 겹친다)                    |
| 4    | 넓은 폭(1056 이상)만: →12→ 채보 의견 쓰기 줄   |
| 5    | 머리                                           |
| 6    | 채보 의견                                      |

무대 폭은 폭 가득이다. 단 첫 화면 안에 들어오도록 아래 값까지만 넓히고 가운데에 둔다.

(화면 높이 − `--nl-header-height` − 위 여백 24 − 돌아가기 `--nl-back-link-height` − 24 − `--nl-control-height` − 12 − 16) × 16/9

넓은 폭에서 쓰기 줄이 있으면 `--nl-control-height` + 12 를 더 뺀다. 낙하형이면 쓰기 줄도 무대 폭으로 가운데에 둔다.

보기 방식 세그먼트([세그먼트](../components/segmented-control.md))는 무대 위에 늘 보인다. 조작 줄 안 아이콘으로 옮기면 낙하형만 있는 것처럼 보여서다.

### 넓은 폭 머리(1056 이상)

무대 아래 12에서 시작한다.

| 순서 | 내용                                                                                        |
| ---- | ------------------------------------------------------------------------------------------- |
| 1    | 제목 묶음. 제목 · 난이도, 현지화 제목, 아티스트 순서로 사이 8                               |
| 2    | 채보 줄. 왼쪽 작성자(동그란 프로필 이미지 32 · 「채보 · 이름」 + 라벨), 오른쪽 끝 동작 버튼 |
| 3    | 정보 상자. 면 `surface` · 모서리 `radius/control` · 안쪽 12 16 · 줄 사이 8                  |

채보 줄의 동작 버튼은 보조 M 아이콘 + 글자다([버튼](../components/button.md)). 「고치기」 · 「출처 보기」(영상 추출 채보만) · 「공유」 순서로 사이 8, 넘치면 다음 줄로 간다.
「공유」 는 주소를 복사하고 `?t` 는 뺀다.

정보 상자는 노트 수 · 공개 버전 · 길이 줄, 영상 추출 줄, 손 범례 순서다.

### 좁은 · 중간 폭 머리(1055 이하)

| 순서 | 내용                                                                                                                                  |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 무대 →12→ 제목 한 줄 `page-title`. 넘치면 줄임표(모든 페이지 제목 규칙) →4→                                                           |
| 2    | 메타 한 줄 `metadata` subdued. 난이도 · 아티스트 · 노트 수 · 길이, 넘치면 줄임표. 끝에 「더보기」(`metadata` · `content/default`) →4→ |
| 3    | `--nl-control-height` 한 줄. 왼쪽 프로필 이미지 32 · 이름 · 라벨, 오른쪽 끝 글자 없는 고스트 아이콘 버튼 「고치기」 · 「공유」        |

아이콘 버튼의 이름은 `aria-label` 과 툴팁으로 준다. 이 줄은 접히지 않는다.
「출처 보기」 버튼은 넓은 폭에만 있다. 좁은 · 중간 폭은 「더보기」 창에서 출처를 본다.

### 「더보기」 창

「더보기」 는 공용 대화상자 「채보 정보」 를 가운데 창으로 연다(`ModalDialog`, [대화상자](../components/dialog.md)).

| 순서 | 내용                                            |
| ---- | ----------------------------------------------- |
| 1    | 제목 묶음 →16→                                  |
| 2    | 정보 상자(노트 수 · 버전 · 길이 · 손 범례) →16→ |
| 3    | 출처. 「출처 보기」 창과 같은 목록              |

출처 목록의 채보 항목은 작성자 · 공개 버전 · 날짜다. 영상 추출 채보면 노트 배치 설명 · 논문 · GitHub 를 더한다.

### 출처

채보 줄은 「채보 · 이름」 이다. 운영자가 공개한 채보의 이름은 공개한 사람의 `username` 이고, 운영자면 기본 태그 「Admin」(`nl-tag`, [태그](../components/tag.md))을 붙인다.

유저 기여 채보는 작성자 줄에 실제 작성자를 쓰고, 이름 옆에 기여 라벨을 붙인다. 라벨은 Lv.3부터, 운영자는 「Admin」 이다(공용 `ContributionLabel`).

영상 추출 채보만 정보 상자에 「노트 배치 · 영상에서 추출(vid2bmap)」(`metadata` subdued)을 두고, 채보 줄에 「출처 보기」 버튼을 둔다.

「출처 보기」 는 공용 대화상자 「출처」 를 연다. 항목 사이 16 + 구분선, 항목 제목 →8→ 내용.

| 항목      | 내용                                                                                            |
| --------- | ----------------------------------------------------------------------------------------------- |
| 채보      | 이름 + 태그 · 공개 버전 · 날짜. 유저 기여 채보는 둘째 줄이 「v18 · 운영자 이름 공개 · 날짜」 꼴 |
| 노트 배치 | 자동 추출 뒤 운영자 검수 · vid2bmap(김영훈 · 최성희, KAIST) · MIT · 논문 · GitHub(새 탭)        |

출처는 창과 글자로만 보이고 캔버스는 그대로 둔다.

### 무대

낙하형 무대는 폭 가득에 16:9 고정이다(`aspect-ratio`). 좁은 폭(672 미만)에서는 화면 끝까지 닿고 모서리가 없다.

그림은 16:9 논리 크기(1280 × 720)에 그려 폭에 맞춰 통째로 줄인다. 원근 · 노트 간격 · 두께 · 선 굵기가 폭에 정비례라서
어느 기기에서나 같은 그림이고 크기만 다르다. 기기 픽셀 밀도로 그린다. 노트 속도(도착까지 시간)는 설정 값 그대로다.

가로 박자선은 박마다 같은 선이 노트와 함께 내려온다(노트 뒤). 레인 0–28 끝을 같은 원근으로 잇고, 가까울수록 굵다(논리 2 × 0.6–1.4).
색은 판정선 색의 30%다. 레인 안내선(회색 38%)과 비슷한 무게가 된다.

빈 채보 자리도 무대처럼 16:9다.

### 트릴

낙하형 · 전체 악보 · 채보 에디터 모두 게임식 모양을 쓴다. 공용 계산은 `lib/chart-pattern/trillShape.ts` 다.

- 머리와 끝 막대는 두 자리를 합친 범위 전체다. 머리 가운데에 마름모 두 개(`#f2c75c`)를 두고, 끝 막대는 캔버스 바탕색 + 손 색 테두리다.
- 몸통은 같은 범위 폭의 육각형을 사분음표 1/12마다 쌓는다. 육각형마다 그때 칠 자리 쪽만 손 색(투명도 0.82)이고, 반대편은 범위 끝까지 옅어진다.
- 첫 육각형은 첫 자리, 다음부터 번갈아 간다.

### 조작 줄

인라인과 전체화면이 같은 줄을 쓰고, 무대 아래쪽에 겹친다.

판은 아래에서 위로 옅어지는 `surface/media-scrim` 이고 위쪽 끝은 투명이다. 안쪽은 위 32 · 옆 8 · 아래 4, 글자는 `content/on-media`.
판의 빈 곳을 누르면 무대로 지나간다.

| 순서 | 내용                                                                                                          |
| ---- | ------------------------------------------------------------------------------------------------------------- |
| 1    | 재생 막대 한 줄(좌우 8) →4→                                                                                   |
| 2    | 버튼 줄(사이 4). 재생 · 처음으로 · 「시각 / 길이」 … 노트 속도 값(「2.0×」, 누르면 설정 창) · 톱니 · 전체화면 |

미디어 위 버튼은 44이고 버튼 판이 없다. 올리면 `interaction/hover` 를 겹친다. 좁은 폭은 처음으로 · 속도 값을 뺀다.

재생 막대 · 음량 막대는 공용 슬라이더 값을 쓰고([폼 컨트롤](../components/form-controls.md)), 미디어 위 버튼의 포커스도 공용 포커스 선이다.

재생 중에 3초 가만히 있거나 마우스가 무대를 벗어나면 조작 줄과 커서가 움직임 없이 바로 숨는다.
움직이거나 누르거나 포커스가 오면 다시 나온다. 멈춰 있으면 늘 보인다.

톱니 「재생 설정」 은 떠 있는 창을 연다. 떠 있는 창 규격([기초값 — 떠 있는 창](../foundations.md#떠-있는-창))에 안쪽 12 · 줄 사이 12 다.
항목은 노트 속도 · 메트로놈 · 메트로놈 음량 · 엄밀한 연주 · 로컬 음원이다. 로컬 음원은 버튼 →4→ 파일 이름 또는 안내이고, 280 안에서 줄바꿈한다.
설정 창이 열려 있는 동안은 조작 줄을 숨기지 않는다.

설정 창과 셀렉트 목록은 전체화면이면 전체화면 요소 안에 띄운다. 밖에 뜨면 보이지 않는다. 설정 창 층은 전체화면일 때만 `--nl-layer-fullscreen-dialog`, 인라인이면 `--nl-layer-popover` 다.
인라인이면 문서에 띄워 무대에 잘리지 않게 하고 `.noslog-ui` 로 감싼다.

### 전체화면

조작 줄 오른쪽 끝 버튼이다. 무대만 브라우저 전체화면으로 띄운다. 요소 전체화면이 없는 iPhone Safari 는 화면을 채우는 것으로 대신하고 Esc 로 나간다.
16:9 를 지켜 가운데에 두고, 남는 곳은 무대 바탕색(`stage/canvas`)이다.

### 전체 악보

읽기 줄(시각 / 길이) 오른쪽 끝에 같은 전체화면 버튼을 둔다. 전체화면에서는 띠가 화면 높이를 채운다(안쪽 16).
열 폭과 배율 상한 2.0은 그대로라서 한 번에 보이는 마디가 는다.

열 이음새 라벨(열 맨 위)은 그 경계에서 BPM · 박자가 바뀌면 「BPM 112 · 4/4」 를 먼저, 시각을 그 아래에 둔다.
캔버스가 아니라 글자로 그린다. 캔버스에 그리면 잘리고 시각과 겹쳐서다.

### 채보 의견

머리 아래 구역이다.

| 순서 | 내용                                                      |
| ---- | --------------------------------------------------------- |
| 1    | 공용 제목 줄 「채보 의견 (N)」 →`--nl-section-title-gap`→ |
| 2    | 쓰기 칸 →16→                                              |
| 3    | 목록 또는 빈 안내                                         |

제목 줄 오른쪽 끝에는 한 단어 필터 세그먼트 M 「전체 · 남은 것 · 해결」 을 둔다. 의견이 있을 때만 보인다.
로그아웃이면 그 자리에 「로그인하고 의견 남기기 ›」 를 둔다.

쓰기 칸의 자리는 폭에 따라 다르다.

| 폭                 | 자리                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 넓은 폭(1056 이상) | 무대 바로 아래 줄. 재생을 보면서 쓴다. 로그아웃이면 그 줄에 「로그인하고 의견 남기기 ›」 를 두고 제목 줄의 링크는 숨긴다 |
| 1055 이하          | 구역 안(위 표의 2)                                                                                                       |

두 자리는 쓰던 글 · 종류 · 고정 시각을 함께 써서 폭을 바꿔도 이어진다.

쓰기 칸은 쉬는 상태에서 한 줄이다. 시각 · 한 줄 입력, 사이 8.
시각은 `metric-value` 링크색이다. 고정폭이라 재생 중에 폭이 바뀌지 않는다.
시각은 지금 재생 위치를 따라가다가 글을 쓰기 시작하면 멈춘다. 시각을 누르면 지금 위치로 다시 맞춘다.

입력을 누르면 아래 8에 줄이 펼쳐진다. 왼쪽에 종류 세그먼트 M 「문제 · 제안 · 칭찬」(칸은 균등 분할, 묶음 폭은 제목 줄 필터와 같다),
오른쪽에 고스트 「취소」 · 주 버튼 L 「남기기」 다. M 예외는 버튼 규칙의 두 곳뿐이다([버튼](../components/button.md)).
폭이 좁으면 버튼이 다음 줄 오른쪽으로 간다.

목록 줄은 악곡 상세 의견 줄 문법에서 아바타만 뺀 모양이다([악곡 상세](./music-detail.md)).

| 순서 | 내용                                                                                                                      |
| ---- | ------------------------------------------------------------------------------------------------------------------------- |
| 1    | 이름 줄 20. 시각(`emphasis-label` `content/default`) · 이름 · 기여 라벨 · 날짜 · 해결이면 상태 태그 성공 「해결」 · ⋯ →4→ |
| 2    | 본문                                                                                                                      |

줄 사이 16, 시각 순이다. 목록 줄의 태그는 하나다. 해결이면 상태 태그 「해결」, 아니면 종류 분류 태그(색 없음).

진행 막대에는 해결 안 된 의견 시각마다 눈금(`--nl-feedback-warning-marker` 2 × 12)을 둔다. 눈금은 누르지 않고, 손잡이가 움직이는 폭에 맞춘다.

## 동작

### 조작 키

| 입력                                          | 동작                                                                      |
| --------------------------------------------- | ------------------------------------------------------------------------- |
| 무대 누르기                                   | 재생 · 일시정지. 설정 창을 닫으려고 누른 것은 제외                        |
| 스페이스                                      | 재생 · 일시정지                                                           |
| ← · →                                         | 한 마디 뒤 · 앞                                                           |
| Shift + < · >                                 | 노트 속도 −0.1 · +0.1                                                     |
| 폰에서 무대 왼쪽 · 오른쪽 절반 두 번 두드리기 | 한 마디 뒤 · 앞. 이어서 두드리면 계속, 한 번이면 300ms 뒤 재생 · 일시정지 |

한 마디는 앞으로 가면 다음 마디 처음, 뒤로 가면 그 마디 처음이다. 마디 처음에서 300ms 안이면 앞 마디 처음으로 가고, 이어서 누르면 계속 뒤로 간다.

글 입력 · 버튼 · 막대 · 셀렉트에 포커스가 있으면 그 부품의 키 동작을 둔다.

손가락인지, 설정 창이 열려 있었는지는 누르기 시작(pointerdown)에서 가린다. iOS WebKit 의 click 에는 pointerType 이 없고,
손가락으로 바깥을 누르면 창 닫힘이 click 뒤로 밀려서다.

### 기여

「고치기」 는 채보 줄의 동작 버튼이다. 내 초안이 있으면 「내 초안 · 상태」 를 보인다(공용 `ChartDraftEntry`).

### 채보 의견

- Esc 나 「취소」 는 글을 지우고 쓰기 칸을 접는다. 포커스가 빠져도 글이 남아 있으면 펼친 채 둔다.
- 목록의 시각을 누르면 낙하형으로 그 시각에 서고, 캔버스 위 끝이 머리 아래(`--nl-header-height` + 16)에 오도록 올라간다. 주소에 `?t=42.3`(초)을 붙인다.
- ⋯ 메뉴는 내 의견이면 「의견 삭제」(해결 전), 운영자면 「해결로 표시」 · 「가리기」 다.

## 하지 않는 것

- 낙하형 · 전체 악보 설명 안내 창과 「28칸 · 열당 4마디」 글자를 두지 않는다.
- Safari 에서도 뷰어를 막지 않고 경고도 띄우지 않는다.
- 마디선을 따로 진하게 그리지 않는다.
