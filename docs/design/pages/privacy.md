# 개인정보 처리방침

주소 `/privacy` · `/privacy/history` · `/privacy/history/[version]` · 코드 `features/privacy`

## 구성

| 순서 | 내용                                                                                                                                |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 머리 — 제목 `page-title` →8→ 최종 수정 · 시행 날짜 `metadata` 흐림 →16→                                                             |
| 2    | 요약 6묶음 — 묶음마다 상자 제목 →8→ 설명 `body-secondary` →8→ 「자세히 보기」 밑줄 링크. 묶음 사이는 구분선(선 위아래 12) →32→      |
| 3    | 목차(좁은 · 중간 폭은 접힘 카드, 넓은 폭은 레일) →32→                                                                               |
| 4    | 본문 15절 — 절 사이 `--nl-section-gap`, 절 제목 `section-title` → 내용 `--nl-section-title-gap`, 항목 제목 `component-title` →8→ 글 |

본문은 `nl-body` 다. 「법률 검토 대기」 는 상자 경고([상태 메시지](../components/status-message.md))로 둔다.
요약 6묶음은 개인정보보호위원회 라벨링 칸(수집 정보 · 처리 목적 · 보유 기간 · 제3자 제공 · 처리 위탁 · 고충 처리)을 그림 기호 없이 글자로 둔다.
절 순서는 개인정보보호위원회 「개인정보 처리방침 작성지침」 의 법정 항목 순서다. 처리 항목 · 제3자 제공 · 위탁 · 국외 이전 · 쿠키 · 구제 기관 · 개정 전후 대조는 표로 쓰고,
표는 공지 본문 표와 같은 모양이다(14 · 줄 구분선 · 머리 칸 흐린 굵은 글자, 좁으면 표만 가로로 민다).
「이용자 권리」 절 끝에는 설정 · 회원 탈퇴(로그아웃이면 「로그인 후 설정에서 관리」) 링크, 「방침 변경 및 이력」 절 끝에는 「이전 버전 보기」 링크를 둔다.

넓은 폭(1056 이상)에서 목차는 오른쪽 레일이다([기초값 — 셸](../foundations.md#셸)). 레일은 헤더 아래 24 에 붙어(sticky) 따라온다.
좁은 · 중간 폭의 목차는 요약 아래 접힘 카드([펼침](../components/disclosure.md))이고, 줄은 카드 폭 전체를 쓴다.

목차 링크는 단독 링크(`nl-link`)다. 평소에는 밑줄 없이 `content/default` · medium 이고, 올리거나 누르거나 키 포커스가 가면 `content/strong` + 밑줄이다.
레일 목차는 상자 제목 →8→ 줄이고, 줄은 목록 행(컨트롤 높이 · 좌우 안쪽 16 · 모서리 `radius/control`)이다. 지금 읽는 절의 줄은 면 없이 굵기 600 이다.

### 이전 버전

- 목록(`/privacy/history`)은 뒤로 링크 「개인정보처리방침」 →24→ 제목 「이전 버전」 →16→ 적용 기간 밑줄 링크 목록(사이 12)이다. 없으면 흐린 한 줄 안내.
- 버전 화면(`/privacy/history/[version]`)은 지금 방침과 같은 모양이고, 맨 위 뒤로 링크 「이전 버전」 →24→ 머리, 머리 날짜 아래에 「적용 기간」 흐림 한 줄을 더한다. 날짜 · 적용 기간 두 줄 모두 쪽 제목 아래 설명 줄 크기(16/24 regular)다.

## 동작

- 처음 열면 첫 절을 고른다. 주소에 절이 있으면 그 절을 고른다.
- 목차를 누르면 그 절을 강조하고 포커스를 옮긴다.
- 스크롤하면 목차의 고른 항목이 지금 읽는 절을 따라간다.
