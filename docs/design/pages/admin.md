# 관리자 화면

주소 `/admin/*` · 코드 `components/admin`(셸 `admin-shell` · 메뉴 `admin-nav` · 카드 `admin-card` · 서랍 `admin-drawer` · 삭제 확인 `admin-delete-dialog`) · 스타일 `app/styles/admin.css`

관리자 화면은 있는 토큰으로 만든다. 파운데이션 판 · 결정은 관리자 화면을 기준으로 삼지 않고, 관리자 화면 때문에 바꾸지 않는다. 공지 편집기는 [관리자 공지 작성](./admin-announcements.md), 채보 에디터는 [채보 에디터](./chart-editor.md)대로 지금 모양을 둔다.

## 셸

| 폭        | 구성                                                                                                                                                                                                                       |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1056 이상 | 왼쪽 사이드바 216(오른쪽 선) + 오른쪽 위 막대 + 본문. 본문은 사이드바 오른쪽 전체 폭, 바깥 여백 12                                                                                                                         |
| 1056 미만 | 사이드바를 숨기고 위 막대 왼쪽 메뉴 버튼이 왼쪽 서랍을 연다. 서랍은 왼쪽 · 위 · 아래 가장자리 8 · 최대 폭 304 · `surface/canvas` · `radius/large` · 가림막, 맨 위 닫기 버튼, 안은 사이드바와 같은 항목. 나타날 때 페이드만 |

- 사이드바: 맨 위 이름 줄(누르면 사이트 헤더 로고처럼 메인 홈으로 간다. 높이 = 컨트롤 높이 + 위아래 12, 아래 점선) → 묶음 제목 없이 14개를 한 줄씩(대시보드 · 공지 · 이벤트 · 피드백 · 유저 · 동기화 · 악곡 · 업데이트 · 기여 · 서열표 · 검정 · 인증 · 빙고 · 오락실). 항목은 컨트롤 높이 · 사이 4 · 좌우 8 · `radius/control` · 아이콘 16 + 글자 14 medium `content/subdued`. 현재 항목은 면 `surface/control` + `content/strong`, 올림은 `interaction/row`.
- 사이드바 · 메뉴 서랍 맨 아래(위 선)에 계정 링크(아바타 · 이름 → 프로필)를 둔다. 사이트 헤더의 계정 링크와 같다. 전역 검색 항목은 두지 않는다.
- 위 막대: 높이 56(넓은 폭은 컨트롤 높이 + 위아래 12, 좁은 폭은 작은 컨트롤 높이 + 위아래 12), 아래 선. 현재 구역 이름. 구역 안 하위 화면은 「구역 ▸ 이름」(구역은 링크).

## 목록

카드 하나(`surface/surface` · 선 `border/divider` · `radius/large`)에 위에서부터 쌓는다.

| 층        | 내용                                                                                                                                 |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 머리 줄   | 왼쪽 제목 16 medium `content/strong`(쪽의 h1), 오른쪽 보조 버튼. 높이 = 컨트롤 높이 + 위아래 12, 좌우 24, 아래 선                    |
| 도구 줄   | 왼쪽 필터, 오른쪽 검색. 머리 줄과 같은 높이 · 여백                                                                                   |
| 표        | 머리줄 · 줄 모두 글자 14 · 줄 높이 24 + 위아래 12, 칸 좌우 24, 줄 아래 선. 머리줄 medium `content/subdued`, 첫 칸만 `content/strong` |
| 페이지 줄 | 왼쪽 「1 — 50 / N단위」, 오른쪽 「1 / N쪽 · 이전 · 다음」. 글자 14 medium, 위아래 16 · 좌우 24. 한 쪽 50줄                           |

- 상태는 표 칸 안에 [상태 점](../components/tag.md) + 글자.
- 줄 전체가 누르는 자리다. 「자세히 보기」 가 있는 목록은 줄 어디를 눌러도 그 서랍이 열리고, 자세히 보기가 없는 목록(오락실)은 「고치기」 서랍을 열고, 제목 링크가 있는 목록은 그 링크가 가던 곳으로 간다(키보드는 줄에서 Enter · Space). 줄 안 링크 · 버튼 · 체크박스 · ⋯ 를 누를 때는 줄 클릭이 일어나지 않는다.
- 줄 끝 칸은 ⋯ 메뉴([목록 · 메뉴](../components/menu.md)). 표에 다 못 넣는 값은 「자세히 보기」 서랍의 읽기 줄로 보인다.
- 체크박스는 두지 않는다.

### 대기열 상태 탭

피드백 · 인증 · 기여 · 업데이트 · 이벤트는 목록 카드 위에 [밑줄 탭](../components/tabs.md) 한 줄을 둔다. 탭은 왼쪽부터 글자 폭만 · 사이 24, 탭마다 건수 알약(글자 12 · 면 `surface/control` · `radius/full` · 좌우 8). 상태 열은 탭이 대신하므로 표에 두지 않는다.

### 일괄 선택

기여 검토(곡 정보)는 줄 맨 앞 체크박스로 고르고, 하나라도 고르면 본문 아래 가운데에 알약 막대가 뜬다. 막대는 높이 40(`control-height-large`) · 바닥에서 32 · `surface/control` · `radius/full` · 떠 있는 창 그림자이고, 「N건 선택 | 반려 R | 반영 A」 를 세로 선으로 나눈다. R · A 는 키보드로도 누른다(글 쓰는 칸 밖에서). 반려 사유는 표 위 도구 줄에 펼친다.

## 홈

위에서부터 지표 카드 4칸(값 + 직전 기간 비교 한 줄) → 그래프 카드(머리 줄 오른쪽에 기간 고르기) → 「처리할 일」 표 → 나머지 패널 격자.
나머지 패널은 활성 사용자 · 전환 흐름 · 기여 활동 · 가입자 · 손님 · 자주 보는 페이지 · 동기화 상태 · API 호출 순서다. 1056 이상은 같은 폭 2열 · 사이 12 · 같은 줄은 같은 높이이고, 홀수로 남는 마지막 패널은 전폭이다. 패널은 목록 카드와 같은 머리 줄(제목) 아래에 줄 목록을 둔다.

## 상세 · 편집

- 1056 이상은 2열(왼쪽 본문 + 오른쪽 440, 사이 12), 좁은 폭은 한 열.
- 구역마다 카드. 카드 머리 줄에 제목과 오른쪽 ⋯. 내용은 읽기 줄 「이름 | 값」(반반, 위아래 16 · 좌우 24, 줄 위 선, 글자 14 `content/subdued`). 표가 필요하면 목록의 표와 같다.
- 고치기는 카드 ⋯ 에서 오른쪽 서랍으로 연다. 서랍은 화면 가장자리 8 · 폭 560 · `surface/elevated` · `radius/large`. 머리 줄(제목 · 닫기) · 본문(여기만 스크롤, 안쪽 24) · 바닥 줄(오른쪽 「취소 · 저장」). 나타날 때 페이드만 쓴다.
- 오락실은 목록 + 서랍이다. 서랍을 열 때만 폼을 그린다.
- 새로 만들기(공지 · 빙고 · 검정 · 서열표)는 지금처럼 따로 된 새 페이지다.

## 삭제 확인

[대화상자](../components/dialog.md) 작은 크기(440)에 설명 → 확인 칸 → 전폭 위험 버튼(동작 이름)을 둔다. 취소 버튼은 없고 닫기와 바깥 누르기로 닫는다.

| 삭제                                                       | 확인 칸                                                         |
| ---------------------------------------------------------- | --------------------------------------------------------------- |
| 공지 · 검정 · 빙고 · 보관 서열표 · 서열표 구간 · 인증 제출 | 이름 입력(인증 제출은 제출한 유저 닉네임). 같아야 버튼이 켜진다 |
| 서열표 항목 빼기 · 오락실 사진 · 자켓 되돌리기             | 없음(설명과 버튼만)                                             |

딸린 줄이 함께 지워지는(스키마 `onDelete: Cascade`) 삭제만 이름을 입력한다.

## 가이드 밖 값

폭 넷(사이드바 216 · 상세 오른쪽 열 440 · 서랍 560 · 메뉴 서랍 304)은 토큰이 아니라 `admin.css` 안 부품 변수다([대화상자](../components/dialog.md) 폭과 같은 방식).
