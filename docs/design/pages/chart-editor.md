# 채보 에디터

주소 `/admin/music/[index]/[difficulty]/pattern`(관리자) · `/music/[index]/[difficulty]/pattern/draft`(기여자) · `/admin/music/[index]/[difficulty]/pattern/review/[draftId]`(검토) · 코드 `components/admin/chart-pattern`

## 구성

### 세 모드

캔버스 · 속성 칸 · 재생 막대는 세 모드가 같고, 위 막대와 레일만 다르다.

에디터 글은 ko · ja · en 세 벌이다. 단 관리자 전용 버튼 · 저장 이력 · 영상 추출 창은 한국어 그대로 둔다.

| 모드   | 위 막대                                                                                                                                                |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 관리자 | 지금 그대로. 버전 저장 · 공개 · 미리보기 · 가져오기 메뉴 · 저장 이력                                                                                   |
| 기여자 | 자동 저장 글 · 실행 취소 · 다시 실행 · 채보 파일 불러오기 · 내보내기, 그다음 상태 태그 + 주 버튼 「검토 요청」                                         |
| 검토   | 「읽기 전용」 · 내보내기, 그다음 상태 태그 · 작성자 + 기여 라벨 · 보조 「수정 요청」 · 주 버튼 「공개」. 둘 다 늘 보이고 검토 대기가 아니면 비활성이다 |

상태 태그는 기존 상태 태그를 쓴다([태그](../components/tag.md)).
기여자 모드에서 검토를 요청한 동안에는 「검토 요청」 자리에 보조 「요청 취소」 가 오고, 읽기 전용이 되어 작성 도구를 숨긴다.

### 「검토 · N」 탭

레일 세 번째 탭이다. N은 남은 댓글 수다.

| 순서 | 내용                                                                                                                                                                                               |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 단계 줄. 막대 4칸(작성 중 · 검토 대기 · 수정 요청 · 공개), 지금 단계까지 채운다. 칸 이름은 화면 읽기에만 두고, 막대 →12→ 「n / 4」 `nl-metadata` 흐림 →8→ 지금 단계 이름 `nl-emphasis-label` 한 줄 |
| 2    | 「0:42.300 에 댓글」 + 여러 줄 입력 + 「남기기」                                                                                                                                                   |
| 3    | 댓글 목록                                                                                                                                                                                          |

이 탭에서도 캔버스는 채보 작성 화면이고, 오른쪽은 노트 속성 칸 그대로다.

해결 안 된 댓글 시각은 두 곳에 표시한다. 캔버스에는 가로 점선 2px를 판정선 위에서도 보이게 맨 위 층에 긋는다.
파형에는 위아래 눈금 2 × 12를 둔다. 둘 다 `--nl-feedback-warning-marker` 이고, 스냅 확인 점선과 같은 색이다.

### 트릴

에디터 캔버스의 트릴은 공개 뷰어와 같은 게임식 모양이다([공개 채보 뷰어 트릴](./chart-viewer.md#트릴)). 공용 계산 `lib/chart-pattern/trillShape.ts` 를 함께 쓴다.
선택과 충돌은 몸통 테두리로 보인다.

## 동작

- 댓글 시각을 누르면 그 시각으로 간다.
- 운영자는 댓글을 「해결」 로 표시할 수 있다. 해결 전 내 댓글은 「삭제」 할 수 있다.

## 부품 고유 크기

| 이름           | 값     | 쓰는 곳                 |
| -------------- | ------ | ----------------------- |
| 단계 줄 막대   | 4      | 「검토 · N」 탭 단계 줄 |
| 댓글 시각 점선 | 2px    | 캔버스                  |
| 댓글 시각 눈금 | 2 × 12 | 파형 위아래             |
