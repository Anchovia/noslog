# 이벤트

주소 `/events` · `/events/[id]` · `/events/new` · `/events/mine` · `/events/[id]/edit` · 코드 `features/events`

## 구성

### 목록

| 순서 | 내용                                                                                                    |
| ---- | ------------------------------------------------------------------------------------------------------- |
| 1    | 제목 줄. 제목은 「소식」 과 입구 탭([소식 입구](./news.md#소식-입구)) →24→                              |
| 2    | 상태 필터 칩 「진행 중 N · 예정 N · 종료 N」(`FilterChipLinks` M, [필터](../components/filter.md)) →24→ |
| 3    | 배너 카드 목록                                                                                          |

제목 줄 오른쪽에는 「내 글」 고스트 M(로그인했을 때)과 「글쓰기」 보조 M을 둔다([버튼](../components/button.md)).
글을 쓸 수 없으면 「글쓰기」 를 비활성으로 두고 제목 아래에 이유를 한 줄 적는다. 서열 투표 잠금과 같은 방식이다([악곡 상세 — 평가](./music-detail.md#평가)).

배너 카드는 좁은 폭(672 미만) 한 열, 672 이상 두 열이다. 카드 사이는 세로 24 · 가로 16.

| 순서 | 카드 안                                                                                     |
| ---- | ------------------------------------------------------------------------------------------- |
| 1    | 배너 2.4 : 1, 모서리 `radius/container`. 배너가 없으면 같은 비율의 `surface/sunken` 면 →12→ |
| 2    | 제목 `entity-title` →4→                                                                     |
| 3    | 기간 `body-secondary` subdued                                                               |

카드에는 면이 없다. 상태는 칩이 말하므로 카드에 상태 태그를 두지 않는다.

### 상세

| 순서 | 내용                                                            |
| ---- | --------------------------------------------------------------- |
| 1    | 상태 태그 · 기간 · 작성자 한 줄 →8→ 제목(공지 상세와 같은 문법) |
| 2    | 배너                                                            |
| 3    | 본문(공지 렌더러, [상세 본문](./news.md#상세-본문))             |

본문 이미지는 본문 폭을 넘지 않고 원래 비율을 지킨다. 모서리는 `radius/container`. 설명은 화면 읽기용 대체 글로만 두고 캡션은 달지 않는다.

### 글쓰기

글쓰기는 관리자 공지 작성과 같은 편집기 · 흐름을 쓴다([관리자 공지 작성](./admin-announcements.md)).
「게시 요청」 작은 창에는 시작일 · 종료일 · 대표 이미지(선택)를 둔다.
시작일과 종료일은 한 줄에 두지 않는다. 좁은 창에서 날짜가 잘려서다.

수정 요청 · 반려 사유는 편집 화면 맨 위 알림으로 보인다([상태 메시지](../components/status-message.md)).

「내 글」 목록은 공지 목록 줄 부품을 쓴다. 상태 태그 · 제목 · 오른쪽 날짜가 한 줄이다([공지 줄](./news.md#공지-줄)).

## 상태

- 빈 탭은 한 줄 안내만 둔다.
- 반려된 글의 고치기 화면은 안내 →16→ 「삭제」 하나만 둔다.

## 동작

상태 필터 칩은 주소 `?tab=` 로 상태를 갖는다.

삭제는 고치기 화면 아래 줄 왼쪽 끝의 보조 「삭제」 버튼에서 시작한다. 누르면 작은 확인 창이 뜬다.
확인 창에는 닫기가 없고 「취소」 와 채운 빨강 「삭제」 만 있다([대화상자](../components/dialog.md)).
공개 중인 글이면 확인 문장에 「목록과 홈에서도 바로 사라진다」 는 한 줄을 더한다.
