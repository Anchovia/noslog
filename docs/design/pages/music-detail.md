# 악곡 상세

주소 `/music/{index}/{difficulty}` · 코드 `features/music/components`(`music-detail-page.tsx` · `music-entity-header.tsx` · 탭마다 `*-panel.tsx`)

## 구성

머리 →16→ 1단 탭 4개 「개요 · 내 기록 · 랭킹 · 평가」(→ [탭](../components/tabs.md)) 아래에 탭 내용을 둔다.
탭은 주소 `tab` 으로 가리키고 값은 `detail · record · ranking · tier` 그대로다.

탭 내용 안의 간격은 모든 탭이 같다.

| 사이                              | 값                                        |
| --------------------------------- | ----------------------------------------- |
| 탭 → 첫 제목                      | 24                                        |
| 구역 사이                         | `--nl-section-gap`                        |
| 구역 제목(`section-title`) → 내용 | `--nl-section-title-gap`                  |
| 펼침 요약 줄의 구역 제목 → 내용   | 16(→ [펼침](../components/disclosure.md)) |

접히는 구역끼리도 다른 구역과 같이 구역 사이 간격을 둔다. 펼침 사이에 구분선을 넣지 않는다.

수치 띠 상자는 세 칸이다.

| 칸      | 내용                                                                         |
| ------- | ---------------------------------------------------------------------------- |
| 위 칸   | 「그레이드」                                                                 |
| 가운데  | 선택한 난이도의 공식 레벨 + 공개 서열 값(Basic S · 990k · Pianist · Recital) |
| 아래 칸 | 「채보 보기 › · 플레이 영상 ›」 늘 두 칸(수치 띠 아래 동작 줄)               |

그레이드 칸은 위 줄 왼쪽에 「그레이드」(`control`), 오른쪽에 내 Grd 를 쓴다.
내 Grd 는 정수 `page-title--fixed` + 소수 `component-title` 이다(→ [기초값 — 글자](../foundations.md#글자)). 글자색은 막대에서 그 위치의 색이고, 최대값을 모르면 기본색이다.
뒤에 「/ 최대 Grd」 를 `body-secondary` 흐림으로 붙이고, 최대값은 Pianist 색이다. 공식 레벨이나 노트 수가 없으면 흐린 「/ —」 다.
기록이 없으면 「—」, 로그아웃이면 「로그인하고 보기 ›」 다.
위 줄 →8→ 진행 막대. 칸 안쪽은 8/12, 아래 12 다.

진행 막대는 막대 목록 트랙 8(→ [그래프](../components/charts.md))이고 0 에서 최대 Grd 까지다. 최대값을 모르면 빈 트랙이다.
채움은 등급 그라데이션이며 색은 oklch 로 섞는다.

| 구간       | 색                                   |
| ---------- | ------------------------------------ |
| 0–40.3%    | B · B+ = 판정 NEAR 파랑              |
| 49.5–59.6% | A · A+ = `feedback/destructive` 빨강 |
| 73.7%      | S                                    |
| 81.9%      | 990k                                 |
| 87.9–100%  | Pianist                              |

공식 레벨 칸은 라벨 「공식 레벨」, 값은 서열 값 그라데이션 색이다. 값이 없으면 흐린 「—」 를 둔다. 수치 띠에서 값 없는 칸을 두는 곳은 이 칸 하나다.
공개 서열 값은 미등재면 칸을 두지 않는다.
아래 칸은 없는 쪽도 칸을 두고 칸 전체를 흐리게 둔다(→ [수치 띠 — 아래 동작 줄](../components/stat-strip.md#아래-동작-줄)).

### 개요

위에서부터 패턴 경향 · 내 기록 요약 띠 · 채보 정보 · 서열 변경 이력이다.

채보 정보의 BPM 바로 아래 줄은 변속 횟수 「78회」 다. 노트 수 아래에는 테누토 수 · 글리산도 수 · 트릴 수 세 줄을 둔다. 0 은 「0회」 · 「0」 으로 쓰고, 공개 채보가 없으면 네 줄 모두 「—」 다(→ [기능 규칙](../product-rules.md)).

패턴 경향은 채보 데이터로 계산한 가로 막대 4줄(계단 · 연타 · 폴리리듬 · 즈레)과 변박 칸 막대 한 줄이다(→ [기능 규칙 — 패턴 경향](../product-rules.md)). 막대 값 글자는 「NN%」 다.
막대 색은 값 × 4 의 가까운 정수 0–4 에 `--nl-pattern-level-*` 를 쓴다(기존 토큰 별칭: 데이터 파랑 · 판정 NEAR · 판정 JUST · 난이도 Hard · 난이도 Expert).
변박 줄은 [막대 목록](../components/charts.md#막대-목록)의 칸 막대 3칸이고, 단계만큼 칸을 채우고 값 자리에 「없음 · 적음 · 보통 · 많음」 을 쓴다. 채운 칸 색은 단계 ÷ 3 × 4 의 가까운 정수 단계 색(적음 1 · 보통 3 · 많음 4)이다. 기록이 없으면 빈 칸 3개와 「—」 다. 기준을 바꿔도 변박 줄은 그대로다.
제목 줄에 ⓘ 를 두고, 오른쪽 끝에 기준 전환 고스트 작은 단추(지금 기준 글자 「Real 기준」 · 「전곡 기준」 + ⇄ 아이콘)를 둔다. 누르면 다른 기준으로 바뀌고, 접근성 이름은 바뀔 기준(「전곡 기준으로 보기」)이다.
공개 채보가 없으면 단추를 두지 않고, 막대 상자를 평가 탭 패턴 투표 잠금과 같은 모양으로 가린다. 뒤의 막대는 뜻 없는 자리표시 값이고, 카드에는 이유 한 줄 「공개 채보가 없어 계산할 수 없어요」 만 둔다. 읽기에 실패하면 막대 자리에 오류 상태와 「다시 시도」 를 둔다.

ⓘ 는 「패턴 경향 기준」 정보 창(→ [대화상자](../components/dialog.md))을 연다. 개요 창에는 계산 기준 문장, 항목마다 세는 법, 빈 값 규칙을 담는다.
평가 탭 패턴 투표의 창은 기준 문장 「모든 곡 대비 세기 · 곡 안 비중 아님」, 단계 0–4 이름과 막대 단계 색 네모 8, 공개 규칙, 축 정의를 담는다.
단계 이름은 없음 · 조금 나옴 · 뚜렷하게 나옴 · 심한 편 · 악곡의 특색일 정도다. 색 네모는 모서리가 없고, 검정 「합격까지」 범례와 같은 막대 범례다.

내 기록 요약 띠는 최고 점수 · 내 순위/참가자 · 플레이다. 순위가 없으면 그 칸을 두지 않는다.
로그아웃이면 제목 줄 오른쪽 끝에 「로그인하고 보기 ›」 를 둔다.

채보 정보는 면 없는 구분선 줄 목록이다. 줄 글자는 구역 제목과 같은 선에 선다.
BPM · 노트 수 · 길이 · 수록일은 비어 있어도 줄을 둔다. 값 자리에 흐린 「—」(`content/subdued`) + 밑줄 글자 「추가」 를 쓰고, 로그아웃이면 「추가」 가 로그인으로 간다.
값이 있으면 줄 끝에 ⋯(고스트 아이콘)를 두고 메뉴는 「수정 제안」 하나다. 로그아웃이면 ⋯ 가 없다.
내 제안이 대기 중이면 상태 태그 「검토 중」(경고)을 둔다.
출처(`chart_field_sources`)가 없는 값은 흐린 글자 + 분류 태그 「확인 전」 이다. 추정값과 확인된 값을 가른다.
⋯ · 「추가」 · 태그는 모두 줄 높이를 늘리지 않게 위아래 · 오른쪽을 당긴다.
그 밖의 줄은 값이 있는 행만 둔다.
해금 조건은 단계마다 한 줄 「(→ )이벤트 이름 · 별가루 N」 이다. 이름은 보는 언어로, 숫자는 이 난이도 몫만 쓴다.

제안 창은 기본 크기(600) 창이다. 위에서부터 지금 값, 값 칸(칸마다 도움말), 근거 세그먼트 「영상 · 공식 사이트 · 직접 확인」, 주소, 설명, 안내 문장, 주 버튼 「제안하기」 다.
안내 문장은 「운영자가 확인한 뒤 반영됩니다 · 지금 검토 대기 N건 · 가장 오래 기다린 제안 N일」 이고, 대기가 없으면 뒤 문장을 뺀다.

서열 변경 이력은 구역 펼침 안에 날짜 묶음 하나를 카드 하나로 둔다. 공용 펼침 `card` · 요약 줄 컨트롤 높이 · 안쪽 16 · 카드 사이 8 이고 모두 기본 접힘이다.
구역 · 날짜 · 항목 세 단계는 들여쓰기 대신 상자로 가른다.

### 내 기록

한 열이다. 다섯 구역 펼침을 위에서부터 쌓는다.

| 구역        | 기본 | 내용                                                |
| ----------- | ---- | --------------------------------------------------- |
| 최고 기록   | 펼침 | 수치 띠                                             |
| 누적 요약   | 펼침 | 수치 띠                                             |
| 판정 분석   | 펼침 | 소구역 요약 · 판정 · 음표별 성공률 · 최근 판정 추이 |
| 성장 추이   | 접힘 | 그래프만. 표는 화면 읽기용. 점이 없으면 빈 틀       |
| 최근 플레이 | 접힘 | 카드 선 목록                                        |

등급은 화면 표기(A+ · B+)로 쓴다. DB 코드 A2 · B2 를 그대로 쓰지 않는다.
성장 추이 · 최근 판정 추이는 선 그래프 규칙(→ [그래프](../components/charts.md))을 따른다.

최근 플레이 줄은 날짜 · 등급 16 · 점수다.
펼친 내용은 위아래 8 · 들여쓰기 없음 · 면 없음이다. 숫자 행만 `metric-value` 이고, Grd 는 소수 둘째 자리까지, 「최고 점수 대비」 를 둔다.

판정 분석의 소구역 사이는 24, 소제목(`component-title`) → 내용은 8 이다.
「요약」 은 「나」 · 「평균」 누적 막대 두 줄을 늘 둔다. 값이 없는 줄은 `surface/control` 한 줄이다. 기준 인원은 제목 줄 오른쪽 끝에 쓴다.
「요약」 다음에 「판정」 목록(색 점이 범례), 「음표별 성공률」 이 온다.
유사 Grd 평균은 켜기 없이 값 아래 메타로 보인다. 평균이 없는 항목은 그 줄을 두지 않는다.
최근 판정 추이 지표는 ◆JUST · MISS · FAST/SLOW 세그먼트다. 선 색은 판정 색이다(◆JUST 분홍 · MISS `feedback/destructive` 빨강 · FAST 판정 NEAR 파랑 · SLOW 주황). 비면 빈 틀 + 가운데 「기록 없음」 이다.

### 랭킹

제목도 카드 면도 없이 점수 자 →`--nl-section-gap`→ 「순위」 구역이다. 탭과 점수 자 사이는 24 다.
구역 이름은 낭독용 sr-only 제목으로만 남긴다. 내 순위는 순위표 안 내 행(면 + 낭독용 「내 순위」)이 말한다.

점수 자는 가로 점수 축 하나다. 925k 에서 100만까지 divider 선 하나로 긋는다. 폰 폭은 범위를 좁히고, 하위 5% 가 925k 보다 낮으면 거기까지 넓힌다.
아래 라벨은 950k · 990k · Pianist 이고 각 목표 색이다(S 노랑 · 990k 살구 · Pianist 분홍). 좁아 겹치면 990k 라벨만 뺀다.
점수 자는 면 · 제목이 없다. 좌우 안쪽 12 로 자 시작선을 순위표 줄 안쪽과 맞춘다.
높이 72 = 핀 줄 48 + 자 → 라벨 8 + 라벨 줄 16 이다. 끝 점수 핀은 자 안쪽으로 16 당기고 점은 제자리에 둔다.

참가자는 한 명도 빠짐없이 자 위의 점 6 으로 남는다. 나는 점 8 · 판정 JUST 노랑, 그 밖은 `local-data/bucket-5` 다.
그 위에 사진 핀을 한 줄로 세운다. 핀 높이에는 뜻이 없다.
사진 핀은 원 24(나 28) + 테두리 `--nl-stroke-strong`(`border/ring`, 나는 판정 JUST 노랑)이고, 끝이 자 위 점수 자리를 가리킨다.
30명 이하면 모두, 넘으면 상위 3명 + 나만 핀을 세운다.
52 보다 가까운 핀은 점수가 가장 높은 대표 하나 + 오른쪽 위 「+N」 으로 묶는다. 사진끼리 겹치지 않는다.
나도 같은 거리 규칙을 따르고, 내가 낀 묶음은 내가 대표가 되고 나머지가 「+N」 으로 접힌다.
「+N」 은 필터 개수 배지 모양 원 20 · `metadata` + `--nl-stroke-default` `border/divider` 이고 늘 핀 오른쪽 위다.

「순위」 구역은 제목 줄이 없다. 로그아웃일 때만 목록 위 오른쪽 끝에 「로그인하고 내 순위 확인 ›」 한 줄을 둔다.
순위표는 유저 랭킹 페이지와 공용이다. 여기서 고치지 않는다. 순위표 머리 값은 글자 클래스(값 `metric-value` · 라벨 `metadata`)로 쓴다.
곡 순위의 점수 글자는 점수 목표 색 `scoreTone` 이다(950k 이상 S 노랑 · 990k 이상 990k · Pianist, 그 아래 기본 글자색).
곡 순위 · 핀 창 목록의 점수 칸은 만점 「1,000,000」 폭(7ch + 쉼표 2)으로 고정한다. 그래서 등급 아이콘이 행마다 한 줄에 선다.

### 평가

세 구역(패턴 투표 · 서열 투표 · 의견)은 모두 구역 펼침(기본 펼침)이다.
제목 줄이 펼침 줄이 되므로, 그 줄에 있던 저장 상태 · 로그인 링크는 펼친 내용 첫 줄 오른쪽 끝으로 내린다.

패턴 투표는 카드 면 없는 구분선 목록이다. 줄은 이름 + 숫자 척도 0–4(→ [폼 컨트롤](../components/form-controls.md))다.
펼친 내용 첫 줄 왼쪽에 기준 한 줄 「모든 곡 기준 · 0 없음 – 4 많음」(`metadata`, 숫자만 기본 글자색) + ⓘ(개요와 같은 기준 창)를 둔다. 잠겨 있어도 보인다.
이 줄은 공용 제목 줄이고 최소 높이 28(`--nl-type-line-height-28`)이다. 버튼이 나타나도 목록이 밀리지 않게 한다. 좁으면 저장 상태가 다음 줄 오른쪽으로 간다.
기준 줄 →8→ 척도.
저장 버튼은 없다. 누르면 바로 저장하고, 연달아 누르면 0.4초 모아 한 번 저장한다.
제목 줄 오른쪽 끝 한 곳에 저장 중 · 저장됨(2초) · 실패 + 「다시 시도」 를 쓴다. 평소에는 「선택 해제」(확인 창)이고, 잉크를 오른쪽 선에 당긴다.
평가할 수 없으면 목록을 흐림 5px 로 덮고, 가운데에 떠 있는 창 규격 카드를 띄운다. 카드는 이유 한 문장 + 로그아웃이면 주 버튼 M 「로그인」 이다. 흐림은 입력 영역 잠금과 공개 채보가 없는 개요 패턴 경향에만 쓴다.
패턴 투표에는 의견 칸이 없다.

서열 투표는 카드 하나 안의 선 목록 「Basic · S … 값 · 투표 N명 ⌄」 이다. 카드는 누르지 않는 묶음 상자라 면 `surface/surface` · 둘레 없음 · 그림자 `--nl-card-shadow` · 모서리 `radius/large` 다. 줄 선은 `border/row` 다.
줄은 컨트롤 높이다. 여는 줄의 올림 · 누름은 줄 전체 면(`interaction/row`)이고 좌우 12 를 넓혀 칠한다. 구분선은 글자 선 안쪽이다.
평균이 없으면 값 자리에 「—」 + 인원을 쓴다. 둘 사이는 가운뎃점 없이 8 이다.
펼친 내용은 같은 카드 안에 위 8 · 아래 8 · 사이 8 로 둔다. 분포(막대 목록 `BarList` · 나온 값마다 한 줄 · 제목 없음, → [그래프](../components/charts.md#막대-목록)) 아래에 「값 선택 셀렉트(내 투표가 기본값) + 투표 저장」 한 줄을 둔다. 한 단계 더 누르지 않는다.
자격이 없으면 입력을 두지 않는다. 펼칠 것이 없으면 누르지 않는 줄이다(⌄ 없음).
로그아웃이면 제목 줄 오른쪽 끝에 「로그인하고 투표하기 ›」 제목 링크를 둔다. 결과는 그대로 공개한다.

의견은 공용 제목 줄 →16→ 작성 칸 →8→ 목록 · 빈 안내다.
의견이 둘 이상이면 목록 위 왼쪽에 정렬(고스트 · 최신순 · 좋아요순)을 둔다.

의견 줄은 상자 없이 아바타 32 열 + 내용 열(사이 12)이다. 줄 사이는 구분선 없이 16 이다.

| 순서 | 자리         | 내용                                                                                              |
| ---- | ------------ | ------------------------------------------------------------------------------------------------- |
| 1    | 첫 줄        | 이름 `emphasis-label` · 날짜 `metadata` · ⋯                                                       |
| 2    | 본문         | 첫 줄 →4→ 본문 `body-secondary` 기본색                                                            |
| 3    | 번역 안내 줄 | 있을 때만                                                                                         |
| 4    | 동작 줄      | 좋아요 하트 · 번역 보기 · 답글. 텍스트 버튼 M 높이. 눌린 하트 = 채움 + `local-data/categorical-4` |
| 5    | 답글 열기    | 「답글 N개 ⌄」                                                                                    |
| 6    | 답글         | 한 단계 · 사진 24 · 줄 사이 12 · 오래된 순. 작성 칸은 목록 끝 제자리                              |

작성 칸은 쉬는 상태에서 아바타 32 + 한 줄 입력 L 이다. 누르면 여러 줄 96 · 도움말 8 · 「취소 · 의견 작성」 M 오른쪽 12 로 펼친다. Esc 로 접힌다.
내 의견이 있으면 맨 위 작성 칸 대신 내 줄 ⋯ 「수정」 이 그 줄 안에서 펼친다.
로그아웃이면 제목 줄 오른쪽 끝에 「로그인하고 의견 남기기 ›」 를 두고 작성 칸이 없다. 기록이 없으면 안내 한 줄이다.
저장 · 삭제 · 신고 중에는 진행형 라벨을 쓰고, 입력칸은 비활성 면 대신 읽기 전용이다.

집계 결과는 개요 · 머리에만 둔다.

## 폭별

좁은 폭 · 중간 폭(1055 이하)은 위 「구성」 대로 한 열이다.

넓은 폭(1056 이상)은 왼쪽 열(악곡 레일 폭, → [악곡 목록](./music-list.md))에 머리 카드를 sticky(위 24)로 두고 오른쪽에 탭 내용을 둔다.
머리 카드에서 자켓은 열 폭 정사각, 난이도는 세로 행(컨트롤 높이), 수치 띠는 세로 목록이다. 난이도 · 그레이드 · 수치 칸 · 동작 칸의 잉크는 모두 열 가장자리에서 12 에 선다.

| 탭      | 넓은 폭 배치                                                    |
| ------- | --------------------------------------------------------------- |
| 개요    | 두 열 — 왼쪽 패턴 경향 · 오른쪽 나머지, 열 사이 16              |
| 평가    | 2:1 두 열 — 왼쪽 패턴 투표 · 서열 투표, 오른쪽 의견, 열 사이 16 |
| 내 기록 | 한 열                                                           |
| 랭킹    | 한 열                                                           |

제목은 넓은 폭에서도 24/32 다. 좁은 열에서 제목이 잘리지 않게 한다.
폭을 바꿔도 선택 · 주소 · 입력이 유지된다.

## 상태

탭 · 난이도를 바꾸는 동안 머리는 이전 값을 `content/subdued` 색으로 둔다. 서열 칸 · 그레이드를 비우지 않는다.
탭 내용 자리는 그 탭의 실제 틀 스켈레톤이다.

| 탭      | 스켈레톤                                                                     |
| ------- | ---------------------------------------------------------------------------- |
| 개요    | 패턴 경향 막대 · 내 기록 띠 · 채보 정보 네 줄(BPM · 노트 수 · 길이 · 수록일) |
| 내 기록 | 다섯 구역. 로그아웃은 안내 그대로                                            |
| 랭킹    | 점수 자 자리 72 · 순위표 머리 · 곡 순위 줄 10                                |
| 평가    | 척도 · 투표 네 줄 · 의견 줄 2                                                |

곡마다 있거나 없는 구역(서열 변경 이력 · 해금 조건 · 의견 작성 칸)은 스켈레톤으로 그리지 않는다.

내 기록이 없어도 다섯 구역 틀과 펼침 기본값을 그대로 둔다. 내 값 자리만 흐린 「—」 다.
누적 수치도 「0」 이 아닌 「—」, 판정 줄은 비율 없이 「—」 하나다. 요약 「나」 는 비활성 한 줄이다.
유사 Grd 평균은 이 곡 기록 대신 유저 Grd 기준으로 그대로 보인다. 성장 추이는 빈 틀, 최근 플레이는 「최근 플레이 없음」 이다.

랭킹 기록이 0명이면 점수 자 · 페이지 넘김 없이 순위표 머리 줄 아래에 줄 한 칸(48 · 아래 `border/row`)만 둔다. 칸 가운데에 흐린 `body-secondary` 「아직 플레이된 기록이 없습니다.」 를 쓴다. 점수 자는 1명 이상일 때부터 둔다.

## 동작

핀을 누르면 창을 열지 않고 바로 그 사람(묶음이면 대표)의 순위 줄로 간다. 그 줄이 있는 페이지로 넘기고, 줄을 가운데로 옮기고, 이름 링크에 포커스를 둔다.
패턴 투표 저장 · 의견 작성 칸은 위 「평가」 대로다.

## 하지 않는 것

랭킹에 「참가자 N명」 · 구역 제목 「순위」 · 「내 순위 N / M」 글자를 두지 않는다.
점수 자에 세로축(분포)을 두지 않는다. 레이더 · 점수 분포의 세로 막대도 쓰지 않는다.
판정 분석 · 최근 판정 추이 · 최근 플레이에 NEAR 를 보여 주지 않는다. 합계 · 비율 계산에는 넣는다.
서열 투표 결과를 흐림으로 가리지 않고, 설명 문장을 두지 않는다.
시안은 구조만 따른다. 간격 · 글자 · 색 · 크기는 이 가이드 값을 쓰고, 시안의 회색 막대 · 띠 경계 같은 대략값은 쓰지 않는다.
