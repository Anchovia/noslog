# 이용약관

주소 `/terms` · `/terms/history` · `/terms/history/[version]` · 코드 `features/terms`

## 구성

| 순서 | 내용                                                                                                                    |
| ---- | ----------------------------------------------------------------------------------------------------------------------- |
| 1    | 머리 — 제목 `page-title` →8→ 최종 수정 · 시행 날짜 `metadata` 흐림 →16→                                                 |
| 2    | 목차(좁은 · 중간 폭은 접힘 카드, 넓은 폭은 레일) →32→                                                                   |
| 3    | 본문 13개 조와 부칙 — 조 사이 `--nl-section-gap`, 조 제목 `section-title` → 내용 `--nl-section-title-gap`, 글 `nl-body` |

폭별 모양 · 목차 동작 · 이전 버전 화면은 [개인정보 처리방침](./privacy.md)과 같고, 스타일과 목차 부품도 같은 것을 쓴다. 요약 묶음은 없다.
「법률 검토 대기」 는 제1조 안의 상자 경고([상태 메시지](../components/status-message.md))로 둔다.
제3조 끝에 「이전 버전 보기」 링크, 제10조 끝에 처리방침 파기 절로 가는 링크를 둔다.

## 하지 않는 것

- 요약 판을 따로 두지 않는다.
- 오락실 사진 · 게시판 조항을 넣지 않는다. 이용자가 올리는 기능이 없다.
