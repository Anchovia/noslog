# 대화상자

`ModalDialog` · `FullScreenDialog` · `LoginPrompt` · 이미지 내보내기 창 `nl-image-share`

## 대화상자 (가운데 창)

`ModalDialog` — 머리 · 본문 · 발 세 칸.

- Spectrum 2 대화상자 — 면 `surface/elevated` · 모서리 `radius/overlay` · 그림자 없음 · 머리 · 발 구분선 없음. 뒤 가림막 `surface/scrim`(#000 60%). 제목은 22 bold(`content/strong`), 본문 글자는 body M(16).
- 크기 `size` = small 440 · medium 600(기본) · large `--nl-container-reading`. 화면 가장자리 16 은 늘 비운다. 높이 상한은 화면 − 48.
- 머리 = 제목 `nl-component-title` 왼쪽 + 오른쪽 닫기(`IconButton` · 아이콘 20, `showClose` 기본은 확인 창이 아니면 보임). 672 이상은 Spectrum 2 Dialog 여백 — 안쪽 위 · 좌우 32, 닫기는 컨트롤 높이 정사각(`radius/control`). 이미지 내보내기 창은 이 여백 · 닫기 대신 [제 값](#이미지-내보내기-창)을 쓴다. 671 이하 폰 창은 안쪽 위아래 12 · 오른쪽 16 · 왼쪽 24.
- 본문 = 여기만 스크롤 · 세로 간격 16 · 글자 body M · 설명은 `nl-body-reading` 흐림. 안쪽은 672 이상 제목 → 본문 16 · 좌우 32 · 발이 없으면 아래 32, 폰 24. 본문 칸은 줄지 않는다(창이 낮으면 본문이 스크롤). 남는 높이를 받아 목록만 줄이는 고정 기록 창만 예외.
- 발 = 버튼 기본 크기 · 오른쪽 끝에 「보조 → 주」 · 버튼 사이 12(672 이상). 안쪽은 672 이상 32, 폰 16 · 24.
- 페이지에서 창 규격을 덮어쓰지 않는다.

## 확인 창

`variant="confirm"` — 되돌릴 수 없는 결정 · 경고.

- small · 제목 `nl-section-title` · 닫기 없음 · 구분선 없음 · 한 판(안쪽 24 · 제목 → 본문 12 · 본문 → 버튼 24).
- 확정 버튼이 되돌릴 수 없는 일이면 채운 빨강(위험), 「취소」 는 보조.
- 입력 칸이 있으면 확인 창이 아니라 기본 창으로(회원 탈퇴 = 지워지는 것 면 상자(`surface/control` · `radius/control` · 안쪽 16) → 「1. Discord로 다시 인증」 → 「2. 확인 글자 입력」(인증 전 잠김) · 버튼은 발).

## 창 안 내용 — 종류별

| 종류      | 구성                                                                                                                                                                                                                    |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 정보 창   | 설명 한 줄 → 소제목 →8→ 구분선 줄 목록 `nl-info-rows`(줄 = 이름 칸(가장 긴 이름 폭) · 값/설명 칸, 줄 높이 = 컨트롤 높이 · 위아래 8 · 좌우 4, `--value` = 값 오른쪽 끝). 예: 패턴 경향 기준 · 서열표 안내 · 곡 정보 제안 |
| 고르기 창 | 고른 것 칩 한 줄 `nl-pick-slots` → 돋보기 검색 칸 → 고르기 줄 목록 `nl-pick-list`. 예: 선호 오락실 · 고정 기록 · 프로필 업적 · 검정 채보 선택 · 관리자 과제곡 검색                                                      |
| 폼 창     | 버튼은 모두 발(본문 안 버튼 없음). 고칠 수 없는 값(오락실 제보 「대상 오락실」)도 칸 라벨 →4→ 값                                                                                                                        |

- 창 안 소제목은 모두 `nl-metadata` 흐림.
- 고른 것 알약 = M 높이 · `radius/full` · 「n · 이름」 + 빼기 × 24. 채운 알약 = `surface/canvas` 면 + `border/input` 선, 눌러 고른 알약 = `surface/control` 면 · 선 없음(안의 난이도 색 글자는 기본 글자색). 빈 칸은 빈 자리 경계 `border/ring` →8→ 쓰는 법 한 줄 `nl-metadata`.
- 고르기 줄 목록 = 최대 min(320, 40dvh) 스크롤 · 줄 = 이름 `nl-emphasis-label` + 보조 `nl-metadata` · 고른 줄 오른쪽 체크 · 줄 사이 구분선 · 줄은 줄어들지 않음. 선호 오락실은 검색어가 없으면 「지금 선택」 묶음(묶음 라벨 → 목록 8).
- 발에 「초기화 · 적용」 이 있는 고르기 창(고정 기록 · 프로필 업적)도 오른쪽 끝 「초기화 → 적용」.

## 로그인 안내

`LoginPrompt` — 로그아웃 상태로 폼 창(신고 · 피드백 · 오락실 제보)이나 연결이 필요한 동작을 열 때.

- 작은 창. 원 면 · 아이콘 · 마크 없이 글자만.
- 제목 `nl-component-title` 「로그인하면 ~할 수 있어요」(연결이면 「…을 연결하면 ~를 쓸 수 있어요」) →4→ 한 줄 설명. 발 = 「취소 · 로그인」(또는 「연결」).
- 덧붙인 안내 줄 · 번호 원 · 로고 마크를 넣지 않는다.

## 좁은 폭

- 672 미만에서 입력 칸이 있는 창은 [전체 화면 창](#전체-화면-창) 모양으로 연다(`ResponsiveDialog`, `ModalDialog` 는 CSS 가 내용으로 가른다). 입력 칸이 없는 창 · 확인 창은 폰에서도 가운데 창이다.
- 두 길 모두 머리 · 본문(안쪽 24/16 · 세로 간격 32) · 발이 전체 화면 창과 같다. `ModalDialog` 가 CSS 로 여는 전체 화면도 면 · 머리 아래 · 발 위 구분선 · 창 제목 글자가 전체 화면 창과 같다. 발에 「취소」 를 두지 않으므로 `ResponsiveDialog` 는 `fullScreenFooter` 에 주 동작만 준다.
- 폭마다 내용 · 발이 다르면 `ResponsiveDialog` 의 `modalChildren` · `fullScreenChildren` · `modalFooter` · `fullScreenFooter` 로 나눠 준다. 없으면 `children` · `footer` 를 함께 쓴다.

## 전체 화면 창

`FullScreenDialog` — 필터 · 제보처럼 긴 창의 좁은 폭 모양.

- GitHub 필터 창 방식이다. 면 `surface/canvas` 이고, 머리 아래 · 발 위에 1px `border/divider` 선을 둔다.
- 머리 = 높이 `--nl-header-height` · 위아래 8 · 왼쪽 16 제목 `nl-component-title` + 오른쪽 닫기 L · 아이콘 24. 창 제목 · 필터 묶음 제목 글자는 [기초값 — 글자](../foundations.md#글자)의 필터 창 값이다.
- 본문 안쪽 24/16 · 세로 간격 32 · 그룹 제목 → 내용 8 · 그룹 사이 선 위아래 24.
- 본문만 스크롤하고 머리 · 발은 고정이다.
- 발 = 안쪽 16(아래는 안전 영역까지). 필터는 왼쪽 「초기화」 고스트 L(`onReset`, 잉크를 16 선에 맞춰 당김) + 남는 폭 「결과 N개 보기」. 글 쓰는 입력 창(`form`)은 주 동작 하나를 오른쪽 글자 폭으로(Google 피드백 보내기).
- 닫기는 머리 × 가 맡아 발에 「취소」 를 두지 않는다.

## 이미지 내보내기 창

`nl-image-share` — 프로필 카드 · 서열표 이미지.

- 1055 이하 = 전체 화면. 바탕 `surface/canvas` · 머리는 전체 화면 창과 같음 · 이미지는 화면 폭 끝까지(모서리 없음) · 본문 안쪽 16 · 버튼 줄은 아래 고정(위 구분선 · 안쪽 16 + 안전 영역, 주 「이미지 저장」 위 · 「복사 · 공유」 아래 같은 폭 L) · 아래에서 올라옴(⑫).
- 1056 이상 = 가운데 창(대화상자 면 `surface/elevated` · 둘레 없음 · 그림자 없음). 본문만 스크롤하고 버튼 줄(같은 면)은 창 아래 고정이라 내용이 길어도 저장 버튼 · 제목 · 닫기가 늘 보인다. 닫기는 컨트롤 높이 정사각 · 아이콘 24.
- 프로필 카드는 카드 묶음을 세로 가운데로, 카드 →8→ 아래 한 줄 `nl-metadata` 「1200 × 630 · 모드 · 기준일」.
- 그 화면의 담는 범위 · 고르기는 화면 문서([프로필](../pages/profile.md) · [서열표](../pages/tiers.md)).

## 포커스

- 열면 창 안으로, 닫으면 연 트리거로 돌아간다. 트리거 없이 외부에서 연 창은 `onCloseAutoFocus` 로 실제로 연 동작에 돌려준다.
- 메뉴에서 연 창을 닫으면 그 메뉴 버튼(⋯)으로 돌아간다.
