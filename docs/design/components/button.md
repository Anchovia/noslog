# 버튼

`Button` · `ActionButton` · `ButtonLink` · `IconButton` — `components/ui/button.tsx` 외

## 쓰는 곳

- 저장 · 보내기 · 창 열기 같은 동작. 화면 이동은 링크 모양이면 링크, 버튼 모양이면 `ButtonLink`.
- `ButtonLink` 는 기존 버튼 클래스(`foundationButtonClass`)를 그대로 쓴다. 일반 이동은 `IntentLink`, OAuth · 외부 주소 · 북마클릿은 `plain`(네이티브 `a`).

## 쓰지 않는 곳

- 글 안 이동 — 링크.
- 누르는 즉시 켜고 끄기 — [스위치](./form-controls.md).

## 변형

| 변형   | 면 · 글자                                                          | 쓰는 곳                                   |
| ------ | ------------------------------------------------------------------ | ----------------------------------------- |
| 주     | `primary/default` · `on-primary`                                   | 한 영역의 주 동작                         |
| 보조   | `surface/control` · `content/default`, 선 없음                     | 나머지 동작                               |
| 고스트 | 면 없음                                                            | 줄 안 보조 · 제목 줄의 동작 · 정렬 트리거 |
| 위험   | `feedback/destructive-surface` · `on-destructive` (채운 빨강 하나) | 되돌릴 수 없는 일을 확정하는 버튼         |

- 누르는 것은 면으로 구분한다. 밝은 면(주) › 옅은 면(보조) › 글자만(고스트). 경계는 포커스 때만 그린다.
- 떠 있는 면(`surface/overlay` — 창 · 아래 시트 · 필터 팝오버 · 뷰어 설정 창) 위의 보조 버튼에는 약한 선 `border/default` 를 더한다([기초값 — 떠 있는 창](../foundations.md#떠-있는-창)).
- 위험 버튼은 확인 창 · 시트 안의 마지막(확정) 버튼에만 쓴다. 그 창을 여는 버튼 · 신고 버튼은 보조다. 빨간 테두리 · 빨간 글자 모양은 쓰지 않는다.

## 크기

- L(기본) = `--nl-control-height` · M = `size="sm"` (`--nl-control-height-compact`). 같은 줄은 한 단계([기초값 — 높이](../foundations.md#높이)).
- 안쪽 여백은 위아래 `spacing-8` · 좌우 `spacing-16` 에서 경계 1 을 뺀 값. M 은 위아래 0.
- 페이지에서 크기를 덮어쓰지 않는다. 칸이 좁으면 열 수를 줄인다(주 동작 한 줄 + 보조 두 열).
- 넓은 폭에서 한 줄을 다 쓰는 자리의 주 버튼은 내용 폭 · 왼쪽(데이터 동기화 로그아웃 「로그인」 · 검정 「로그인 후 인증 가능」). 폰 · 아래 시트 · 확인 창 · 좁은 열 안은 폭 가득.
- 버튼 줄 `nl-button-row` — 버튼 하나면 폭 가득, 둘이면 같은 폭 둘(사이 8).

## 상태

- 올림 · 누름은 다른 누르는 것과 같은 겹침 층(`interaction/hover` · `selected-pressed`).
- 바쁨 — `ActionButton busy`: 스피너 16 + 진행형 라벨, 다시 누를 수 없다. 비활성처럼 흐리게 하지 않는다.
- 잠김 — 로그인이 필요한 동작은 `data-locked`. 비활성처럼 보이되 이유를 보여 준다.
- 복사 성공은 누른 버튼 글자가 2초 「복사됨」 으로 바뀐다. 체크 표시 · 상자 없이 글자만, 알림은 화면 읽기로.

## 아이콘 버튼

- `IconButton` = 공용 버튼 `size="icon"` — 컨트롤 높이 정사각 · `radius/field` · 기본 고스트 · `label` 필수(아이콘은 `aria-hidden`).
- M 줄에서는 `size="compact"`(정사각 `--nl-control-height-compact`).
- 아이콘 20. 전체 화면 창과 폰 입력 창 머리의 닫기만 24.
- 패딩이 있는 칸의 첫 · 마지막 자식이면 `(컨트롤 높이 − 20) / 2` 만큼 밖으로 당겨 아이콘 잉크를 패딩 선에 맞춘다.
- 사진 위 넘김 · 지도 범례처럼 미디어 위 버튼만 자기 모양을 쓴다.

## 문구

- 동작 이름으로 쓴다(「기록 삭제」 · 「투표 저장」). 「확인」 · 「OK」 만 쓰지 않는다.
- 진행형 라벨은 같은 동작의 진행형(「저장 중」).

## 하지 않는 것

- 누를 때 크기 줄이기.
- 페이지 CSS 로 높이 · 여백 · 모서리 덮어쓰기.
- 빨간 테두리 · 빨간 글자 버튼, 옅은 색 면 버튼.
