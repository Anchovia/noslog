# 마크다운 입력

`MarkdownEditor` — 공지 · 이벤트 글쓰기

## 모양

- 상자 = 입력칸과 같은 2px 테두리 `border/input` · `radius/control` · 면 `surface/input`. 올리면 테두리가 `border/input-hover` 다. 입력에 포커스가 오면 상자 테두리가 `content/strong` 으로 바뀐다(입력 계열 포커스, [기초값 — 포커스](../foundations.md#포커스)). 잘못된 상자는 포커스에도 빨간 테두리를 지킨다.
- 머리 줄 = 가라앉은 면(`surface/canvas`) + 아래 `border/divider`. 왼쪽 「쓰기 / 미리보기」 탭(2단 탭 모양 · 의미는 tablist), 오른쪽 서식 아이콘 버튼. 모두 컨트롤 L(한 줄 한 단계). 넘치면 가로 스크롤.
- 입력 = `nl-body` · 안쪽 8/12 · 처음 8줄, 35줄까지 늘고 그 뒤 스크롤.
- 칸 아래 도움말 줄 = 왼쪽 안내(오류면 오류) · 오른쪽 「쓴 수 / 최대」. 쓴 수는 한도의 75% 를 넘을 때만 보인다. 넘겨도 입력은 막지 않고 게시만 막는다.

## 서식 버튼

- 렌더러가 그리는 것만 둔다: 소제목(메뉴 — 큰 `##` · 작은 `###`) · 굵게 · 기울임 · 취소선 · 인용 · 코드 · 표 · 구분선 · 목록 · 번호 목록 · 링크 · 이미지.
- 서식은 접지 않고 넘치면 가로 스크롤.
- 버튼을 눌러도 입력칸 포커스와 고른 자리를 지킨다.

## 단축키

- Cmd/Ctrl + B · I = 굵게 · 기울임. Cmd/Ctrl + Enter = 주 동작(게시 · 게시 요청).
- 단축키는 이름표에 적지 않고 툴팁에만.

## 이미지

- 버튼 · 붙여 넣기 · 끌어다 놓기로 올린다. 올리는 동안 자리 표시를 두고, 끝나면 `![](주소)` 로 바뀐다.
- 도움말 줄에 넣는 방법을 적는다.

## 미리보기

- 미리보기 탭을 누르면 전체 화면 창에 공개 화면 그대로 보인다(같은 렌더러 · 읽기 폭 `--nl-container-reading` · 제목 · 분류까지). 그 탭에 `aria-haspopup="dialog"`. 발에 「이어 쓰기」.
- 상자 안에서 글만 바뀌지 않는다.

## 글 안 서식 값

| 요소       | 값                                                                                                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 고정폭     | 기기 글꼴 `--nl-font-family-mono`(파일 추가 없음)                                                                                                                                                                    |
| 글 안 코드 | 면 `surface/surface` · `radius/small` · 안쪽 2/4 · 14                                                                                                                                                                |
| 코드 덩이  | 면 `surface/canvas` · 경계 `border/divider` · `radius/control` · 안쪽 12 · 넘치면 그 상자만 가로 스크롤                                                                                                              |
| 표         | 칸 안쪽 위아래 (컨트롤 높이 − 20 − 1) / 2 · 좌우 12(한 줄 칸 = 아래 선 포함 컨트롤 높이) · 줄 아래 `border/row` · 머리 `content/subdued` bold(`--nl-type-weight-strong`) · 좁으면 표만 가로 스크롤(열을 줄이지 않음) |
| 인용       | 왼쪽 2px `border/ring` + 안쪽 12 + 글자 `content/subdued`                                                                                                                                                            |
| 기울임     | 본문 `em` 만 `font-synthesis: style`                                                                                                                                                                                 |

## 아래 고정 바

`nl-form-bar` = 왼쪽 묶음(나가기 · 삭제 · 공개 페이지) · 오른쪽 묶음(저장 상태 → 임시저장 → 주 버튼). 저장 상태는 「저장 안 한 변경 · 저장 중 · 저장됨 · 저장 실패」 를 `role="status"` 로 알린다. 삭제는 보조 버튼이고, 누르면 확인 창의 확정 버튼만 채운 빨강이다.
