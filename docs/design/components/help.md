# 도움말

`TermHelp` · 기준 설명 `nl-info-trigger`

두 모양 모두 마우스 올림 · 포커스 · 탭으로 연다.

## 용어 뜻

`TermHelp` = 점선 밑줄 글자 + ? 16(간격 4) → 위쪽 작은 창(떠 있는 창 규격 · 최대 280 · 안쪽 12 · 제목 `nl-control` + 설명 `nl-body-secondary`).

- 오락실 기체 상태 이유만 줄 끝을 맞추려고 ? 없이 점선.
- `plain` 변형은 창 안 내용을 자유롭게 둔다(기여 라벨 · 업적 배지 정보 카드).

## 기준 설명

라벨 뒤 ⓘ 16(`nl-info-trigger` — 누르는 영역은 컨트롤 높이, 자리 차지 없음) → 같은 작은 창.

- 설명이 긴 곳(「패턴 경향 기준」)만 ⓘ 를 누르면 대화상자([정보 창](./dialog.md#창-안-내용--종류별)).
- 모두가 알아야 할 기준은 도움말로 숨기지 않고 늘 보이는 글로 둔다.
- 제목 옆 ⓘ 는 두지 않는다(서열표는 메타 줄 「안내」 링크).

## 동작

- 한 번에 하나만 열린다. 옆 배지 · 라벨로 옮기면 먼저 것이 바로 닫히고 그 자리에서 내용만 바뀐다.
- 열려 있을 때 같은 것을 누르면 닫힌다. 닫은 직후 200ms 는 다시 열지 않는다.
- 용어 도움말은 움직임 없이 즉시 뜬다. 업적 배지 정보 카드만 떠 있는 메뉴 페이드(③).
