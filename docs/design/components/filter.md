# 필터

`FilterSurface` · `FilterGroup` · `FilterChips` · `FilterChipLinks` · `SelectionList` · `AppliedTokens`

## 그릇

| 폭 · 화면               | 그릇                                                              |
| ----------------------- | ----------------------------------------------------------------- |
| 좁은 폭                 | 전체 화면 창([대화상자 — 전체 화면 창](./dialog.md#전체-화면-창)) |
| 악곡 · 서열표의 넓은 폭 | 왼쪽 레일                                                         |
| 오락실 672 이상         | 팝오버                                                            |
| 빙고                    | 그릇 없음(상태 칩 한 줄)                                          |

팝오버 폭은 334(화면 폭 − 32 를 넘지 않는다). 아래 시트 필터는 쓰지 않는다.

## 트리거

- 「필터」 + 적용 그룹 수 배지([태그 — 개수 배지](./tag.md#개수-배지)).
- 좁은 폭 목록 화면에서는 검색줄 오른쪽 아이콘 버튼 ☰ 컨트롤 높이 정사각(배지는 오른쪽 위, `nl-filter-icon-trigger`).
- 트리거는 높이를 덮어쓰지 않고 버튼 크기(`size`)를 따른다.

## 그룹

- `FilterGroup` = 제목 + 오른쪽 슬롯 + 그룹 사이 1px 구분선. 선 위아래 간격은 [기초값 — 간격](../foundations.md#간격) 의 「선으로 나눈 묶음」.
- 팝오버는 즉시 적용, 머리 줄 = 제목 | 「초기화」 M.
- 전체 화면 창은 발에 「초기화」 · 「결과 N개 보기」.

## 칩

- 짧은 열거는 창 · 팝오버에서 `FilterChips`.
- 칩 = `surface/canvas` 면 + 1px `border/input` 선 · `radius/full`(알약) · M 높이. 올림 `surface/control-hover`.
- 정렬 메뉴 안 칩은 좌우 안쪽 8 인 촘촘한 변형이다. 공용 파일에 둔다.
- 고른 칩 = `surface/control` 면 · 선 없음 + ✓. 굵기 400 그대로(고를 때 폭이 늘지 않게). 안의 개수 · 색 글자도 칩 글자색으로.
- 창 밖에서 늘 보이는 한 줄은 `row` — 줄바꿈 없이 가로 스크롤.
- 주소가 곧 상태인 페이지 필터(공지 분류 · 이벤트 상태)는 같은 모양의 링크 칩 `FilterChipLinks`(고름 = `aria-current`).
- 레일에서는 체크박스 목록 `SelectionList`.
- 난이도 · 분류 · 기록(S · FC · Pianist) 항목 글자는 그 색. 올리면 기본 글자색.

## 적용 조건

- `AppliedTokens` 알약 = 칩과 같은 알약 모양. 글자 →4→ × 16. 끝에 글자 버튼 「필터 모두 지우기」.
- 난이도 · 분류 · 기록 조건은 글자만 필터 칩과 같은 색, × 는 기본 글자색. 올리면 글자도 기본색. 레벨 · 미플레이 · 그 밖의 조건은 기본 글자색.
