# 상태 메시지

`StatusMessage` · `ResultState` · 알림 토스트(`AppToaster`)

상태 · 오류 · 결과 · 안내는 드물게, 가까이, 약하게 알린다. 색 면 상자 · 색 아이콘(빨간 ! · 초록 체크 · 파란 i) · 옅은 색 경고 상자는 쓰지 않는다.

## 모양

| 변형           | 모양                                                                                     | 쓰는 곳                                    |
| -------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------ |
| `inline`(기본) | 면 · 아이콘 없이 글자 `nl-body-secondary` 만. 오류는 `feedback/destructive`, 설명은 흐림 | 창 · 폼 · 동작 결과 · 빈 상태 안내         |
| `quiet`        | 색 없이 흐린 한 줄 + 오른쪽 고스트 M 「다시 시도」                                       | 구역 불러오기 실패 · 목록 더 불러오기 실패 |
| `boxed`(경고)  | 제목 `nl-component-title` + 설명 `nl-body-secondary`, 글자만                             | 개인정보 「법률 검토 대기」 등             |

- `severity` 는 info · success · warning · danger 넷이다. 모양이 바뀌는 것은 `danger`(오류 글자색)뿐이다.
- 오류 · 결과 한 줄을 `StatusMessage` 밖에서 따로 그리지 않는다(오락실 기기 줄 · 빙고 저장 실패 + 고스트 M 「다시 시도」 · 검정 인증 결과).
- 결과 상태는 `ResultState`. 느린 교체는 기존 값을 `content/subdued` 으로 둔다.
- `ResultState` = 위아래 안쪽 24 · 문구 `nl-body-secondary` 흐림 →24→ 동작, 왼쪽 정렬. 빈 결과는 `status`, 불러오기 실패(`error`)는 `alert` 로 알린다. 실패의 「다시 시도」 는 보조 버튼 기본 크기다.
- 빈 상태 안내는 흐린 `nl-body-secondary` 한 줄. 큰 그림 · 격려 문구 없음.
- 헤더 없는 오류 화면(`app/error.tsx` · `global-error`)은 같은 최소 복구 모양. 관리자 · 채보 에디터는 원래 화면.

## 알림 토스트

- 떠 있는 창 규격([기초값 — 떠 있는 창](../foundations.md#떠-있는-창))이다. 안쪽 12 16 · `nl-emphasis-label` 글자만. 색 면 · 색 아이콘 없음.
- 자리는 화면 위 가운데 · 가장자리에서 16. 3초 보이고, 한 번에 3개까지 보인다.
- 나타날 때 페이드 + 8 올라옴, 사라질 때 페이드(⑤).
- 칸 오류를 토스트로 바꾸지 않는다.

## 문구

- 무엇이 안 됐는지와 할 일을 1–2문장으로. 「앗!」 · 사과 · 느낌표 · 이모지 없음.
- 성공은 짧게(「링크 복사됨」 · 「뮤즈캣에 반영했어요」). 복사 성공은 토스트 대신 누른 버튼 글자가 2초 「복사됨」. 메뉴 항목(서열표 「⋯」 의 「링크 복사」 등)은 누르면 메뉴가 닫혀 글자를 바꿀 수 없으므로 토스트로 알린다.
