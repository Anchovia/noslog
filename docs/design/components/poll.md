# 투표

글에 딸린 투표 — 공지 · 이벤트. 본문에 흔적을 남기지 않고 글 하나에 하나. 공개 화면에서는 본문 끝에 위젯. 동작 규칙은 [기능 규칙 — 글에 딸린 투표](../product-rules.md).

## 글쓰기 구역

`nl-poll-section` = 제목 「투표」 + 「선택」 →12→

- 만들기 전 = 「투표 만들기」 보조 버튼.
- 만든 뒤 = 요약 카드(면 `surface/surface` · `radius/control` · 안쪽 12) — 질문 `nl-emphasis-label` · 오른쪽 「고치기 · 지우기」 고스트 M →4→ 「선택지 n개 · 한 개만 고름 · 마감」 `nl-metadata`. 표가 들어왔으면 그 아래 「N표」 `nl-metadata` 한 줄이 더 붙고 「지우기」 는 비활성이다.

## 만들기 창

`nl-poll-builder` — 672 이상 기본 창(600) · 그 아래 전체 화면. 칸 사이 24 이고, 펼친 「자세히」 안도 24 다.

- (표가 들어왔으면) 잠김 안내 한 줄 `nl-body-secondary` 흐림 → (공지만) 언어 탭 → 고르는 방법 세그먼트 → 질문 → 선택지(엔터로 칸 추가 · 「선택지 추가」 · 「여러 줄 붙여넣기」, 2–20개) → (여러 개일 때만) 「최대 몇 개까지」 숫자 칸 → 「누가 무엇을 골랐는지」 세그먼트 → 펼침 「자세히」(마감 · 결과 공개 · 게시 뒤 선택지 추가).
- 발은 「취소 · 넣기」, 전체 화면에서는 머리 × 가 닫기를 맡아 「넣기」 하나다.
- 만들기 창에 미리보기는 두지 않는다.

## 위젯

`nl-poll` = 면 카드(`surface/surface` · `radius/control` · 안쪽 12 · 사이 12) 안에 질문 `nl-emphasis-label` → 마감 · 익명 `nl-metadata` → 고르는 줄 또는 결과 → 아래 줄 「N명 참여」 + 버튼.

- 고르는 줄 = 경계 1px · `radius/control` · 컨트롤 높이. 고른 줄은 `--nl-stroke-strong` `border/ring` 경계 + 600.
- 결과 = 라벨 + 오른쪽 퍼센트 →4→ 진행 막대([그래프](./charts.md#진행-막대)). 내 표는 ✓ + 밝은 채움.
- 한 개만 고르는 투표는 누르면 바로 저장하고, 저장 상태는 「N명 참여」 줄 위 한 곳에 둔다([패턴 — 저장 방식](../patterns.md#저장-방식)). 여러 개는 「투표하기」 로 내고, 실패하면 같은 자리에 상태 메시지를 두며 다시 내기는 「투표하기」 가 맡는다.
- 로그아웃 · 마감은 결과만(고르는 줄을 보여 주지 않는다). 표를 낸 사람에게는 「다시 고르기」.
- 로그아웃이고 결과가 아직 비공개(투표한 뒤 · 마감한 뒤 공개)인 마감 전 투표는 질문 줄 오른쪽 끝에 제목 링크 「로그인하고 투표하기 ›」 를 두고, 결과 자리에는 설명 문장을 두지 않는다([패턴 — 로그아웃 상태](../patterns.md#로그아웃-상태)).
