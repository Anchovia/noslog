# 세그먼트

`SegmentedControl` — 공용 클래스 `nl-segments`

## 쓰는 곳

보기 방식 · 모드 · 난이도 · 한 차트 안에서 보는 지표 전환(최근 판정 추이 등)에만.

## 모양

- 판 = `surface/sunken` 면 + 1px `border/divider` · `radius/field`. 카드 위에서도 판이 보인다.
- 고른 칸 = `surface/control-selected` 면 + `content/interactive` 글자 + 600 · 선 없음.
- 고른 칸 안의 색 글자(난이도 레벨 숫자 · 난이도 이름)는 기본 글자색으로 돌린다(고른 칩과 같은 규칙).
- 칸은 균등 분할.

## 크기

| 크기                 | 높이                                                                           |
| -------------------- | ------------------------------------------------------------------------------ |
| 기본                 | 컨트롤 L                                                                       |
| 글자형 M `size="sm"` | 바깥 높이가 M — 칸 위아래 여백으로 맞춘다(같은 줄의 M 고르기 · 정렬과 한 단계) |
| 아이콘만             | 항목 40 × 36                                                                   |

## 넓은 폭 세로 변형

`nl-segments--wide-vertical` — 1056 이상에서 세로로 쌓는다. 행 = 컨트롤 높이 · 이름 왼쪽 · 값 오른쪽. 항목 안쪽은 `8 − 1`(트랙 경계 1 + 트랙 안쪽 3 을 더해 잉크가 옆 칸과 같은 12 에 선다).

## 난이도 세그먼트

악곡 상세의 난이도 고르기. 항목 = 이름 + 난이도 색 레벨 숫자(`nl-metric-value`, 사이 8, 항목 안쪽 4) · L 한 줄. 375 미만은 약칭 N · H · EX · R. 넓은 폭 왼쪽 열에서는 세로 변형(잉크 12).
