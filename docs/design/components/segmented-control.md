# 세그먼트

`SegmentedControl` — 공용 클래스 `nl-segments`

## 쓰는 곳

보기 방식 · 모드 · 난이도 · 한 차트 안에서 보는 지표 전환(최근 판정 추이 등)에만.

## 모양

MangaDex 보기 전환 방식이다.

- 판 = `surface/surface` 면 · 선 없음 · `radius/control` · 안쪽 0. 판 높이 = 칸 높이 = 컨트롤 높이다.
- 칸 = 좌우 안쪽 12 · `radius/small` · 칸 사이 4 · 글자 `nl-control`(14 · 400). 고른 칸도 굵기는 400 이고 색만 다르다.
- 고르지 않은 칸 글자는 `content/subdued` 이고, 올림 · 누름 · 키 포커스에 `content/default` 로 밝아진다.
- 고른 칸 = `surface/control` 면 + 글자 `content/strong` · 선 없음. 고른 표시는 칸과 같은 자리 · 크기다. 고대비 모드에서는 시스템 색 바꿈을 꺼 면을 남긴다([기초값 — 색 규칙](../foundations.md#색-규칙)).
- 비활성 칸은 글자 `content/disabled`.
- 고른 칸 안의 색 글자(난이도 레벨 숫자 · 난이도 이름)는 기본 글자색으로 돌린다(고른 칩과 같은 규칙).
- 칸은 균등 분할이다. 아이콘 칸만 내용 폭이다.

## 크기

| 크기                           | 높이                                                                                      |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| 기본                           | 판 · 칸 = 컨트롤 L                                                                        |
| 작게 `size="sm"`               | 판 · 칸 = 컨트롤 M(같은 줄의 M 고르기 · 정렬과 한 단계)                                   |
| 아이콘만 `nl-segments--icons`  | 칸 = 그 단계 높이의 정사각 · 아이콘 20 · 판 폭은 내용만큼                                 |
| 촘촘한 칸 `nl-segments--dense` | 칸 좌우 안쪽 4 · 줄바꿈 없음(검정 넓은 폭 종류 · 악곡 상세 지표). 칸은 같은 폭으로 나뉜다 |

## 넓은 폭 세로 변형

`nl-segments--wide-vertical` — 1056 이상에서 세로로 쌓는다. 행 = 컨트롤 높이 · 이름 왼쪽 · 값 오른쪽 · 좌우 안쪽 12. 잉크가 옆 칸(수치 띠 · 동작 칸)과 같은 12 에 선다.

## 난이도 세그먼트

악곡 상세의 난이도 고르기. 항목 = 이름 + 난이도 색 레벨 숫자(`nl-metric-value`, 사이 8, 항목 안쪽 4) · L 한 줄. 375 미만은 약칭 N · H · EX · R. 넓은 폭 왼쪽 열에서는 세로 변형이다.
