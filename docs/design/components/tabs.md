# 밑줄 탭

`AreaTabs` · `AreaTabLinks` · `MetricSwitch` — 공용 클래스 `nl-tabs`

## 모양

- 안 고른 항목 `content/subdued` 500 · 고른 항목 `content/default` 600 + `--nl-stroke-strong` 밑줄.
- 올림은 글자만 바뀐다. 밑줄 이동은 움직임 없이 즉시.

## 두 단계

| 단계 | 부품                               | 쓰는 곳               | 모양                                                                                                                                         |
| ---- | ---------------------------------- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 1단  | `AreaTabs` · 링크판 `AreaTabLinks` | 페이지 구역 전환      | 높이 48 · 내용 폭 전체 1px 구분선 · 항목이 줄 폭을 똑같이 나눔(안쪽 8, 글자가 칸보다 길면 그 칸만 글자만큼) · 모든 폭 탭, 넘치면 가로 스크롤 |
| 2단  | `MetricSwitch`                     | 같은 목록의 기준 전환 | 구분선 없음 · 컨트롤 높이                                                                                                                    |

- 1단 항목은 균등 분할로 둔다. 어색하면 폭이 아니라 배치를 바꾼다.
- 1단은 tablist(방향키로 포커스, Enter · Space 로 적용), 2단은 `aria-pressed` 버튼 묶음.
- `AreaTabLinks` 는 항목이 링크이고 고름은 `aria-current`(탭마다 주소가 다른 화면 — 프로필 · 소식).
- 위 구역 탭과 같은 화면에서 2단 탭을 겹쳐 쓰지 않는다. 그 자리는 [세그먼트](./segmented-control.md).
