## 3. Two items worth a decision

1. **Overlay edge** — keep `border/default` 1px + shadow (current, shadcn-like) or shadow-only
   in Light (Spectrum / Material / Carbon / Atlassian) with the 1px edge kept only in Dark,
   where shadows are invisible. Touches C8 `DestinationPanel`, search popover, listbox,
   language menu, preview sheet, dialog, tooltip.
2. **Home destination tiles** — the only surface that reads as the "feature-card template".
   Options if the user wants distance from it: icon beside label (horizontal tile), or a list
   instead of a grid on compact. This reopens `HOME-21` / 2026-08-18 tile decisions.

## 4. Tells the user already removed during the project (for the record)

- Difficulty chips / dot markers → colored text (`EXAM-32`, "AI 티 나는 칩 디자인").
- Default 805/395 two-column wide template → per-page compositions from measured references.
- Five-variant share-card set built on product-UI restraint → rejected; rebuilt on the shipped card's language.
- Pill chips on the share card bottom row → inline colored marks (B-a).
- Explanatory sentences per contract clause → copy budget (P9, P14).

## 5. Not measurable here — run on the implementation

Motion (`transition-all`, bounce easing, image hover transforms, pulsing dots), copy cadence in
rendered pages, line length, cramped padding at runtime, skipped heading levels, overflow
clipping of popovers. `npx impeccable detect` covers all of these deterministically.
