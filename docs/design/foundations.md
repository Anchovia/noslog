# 기초값

색 · 글자 · 간격 · 모서리 · 높이 · 선 · 층 · 포커스 · 상태 · 움직임 · 로딩 · 셸 · 레이아웃 규칙이다.
값의 정본은 [`app/styles/tokens.css`](../../app/styles/tokens.css) 하나다. 이 문서는 토큰 이름과 쓰는 곳만 적고, 값은 이해를 돕는 데 필요할 때만 괄호로 붙인다.
값이 이 문서와 `tokens.css` 에서 다르면 `tokens.css` 가 맞다. 이 문서를 고친다.

## 테마 · 글꼴

- 다크만 쓴다. `NEXT_PUBLIC_ENABLE_THEME_SWITCHING=false` 동안 라이트 값은 남겨 두되 새로 만들지 않는다. 대비는 다크 값으로 잰다.
- 글꼴은 Pretendard JP Variable 1.3.9 를 자체 호스팅한다. 화면은 저작권자가 배포한 공식 분할판(unicode-range 조각, 파일 수정 없음, 전역 preload 없음)으로 쓰는 글자 묶음만 받는다. 직접 자르지 않는다(글꼴 이름이 예약 이름이다).
- 한 파일 원본(`PretendardJPVariable.woff2`)은 북마클릿 오버레이와 서열 변경 공지 이미지(캔버스)만 쓴다. 서버에서 그리는 이미지(프로필 카드 · 공유 미리보기)는 그리는 도구가 woff2 를 읽지 못해 `assets/fonts/pretendard-jp/1.3.9` 의 TTF 원본(Regular · Bold)을 쓴다. 한국어에만 `ss05` 를 켠다.
- 고정폭 글꼴은 기기 글꼴(`--nl-font-family-mono`)만 쓰고 파일을 더 싣지 않는다.
- 기울임 합성은 끈다. 예외는 글 본문의 `em` 한 곳으로, 우리 글꼴에 기울임 글꼴이 없어 합성을 켠다(`font-synthesis: style`).

### 도메인 색

이미 있는 것만 쓴다. 새 색이 필요해 보이면 만들지 말고 시안으로 묻는다.

- 난이도 글자 `difficulty/text-*` · 분류 `category/*` — 누르는 면(`surface/control`) 위에서도 4.5 : 1 을 넘게 명도만 올린 값이다.
- 판정 `judgement/*` · 달성 `achievement/*` · 검정 `exam/*` · 상태 `feedback/*-marker` · `feedback/destructive` · 차트 `local-data/*`.
- 다른 뜻의 색을 빌린 별칭(패턴 경향 단계 · 등급 A+ · A · B · Grd 구간)은 각 부품 · 화면 문서에 적힌 것만 쓴다.
- 난이도 원색 `difficulty/*`(글자용 아닌 바탕값)은 레벨 범위 슬라이더 색과 위 별칭의 바탕으로만 쓴다. 서열 값 글자색은 `tier/value-start`(1.0)에서 `tier/value-end`(14.5)까지 난이도 글자색(Normal · Hard · Expert · Real)과 `judgement/just` 를 기준점으로 거쳐 oklch 로 섞는다(`lib/music/tier-value-color.ts`).

### 색 규칙

- 상호작용 면(올림 · 선택 · 비활성)은 그 상태일 때만 칠한다. 평소 요소에 칠하지 않는다.
- 올림은 Geist 방식이다. 면 있는 것은 제 올림 면으로 바꾼다(보조 · 칩 = `surface/control-hover`, 주 버튼 = `primary/hover`, 위험 = `feedback/destructive-hover`). 면 없는 것은 `--nl-state-layer` 와 `background-image: linear-gradient(var(--nl-state-layer), var(--nl-state-layer))` 로 제 면 위에 겹친다. 고스트 · 면 없는 줄은 `interaction/hover`, 목록 줄 · 펼침 줄은 `interaction/row`, 메뉴 항목은 `interaction/menu` 다. 누름 전용 값은 없다.
- 고른 것은 `surface/control` 면에 선이 없다(세그먼트 칸 · 칩 · 지금 쪽 · 숫자 척도 · 누른 알약 · 고르기 줄). 메뉴의 고른 항목만 `interaction/menu` 겹침이다.
- 링크는 `content/default` 글자에 밑줄이다. 글 안 링크는 늘 밑줄, 글자 링크(돌아가기 등)는 올리면 밑줄. 따로 링크 색을 두지 않는다.
- 텍스트 선택(`::selection`)은 `primary/default` 면 + `on-primary` 글자다.
- 비활성은 부품 전체 불투명도 `--nl-disabled-opacity`(50%)다. 버튼만 흐린 면 `surface/control` + 흐린 글자 `content/disabled` 이고, 고스트는 면 없이 글자만 흐리다. 잠긴 버튼(`data-locked`)도 같은 모양이다. 올림 규칙은 `:not(:disabled)` 로 비활성에 걸리지 않게 한다.
- 배경 그림을 이미 쓰는 요소(투표 줄의 구분선)와 `::selection` 만 `background-color` 로 칠한다.
- 대비는 글자 4.5 : 1, 글자 아닌 단서 3 : 1 이다. 색만으로 상태를 알리지 않는다 — 상태 색은 늘 상태 글자와 함께 쓴다.
- 상태는 글자색으로 써도 된다. `feedback/*-marker` · `feedback/destructive` 처럼 다크 바탕에서 4.5 : 1 을 넘는 표시색만 쓴다.
- 고대비 모드(`forced-colors: active`)에서는 시스템 색을 쓴다(포커스 선 `Highlight`, 체크박스 상자 `ButtonText` · 체크하면 `Highlight`). 규칙은 `foundation.css` 한 곳에 있다.

## 글자

`tokens.css` 의 글자 클래스 13종과 태그 글자 하나만 쓴다. 이 밖의 크기 · 줄 높이 · 굵기 조합은 쓰지 않는다. 다른 문서가 조합을 따로 정하지 않는다.

| ---------------------------------------- | ------------------------- | --------------------------------------------------------------- |
| `nl-display`                             | 40/48 · 700               | 따로 승인된 곳만(프로필 머리 아바타 첫 글자)                    |
| `nl-page-title`                          | 32/40 · 600               | 페이지 제목(모든 폭)                                            |

| `nl-component-title` · `nl-entity-title` | 24/32 · 600 · 16/24 · 600 | 상자 · 창 · 필터 그룹 제목 / 목록 · 카드 항목 이름              |

| `nl-metric-display` · `nl-metric-value`  | 32/40 · 700 · 14/20 · 500 | 비교하는 숫자. 고정폭 숫자(tabular)는 이 둘에만                 |
| `nl-tag-label`                           | 12/16 · 600               | 태그 · 배지 안 글자만(공용 `nl-tag` 가 씀). 12 굵게는 이 하나뿐 |

변형 두 개:

- `nl-metadata--long` — 여러 줄로 읽는 12 설명(칸 도움말 · 칸 오류 · 창 안 설명 문단)은 줄 높이만 18. 한 줄 라벨 · 표 · 목록 줄 안 12 는 16 그대로.
- `nl-page-title--fixed` — 좁은 열 안의 페이지 제목(악곡 상세 머리 열)은 모든 폭 24/32.

규칙:

- 굵기는 400 · 500 · 600 · 700 만.
- 클래스 없는 셸 기본 글자와 입력칸 글자는 모든 폭에서 14/20 이다.
- 제목 클래스(`page-title` · `section-title` · `component-title` · `entity-title`) 글자색은 `content/default`, 본문은 `content/default`.
- 흐린 메타 줄(`metadata` + 흐림)은 `content/subdued`. 칩 · 버튼 · 세그먼트 칸 안에서는 대비가 모자라 `content/subdued` 그대로.
- `metric-value` 밖의 14/20 · 500 은 탭 · 세그먼트의 안 고른 칸에만 쓴다(고른 칸은 600). 칸 라벨 · 필터 그룹 옆 버튼은 `control` 400 이다.
- 20 이상 제목과 `metric-display` 의 자간은 `--nl-type-tracking-title`(−0.02em). 글자 다듬기는 antialiased(맥 데스크톱만 차이).
- 표의 조합 밖(16 굵게 + 고정폭, 태그 밖의 12 굵게)은 쓰지 않는다. 고정폭 숫자도 `metric-display` · `metric-value` 밖에서는 쓰지 않는다.
- 글자 클래스는 원재료 토큰 `--nl-type-size-*` · `--nl-type-line-height-*` · `--nl-type-weight-*` · `--nl-font-family`(고정폭 `--nl-font-family-mono`)로 만든다.

## 토큰 · 공용 부품으로만

- 모든 시각 수치(간격 · 안쪽/바깥 여백 · 모서리 · 선 두께 · 색 · 글자 크기 · 굵기 · 줄 높이 · 높이 · 층 · 시간)는 CSS · TSX · Tailwind · JS 계산 어디서든 토큰이나 토큰으로 만든 식으로 쓴다. 토큰에 없는 값은 쓰지 않는다.
- Tailwind 는 `app/styles/tailwind-theme.css` 의 `nl` 별칭만 쓴다. 기본 스케일(`p-3` · `rounded-md` · `text-sm` · `font-bold` · `z-10`), 임의값(`w-[13px]`), 기본 색 팔레트(`bg-red-400/10` · `text-white`), 중단점 변형(`md:` · `min-[672px]:`)은 쓰지 않는다. 폭 단계는 CSS media query 로 둔다. 별칭은 `.noslog-ui` 안에서만 쓴다.
- 인라인 `style` 은 데이터로 계산한 값(비율 · 좌표 · 데이터 색)만. JS 가 크기를 계산해야 하면 숫자를 다시 쓰지 말고 토큰을 읽거나(`readTokenPixels`) 실제 요소를 잰다. CSS 변수를 읽지 못하는 캔버스 · 공유 이미지는 크기 · 굵기를 `lib/design-token-values.ts` 한 파일에서 읽고, 색은 그림마다 다크 값을 옮긴 상수(아이콘 · 공유 미리보기 `lib/metadata/brand-image.tsx`, 프로필 카드 `features/profile/profile-card-colors.ts`, 값 색 `lib/music/score-tone.ts`, 채보 무대 `lib/chart-pattern/stageColors.ts`)에서 읽는다. 각 상수는 테스트가 `tokens.css` 와 대조한다. 서열 변경 공지 이미지는 사용자가 정한 원본 규격의 색(`TIER_CHANGE_IMAGE_PALETTE`)을 쓴다.
- 반복되는 요소는 공용 부품(`components/ui`)으로 만들고, 크기 단계는 숫자 prop 대신 부품의 클래스 · 변형으로 둔다.
- 필요한 값이 토큰에 없으면 만들지 말고 시안으로 묻는다.
- 검사는 CSS(관리자 `admin.css` 포함)와 라우트가 닿는 TSX · TS(관리자 · 에디터 포함)를 모두 본다. 토큰으로 옮기면 모양이 바뀌는 값만 각 검사(`tests/design-foundation.test.ts` · `tests/design-tsx-tokens.test.ts` · `tests/admin-tsx-tokens.test.ts`)의 예외 목록에 이유와 함께 둔다. 계산식 안 크기 · 폭 · 높이는 검사 밖이다.

- 문서의 L · M 은 기본 · 작게를 줄여 쓴 것이다.
- 표 줄 · 목록 행 = 컨트롤 높이(아래 선 포함)는 글자 한 줄 표에만 쓴다. 자켓 행 · 두 줄 행 · 빈 줄(서열표 · 빙고 · 악곡 목록 · [프로필](./pages/profile.md) 기록 표 · 공지 줄 · 랭킹 0명 줄 등)은 화면 문서 값을 따른다.
- 같은 줄은 한 단계다. 버튼 `size` 는 `sm`(작게) · `md`(기본) · `lg`(크게), 아이콘 버튼은 자기 줄의 단계를 따른다.
- 폼 제출이라도 상자 안 인라인 칸의 버튼(의견 작성 칸 「취소 · 의견 작성」, 평가 잠금 카드 「로그인」)은 M 이다. 예외는 이 둘뿐이다.
- 폼 안 첨부 버튼은 입력칸 역할이라 L 이다. 붙인 뒤 들어서는 파일 줄(L)과 높이가 같아 자리가 튀지 않는다.
- 전체 화면 창 발의 「초기화」 는 주 동작과 같은 줄이라 L 이다.
- 1단 탭은 48. 헤더 메뉴(≡) 이동 줄만 48(넓은 폭은 컨트롤 높이).
- 헤더는 `--nl-header-height`(1055 이하 56 · 1056 이상 64).

## 포커스

- 포커스는 `foundation.css` 의 공용 규칙이다. 모든 요소가 `--nl-stroke-strong`(2) `focus/ring` 흰 outline 한 줄이고 후광 · 두 줄은 없다. 부품 CSS 에 포커스 모양을 따로 쓰지 않는다.
- 떨어진 요소(링크 · 카드 · 체크박스 상자)는 바깥 간격 `--nl-stroke-strong`(2), 버튼은 간격 0 이다. 폭이 꽉 찬 줄 · 탭 · 세그먼트 칸 · 메뉴 항목 · 칩은 안쪽(−2)으로, 공용 규칙의 안쪽 목록에 클래스를 더한다.
- 입력 계열(입력 · 셀렉트 · 검색칸 · 마크다운 입력 · 단위 입력)은 같은 흰 선 한 줄을 테두리에 붙여(간격 0) 그린다. 테두리 색은 바꾸지 않는다.
- 숨긴 입력이 포커스를 받는 부품(검색칸 · 마크다운 입력 · 단위 입력 · 체크박스)은 보이는 상자에 포커스를 그린다. 상자 안 다른 버튼에 포커스가 있을 때는 그리지 않는다.
- 사진 · 무대 위 버튼도 같은 공용 포커스를 쓴다.
- 목록(셀렉트 목록 · 정렬 메뉴) 항목의 포커스 선은 키보드로 움직일 때만 보인다. 마지막 입력 방식을 `lib/input-modality.ts` 가 `<html data-input>` 에 적는다.

## 올림 · 누름

- 올림(hover) 면은 포인터 장치에서만 칠한다. 모든 `:hover` 규칙은 `@media (hover: hover)` 안에 둔다(터치는 탭한 뒤 hover 가 남아 고른 것처럼 보인다). `:not(:hover)` 로 평소 색을 정하는 규칙은 밖에 둔다.
- 누를 수 있는 것은 모두 반응한다.

| 요소                                                                 | 올림 모양                                               |
| -------------------------------------------------------------------- | ------------------------------------------------------- |
| 면 있는 버튼 · 칩 · 셀렉트                                           | 제 올림 면으로 바꿈([색 규칙](#색-규칙))                |
| 면 없는 줄 · 고스트 · 카드 · 판 칸                                   | 제 면 위 겹침([색 규칙](#색-규칙)). 모서리는 그 요소 것 |
| 고르지 않은 세그먼트 칸                                              | 글자만 밝게                                             |
| 글자 링크(돌아가기 · 「원문 보기」 · 「전체 레벨 보기」 · 공지 제목) | 밑줄(`--nl-underline-offset`)                           |
| 면 없는 그림 카드(이벤트 · 빙고)                                     | 제목 밑줄                                               |
| 투표 줄                                                              | 경계 `border/ring`                                      |
| 밑줄 탭 · 범례                                                       | 글자만                                                  |
| 그림만 있는 서열 칸                                                  | 테두리                                                  |
| 면 없는 구분선 목록 줄(프로필 기록 · 고정 기록)                      | 좌우 12 를 넓혀 칠함. 글자 선 · 구분선은 그대로         |
| 고른 칸 · 지금 쪽                                                    | 반응 없음                                               |

- 전용 부품 클래스가 없는 줄 · 버튼은 공용 `.nl-hover-layer` 를 쓴다. 면 색을 바꾸는 `hover:bg-*` 는 쓰지 않는다.
- 누름 전용 색은 없다. 크기 줄이기(scale)도 없다.
- 바쁨(busy)은 비활성이 아니다. 버튼은 스피너 16 + 진행형 라벨, 화면 · 영역 로딩은 아래 「로딩」.

## 떠 있는 창

목록 · 메뉴 · 팝오버 · 대화상자 · 차트 툴팁 · 알림 토스트 · 지도 아래 시트 · 지도 위 검색칸 · 평가 잠금 카드가 해당한다.

- 면 `surface/surface` · 모서리 `radius/overlay` · 그림자 `--nl-overlay-shadow`. 경계는 모두 둘레 1px `border/elevated` 다(메뉴 · 헤더 메뉴 패널 · 팝오버 · 차트 툴팁 · 빙고 칸 팝오버 · 홈 검색 미리보기 · 떠 있는 검색 · 뮤즈캣 패널 · 대화상자). 폰 헤더 메뉴 패널은 헤더에 붙어 위 모서리 · 위 선이 없다.
- 메뉴(셀렉트 목록 · 정렬 메뉴 · 액션 메뉴 · 검정 선택 목록)는 판 안쪽 4 · 항목 높이 = 컨트롤 높이 · 항목 모서리 `radius/control` · 쌓임 층 `--nl-layer-select` 다. 규칙은 `foundation.css` 「메뉴 한 모양」 한 곳에 있다.
- 알림 토스트는 면 `surface/canvas` + 둘레 1px `border/elevated` · 그림자다.
- 용어 도움말 창(`TermHelp`)은 면 `surface/inverse` · 글자 `content/on-inverse` · 모서리 `radius/small` · 안쪽 4 8 · 그림자 `--nl-tooltip-shadow` 다.
- 미디어 위 판(자켓 카테고리 · 서열 카드 난이도)은 떠 있는 창이 아니다.

## 움직임

움직임은 상태 · 위치 · 로딩에만 쓰고 장식은 없다. 아래 표에 없는 곳은 즉시 바뀐다. 새 움직임이 필요하면 이 표와 토큰을 먼저 고친다(사용자 허락).

값은 `tokens.css` 의 움직임 토큰만 쓴다. CSS 에 숫자 시간 · `cubic-bezier` · `ease` · `linear` 를 직접 쓰지 않는다(테스트가 막는다).

| 토큰                                                        | 값                                                    | 쓰는 곳                                           |
| ----------------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------- |
| `--nl-motion-duration-state`                                | 100ms                                                 | ① 올림 · 누름 색                                  |
| `--nl-motion-duration-popup`                                | 150ms                                                 | ③ 떠 있는 메뉴 열림                               |
| `--nl-motion-duration-overlay-in` · `-out`                  | 200 · 150ms                                           | ④ 대화상자 · ⑤ 토스트 나타남 · 사라짐             |
| `--nl-motion-duration-move`                                 | 200ms                                                 | ⑫ 헤더 숨김 · 오락실 시트 · 이미지 내보내기 창    |
| `--nl-motion-duration-chart-in` · `-change`                 | 800 · 300ms                                           | ⑯ 그래프 나타남 · 값 바뀜                         |
| `--nl-motion-loop-spin` · `-pulse`                          | 800 · 1600ms                                          | ⑩ 스피너 한 바퀴 · ⑪ 스켈레톤 한 번               |
| `--nl-ease-enter` · `--nl-ease-exit`                        | `cubic-bezier(0.4, 1, 0.6, 1)` · `(0.6, 0, 0.8, 0.6)` | 들어올 때 감속 · 나갈 때 가속                     |
| `--nl-ease-spin` · `--nl-ease-pulse`                        | `linear` · `ease-in-out`                              | 스피너 · 스켈레톤                                 |
| `--nl-motion-distance`                                      | 8px                                                   | 대화상자 · 토스트가 떠오르는 거리                 |
| `--nl-motion-delay-progress` · `--nl-motion-delay-skeleton` | 100 · 300ms                                           | 이 안에 끝나면 진행 막대 · 스켈레톤을 띄우지 않음 |
| `--nl-motion-duration-progress`                             | 1500ms                                                | 위쪽 진행 막대가 80% 까지 차오름                  |

- ① 올림 · 누름 색 — 누를 수 있는 모든 것(`a` · `button` · `summary` · `label` 로 만든 줄 · 옵션 · 메뉴 항목 · 탭, 누를 줄을 품고 올림 면을 칠하는 카드, 올림 면을 `::before` 로 그리는 버튼)에 같은 값. 배경 · 글자색 · 겹침 층(`--nl-state-layer`)만 움직이고 포커스 선 · 경계는 즉시. 겹침 층은 켜질 때만 움직이고 꺼질 때는 즉시.
- ③ 떠 있는 메뉴(셀렉트 · 정렬 · ⋯ · 필터 팝오버 · 빙고 칸 · 지도 범례 · ≡ 메뉴 · 폰 ≡ 뒤 어둠 · 업적 배지 카드) — 열 때 페이드만, 닫을 때 즉시.
- ④ 대화상자 · 전체 화면 창 — 나타날 때 페이드 + 8 떠오름, 사라질 때 페이드만. 떠오름은 `translate` 속성(가운데 맞춤 `transform` 과 따로).
- ⑤ 토스트 — 나타날 때 페이드 + 8 올라옴, 사라질 때 페이드만(sonner 기본값을 토큰으로 덮음).
- ⑩ 스피너 회전 · ⑪ 스켈레톤 불투명 1 → 0.5 깜빡임.
- ⑫ 위치 이동 — 헤더는 나타날 때 감속 · 숨을 때 가속. 시트는 화면 안 이동이라 감속. 손가락으로 끄는 동안은 움직임 없이 따라간다.
- ⑮ 지도 — 카드를 누르면 핀으로 미끄러진다(카카오맵 `panTo`). 목록 스크롤은 즉시.
- ⑯ 그래프(막대 목록 · 누적 막대 · 선 그래프 · 값이 바뀌는 진행 막대) — 나타날 때 막대 · 선이 왼쪽부터 드러나고(바닥선 · 틀은 그대로), 같은 막대 · 같은 점의 값이 바뀌면 새 값으로 옮겨 간다. 선 그래프는 점 구성(날짜)이 바뀌면 다시 드러난다. 공용 클래스 `nl-chart-reveal`(드러남) · `nl-chart-bar`(막대 길이 옮겨 감) 두 개만 붙인다. SVG 선의 옮겨 감은 `lib/motion` 이 같은 토큰을 읽는다. 값이 바뀌지 않고 여러 장이 한꺼번에 움직이는 막대(빙고 목록 카드 완료 막대)는 장식이라 움직이지 않는다.
- 즉시(움직임 없음) — ② 누름 크기 줄이기 · ⑥ 탭 밑줄 · ⑦ 구역 펼침 · ⑧ 툴팁(그래프 · 용어 도움말) · ⑨ 체크박스 · 라디오 · 토글 · ⑬ 스크롤 연출 · ⑭ 페이지 이동.
- 동작 줄이기 — 기기 설정이 켜지면 `tokens.css` 한 곳에서 시간 토큰을 모두 0 으로 한다. 스피너 한 바퀴와 위쪽 진행 막대는 남긴다(멈추면 고장처럼 보인다). JS 가 같은 설정을 읽는 곳은 둘이다. 지도는 곧바로 옮기고, 동기화 안내의 움직이는 그림은 그림 대신 라벨 글자를 둔다(누르면 여는 큰 그림은 그대로).
- 손대지 않는 것 — 채보 캔버스, 카카오맵 안 타일 페이드(라이브러리), 공식 사이트 위 북마클릿 창.

## 로딩

로딩 표시는 한 영역에 하나다.

- 사이트 안 이동 = 위쪽 진행 막대(`NavigationProgress`, 일반 · 관리자 셸에 하나씩). 사이트 안 링크를 누르고 `--nl-motion-delay-progress` 안에 끝나지 않으면 맨 위에 `--nl-stroke-strong` 두께 `primary/default` 막대가 80% 까지 차오르고, 새 화면이 오면 끝까지 채우고 사라진다. 이전 화면은 그대로 둔다(흐리게 하지 않는다). 다른 처리가 클릭을 막아 이동하지 않으면(저장 안 한 변경 안내 등) 뜨지 않는다.
- 스켈레톤은 실제 부품의 틀 · 클래스를 그대로 써서 컨테이너 · 간격 · 안쪽 여백 · 높이가 저절로 같다. 제목 · 탭 · 필터 · 라벨처럼 고정된 부분은 실제 글자 · 실제 부품으로 두고, 이름 · 수치 · 사진 · 그래프 · 목록 자리만 스켈레톤으로 그린다. 부품마다 `…Skeleton` 을 부품 곁에 둔다.
- 글자 자리 `SkeletonText` 는 그 글자 클래스를 받아 줄 높이(1lh)를 차지하고 막대는 글자 크기(1em)다. 폭은 25 · 50 · 75 · 100% 네 단계만. 짧은 값(순위 · 숫자)은 보이지 않는 표본 글자(「0,000」) 폭만큼이라 기준선 정렬 줄에서도 실제 글자와 같은 선에 선다. 값 칸에는 실제와 같은 글자 클래스를 붙인다.
- 채움은 `surface/control` 하나 · 모서리는 실제 부품 것 · 펄스(⑪). 입력 · 셀렉트 자리는 컨트롤 높이 · `radius/control`.
- 스켈레톤 안에 스피너를 넣지 않는다. 모양을 모르는 한 덩어리(지도 등)만 그 자리 가운데 스피너 20.
- 첫 진입(서버가 그림)은 지연 없이 스켈레톤. 화면 안 다시 불러오기는 `nl-loading-delay`(`--nl-motion-delay-skeleton`) 동안 숨겨 짧으면 번쩍이지 않게 한다. 최소 표시 시간은 두지 않는다.
- 다시 불러오는 동안 이전 내용이 있으면 그 내용을 `content/subdued` 로 두고 스켈레톤 · 글자를 끼우지 않는다.
- 값의 뜻이 바뀌는 전환(지표 Grd ↔ 레이팅 · 기간 · 모드 Basic ↔ Recital)은 이전 내용을 두지 않는다. 처음 `--nl-motion-delay-skeleton` 동안만 흐린 색, 넘으면 같은 틀의 스켈레톤(그래프 면 · 요약 값 · 목록 줄, 라벨은 실제 글자). 같은 지표에 줄만 이어 붙는 「더 보기」 는 해당 없다.
- 「…불러오는 중」 문장은 화면 읽기에만 한 번 알린다(`LoadingStatus`). 로딩 중인 영역은 `aria-busy`. 보이는 곳에 로딩 문장 한 줄만 두지 않는다.
- 확인: 요청을 늦춰 스켈레톤일 때와 내용이 들어온 뒤 요소 위치 · 크기를 재서 비교한다(폭 390 · 1280).

## 셸과 레이아웃

### 폭 단계

viewport media query 로만 정하고, CSS 와 JS 가 같은 기준을 쓴다.

| 이름                   | 폭        | 구성                    |
| ---------------------- | --------- | ----------------------- |
| 좁은 폭                | 672 미만  | 모바일 구성             |
| 중간 폭 (Intermediate) | 672–1055  | 중간 구성               |
| 넓은 폭 (Wide)         | 1056 이상 | 넓은 구성(셸 폭은 같음) |

부품이 자기 폭을 재서 글자를 맞추는 것은 되지만, 그걸로 폭 단계를 따로 바꾸지 않는다.

### 셸

- 헤더 · 본문 · 푸터 내용은 최대 1200 가운데. 바탕과 구분선은 화면 전체.
- 전역 좌우 여백은 16(좁은 폭) · 24(672 이상). 페이지가 여백을 한 번 더 넣지 않는다. 셸 1200 에서 안쪽 내용은 1152, 1440 에서 양옆 120 씩 빈다.
- 넓은 폭 레일(악곡 · 서열표 · 검정 · 개인정보 목차 · 설정) = 내용 폭의 1/4, `calc((100% - 3 * 16px) / 4)` (셸 1200 에서 276).
- 헤더 높이 `--nl-header-height`. 헤더 면은 바탕과 같은 `surface/canvas` 이고 아래에 1px `border/divider` 를 긋는다.
- 머리글에 가리지 않게 하는 규칙은 전역 `scroll-padding-top` = `--nl-header-height` 하나다. 요소마다 `scroll-margin` 을 따로 두지 않는다.
- 푸터는 840 이상 한 줄, 그 아래는 가운데로 쌓는다.

### 헤더 메뉴

- 넓은 폭은 이동 메뉴 여덟 개를 로고 옆에 나란히 둔다. 로고 →24→ 메뉴(항목 `control` · 컨트롤 높이 · 좌우 안쪽 12 · 사이 4 · `content/subdued`, 지금 위치 = `content/default` + 600). ≡ 창의 지금 위치 줄도 면 없이 600 만. 오른쪽 끝에 로그인(프로필 사진) · ≡. 메뉴 항목 · 로그인 · ≡ 는 모두 컨트롤 높이 · 올림 면 모서리 `radius/control`. 프로필 버튼은 사진 원이고 올림 면이 없다.
- 넓은 폭의 ≡ 창은 「설정 · 피드백 · 신고 · (관리자)」 만 담는 한 열(폭 248). 이름은 「더 보기 메뉴」. ≡ 버튼 바로 아래(버튼 아래 0)에 열려 헤더 아래 칸에 걸친다.
- 1055 이하는 ≡ 안에 전부(두 열). 좁은 폭은 헤더 바로 아래에 붙어 좌우 16 을 뺀 폭 가득이다. 중간 폭은 헤더 아래 8 떨어진 폭 488 창으로 오른쪽 끝을 전역 여백에 맞추고, 둘레 1px `border/elevated` 를 다 두른다. 359 이하에서는 줄 글자가 12/16 · 400 이고, 지금 위치는 고른 면(`surface/control`)이 표시한다.

### 브라우저 색 · 이름 · 아이콘

- `theme-color` = `surface/canvas`(#000) · `color-scheme: dark`, manifest 색도 #000.
- 이름 「NosLog」 은 어디서나 사이트 글꼴 글자다(헤더 `section-title` · 홈 · 로그인 · 오류 페이지 `page-title`). 글자색은 `content/default` 다.
- 얼굴은 고양이 원 아이콘(`components/layout/brand-mark.tsx`, 이미지는 `BrandMarkImage`). 채운 원 = `identity-mark` · 고양이 = `surface/canvas`. 테두리 원 변형은 쓰지 않는다.
- 아이콘이 들어가는 곳: 앱 아이콘(바탕 #000 + 지름 68% 상자 — 상자가 안전 영역 80% 안. 192 · 512 · 애플 180, maskable 은 512 하나) · 탭 아이콘(`app/favicon.ico` 48, 바탕 없이 원이 칸을 채운다) · 홈 머리(이름 위 40) · 프로필 카드(54 + 글자 28) · 공유 미리보기 오른쪽(220).
