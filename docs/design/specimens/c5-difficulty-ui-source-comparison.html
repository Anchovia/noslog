저명한 출처의 난이도 4색 후보 비교

색 사용 여부는 이미 확정했습니다. 아래는 각 출처의 공개 값을 수정하지 않고 Normal / Hard / Expert / Real에 배치한 Light·Dark 비교입니다. Tailwind 색과 임의 혼합값은 없습니다.

범위: 악곡 목록·상세의 반복 탐색용 일반 DOM marker만 비교합니다. 채보 viewer/editor의 page, control, renderer, palette, geometry, animation 및 동작은 전부 잠겨 있으며 이 표본에 존재하지 않습니다.

Light와 Dark 모두 marker 3:1 통과: Adobe Spectrum S2, IBM Carbon Charts, SAP Fiori Horizon.

값은 통과하지만 출처 token이 deprecated: GitLab Pajamas. 나머지는 적어도 한 theme 값이 3:1 미달입니다. 통과 여부는 최종 선택이 아니며, 의미 직관성과 네 role의 적합성은 함께 비교해야 합니다.

색을 끄면 이름, level, 고정 순서, pattern과 선택 표시가 남습니다. Rejected인 neutral-only 후보는 다시 선택지로 올리지 않았습니다.
