NosLog 일반 UI 아이콘 6개 출처 비교

동일한 8개 의미와 NosLog 콘텐츠 비교 결과, IC-06 · Lucide를 일반 UI iconography source로 승인했습니다.

범위: 검색, 위치, 동기화, 설정, 업로드, 이동, 닫기, 삭제의 일반 UI만 비교합니다. 채보 viewer/editor 전체와 최종 logo drawing은 포함하지 않습니다. 아이콘은 전부 무채색이며 행동·상태 색상을 새로 만들지 않습니다.

승인 결과: Lucide 20px default, 16px compact supporting, 원본 24×24 viewBox와 2px round stroke를 유지합니다.

Native size: 각 시스템이 작은 product UI에 권고하는 16/18/20px 크기를 유지합니다. Normalize 20px: 크기 차이를 제거하고 glyph 형태만 비교합니다. 모든 실제 button hit area는 40–44px입니다.
