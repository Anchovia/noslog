# NosLog 2.0 C5 Identity Touchpoint Alias 시각 비교

## 문서 관리

- 상태: `ITA-C achromatic shell identity 승인; 비교 근거 보존`
- canonical 언어: 영어
- 영어 canonical:
  [49-foundation-c5-identity-touchpoint-alias-visual-comparison.md](./49-foundation-c5-identity-touchpoint-alias-visual-comparison.md)
- 날짜: 2026-08-10
- 범위: 승인된 NosLog shell 맥락 4개에서 동일한 provisional mark silhouette로
  `ITA-A`, `ITA-B`, achromatic control `ITA-C` 비교
- interactive artifact:
  [C5 identity touchpoint alias 비교](./specimens/c5-identity-touchpoint-alias-comparison.html)
- 입력: 문서 `15`, `25`, `32`–`48`, 승인된 Spectrum S2 neutral mapping,
  승인된 Radix Indigo identity 소스, 승인된 Fluent focus mapping, 현재 shell
  migration 근거
- 제외: 최종 logo drawing, exported asset, filled primary-action 적격성, 최종
  page design, 애플리케이션 구현

사용자는 문서 `48` 이후 2026-08-10 세 후보 시각 비교 범위를 승인했다. 완성된
specimen을 검토한 뒤 같은 날짜에 identity logo 자체에 색을 적용하는 것은 의도한
NosLog treatment가 아니라는 이유로 `ITA-C`를 선택했다. 이는 achromatic shell
mark와 wordmark를 승인하지만 provisional mark drawing을 승인하지 않는다.

## 고정 비교 계약

1. Adobe Spectrum S2가 candidate fragment의 모든 Light/Dark neutral surface,
   foreground, boundary를 제공한다.
2. Radix Colors Indigo는 승인된 identity 소스로 유지한다. 비교는 정확한 default
   `#3E63DD`를 사용하며 hue, saturation, appearance 값을 변경하지 않는다.
3. Fluent `FI-C`는 Light 검정 / Dark 흰색, `2px`, zero-gap focus로 유지한다.
   기본 identity mark에는 흰 outline이 없다.
4. Candidate color는 graphical mark 또는 그 field에만 나타날 수 있다. Wordmark,
   page title, link, action, selected state, chart data, feedback을 재착색하지 않는다.
5. 모든 후보는 동일한 provisional filled geometric `N` silhouette를 사용한다.
   이는 비교 구조이며 최종 NosLog logo가 아니다.
6. `ITA-B`는 Foundation geometry를 암묵적으로 선택하지 않도록 radius, border,
   shadow가 없는 정사각형 field를 사용한다. 정사각형은 제안하는 최종 app icon이 아니다.
7. `FCM-11`, `SIG-07`, 전체 Indigo header, Indigo 작은 text wordmark, 얇은
   identity rail은 렌더링하지 않는다.

## 정확한 후보 Treatment

| 후보                 | Graphical mark                             | Mark field                                  | `NosLog` wordmark                      | Appearance 동작                                                        | Gate 상태               |
| -------------------- | ------------------------------------------ | ------------------------------------------- | -------------------------------------- | ---------------------------------------------------------------------- | ----------------------- |
| `ITA-A` Indigo mark  | `#3E63DD` filled `N`                       | Transparent                                 | 승인된 appearance별 neutral foreground | Indigo는 고정되고 neutral wordmark는 appearance에 따라 변경            | `Rejected — 2026-08-10` |
| `ITA-B` Indigo field | `#FFFFFF` filled `N`                       | Static `#3E63DD`, radius/border/shadow 없음 | 승인된 appearance별 neutral foreground | Field와 mark pair는 고정되고 neutral wordmark는 appearance에 따라 변경 | `Rejected — 2026-08-10` |
| `ITA-C` Achromatic   | Appearance별 neutral foreground filled `N` | Transparent                                 | 승인된 appearance별 neutral foreground | Mark와 wordmark 모두 neutral appearance foreground를 따름              | `Approved — 2026-08-10` |

승인된 대비 근거는 그대로 유지한다.

- Spectrum Dark canvas `#111111`에 대한 `ITA-A` mark: `3.63:1`;
- Spectrum Dark raised `#222222`에 대한 `ITA-A` mark: `3.06:1`;
- Indigo field에 대한 `ITA-B` white mark: `5.21:1`.

따라서 `ITA-A`는 작은 colored text가 아니라 graphical mark로만 평가한다. 보이는
neutral `NosLog` wordmark와 접근 가능한 Home label은 색상과 독립적으로 identity를
보존한다.

## 네 가지 비교 맥락

| 맥락                      | 공통 콘텐츠 및 구조                                                                                        | Specimen이 검증하는 것                                                         |
| ------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 일반 public shell         | NosLog Home identity, 보이는 Login, 하나의 menu trigger, 작은 Music page lead                              | Desktop, `390px`, `320 CSS px`에서 승인된 오른쪽 control 2개와의 compact 공존  |
| 최소 authentication shell | 큰 identity lockup, archive tagline, neutralized Discord continuation action, 설명 note                    | 일반 navigation 또는 action color 없이 alias가 인식 가능한지                   |
| 집중 chart-viewer shell   | Return control, 제한된 NosLog Home identity, 긴 한국어 music/chart identity, chart metadata, neutral staff | 일반 header를 추가하지 않고 service cue가 chart identity보다 subordinate한지   |
| system-recovery shell     | 큰 identity lockup, fatal-state heading, recovery 설명, neutral retry action                               | Global navigation과 chromatic action을 이용할 수 없을 때 identity가 작동하는지 |

Discord와 retry action은 이 alias gate에서 의도적으로 neutral이다. 최종 visual
treatment는 이후 external-brand 및 action gate가 관리한다.

## 관찰된 시각적 차이

### `ITA-A` — Indigo mark

- 지속 chromatic area가 가장 작으며 wordmark와 shell hierarchy를 거의 완전히
  neutral로 유지한다.
- Container 없는 mark는 Light canvas와 Dark canvas에서 명확하지만 compact
  header 크기에서는 colored option 중 가장 절제되어 있다.
- Authentication과 recovery 맥락에서는 colored symbol 뒤에 독립적으로 읽을 수
  있는 service name이 오는 구조로 보인다.
- 실효성은 이후 최종 mark가 충분한 filled area와 distinctiveness를 갖는지에
  달려 있다. 얇은 최종 drawing이 이 specimen의 측정된 non-text 동작을 자동으로
  상속하지 않는다.

### `ITA-B` — Indigo field

- Chromatic area를 compact field 하나에 제한하면서도 세 후보 중 가장 강하고
  theme-stable한 service recognition을 만든다.
- White-on-Indigo는 Dark white outline을 사용하거나 승인된 identity 값을 바꾸지
  않고 네 맥락 모두에서 읽힌다.
- Field가 `ITA-A`보다 mark를 chart 및 content text로부터 더 명확히 구분한다.
- Field geometry를 장식처럼 다루면 generic app tile과 비슷해질 수 있다.
  `ITA-B` 선택은 field shape 및 radius gate를 끝내는 것이 아니라 새로 연다.

### `ITA-C` — Achromatic control

- 가장 조용한 content hierarchy를 보존하며 domain 또는 external-brand color와
  hue collision이 없다.
- 안정된 배치와 보이는 wordmark가 모든 맥락에서 NosLog를 식별한다.
- Shell에서 승인된 Radix identity 소스를 가시적으로 사용하지 않으며 맥락 간
  chromatic recognition이 가장 약하다.
- 사용자가 service mark를 achromatic으로 유지하고 Radix를 다른 이후 승인
  identity role에 예약하기로 결정한다면 유효한 결과로 남는다.

## 승인 결과

Specimen은 선택을 하나의 material tradeoff로 좁혔다.

- 가능한 가장 작은 color area가 가장 강한 small-size recognition보다 중요하면
  `ITA-A` 선택;
- 이후 field-geometry gate를 수용하면서 Light와 Dark 전반에 고정된 compact
  single-color field가 필요하면 `ITA-B` 선택;
- 가시적인 chromatic shell identity보다 content neutrality가 중요하면 `ITA-C` 선택.

사용자는 `ITA-C`를 선택했다. NosLog shell identity는 logo를 색칠하는 대신 안정된
placement, 최종 mark silhouette, 보이는 wordmark, typography, spacing, semantics에
의존해야 한다. 승인 mapping은 다음과 같다.

- Graphical mark: appearance별 Spectrum S2 neutral foreground;
- 보이는 `NosLog` wordmark: appearance별 Spectrum S2 neutral foreground;
- Mark field: transparent;
- 기본 outline: 없음;
- 실제 keyboard focus: 승인된 Fluent `FI-C`만 사용.

`ITA-A`와 `ITA-B`는 Rejected chromatic logo treatment다. 결정 이력을 폐기하지
않도록 측정 근거는 이 문서와 specimen에 보존한다. Radix Indigo는 승인된 signature
identity source로 유지하지만 승인된 shell identity alias는 없다. 다른 제한된 배치는
별도 사용자 승인 gate가 필요하며, 이 결정으로 Indigo를 action이나 content에
암묵적으로 이동시키지 않는다.

## 브라우저 검증 — 2026-08-10

| Target                    | 결과                                                                                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 기본 desktop `1280 × 720` | 약 `400px`의 candidate 3열 렌더링; context fragment 12개 모두 존재; document 및 검사 component에 가로 overflow 없음                                                                   |
| `390 × 900` Light         | 후보가 쌓이고 각 context card는 약 `333px`; document scroll width와 client width 일치; `44px` 미만 target 없음                                                                        |
| `320 × 900` Light         | 후보가 쌓이고 각 context card는 약 `263px`; document scroll width와 client width 일치; ordinary header 및 viewer identity에 crowding 또는 내부 overflow 없음; `44px` 미만 target 없음 |
| `320 × 900` Dark          | 세 frame 모두 canvas `#111111`, focus `#FFFFFF` 사용; 정확한 mark/field/wordmark mapping이 후보 계약과 일치; 기본 identity pseudo-outline 없음                                        |
| Context filter            | `all`, ordinary header, authentication, viewer, recovery control이 세 후보에서 동일하게 선택된 context 표시                                                                           |
| Focus                     | Native `:focus-visible`이 Light 검정, Dark 흰색으로 `2px`, `inset: -2px` 측정; 명시적인 review-only preview가 이를 기본 mark outline으로 만들지 않고 같은 geometry 노출               |
| Runtime                   | 후보 3개, 후보별 context 4개, console warning 없음, console error 없음                                                                                                                |
| Decision-state regression | `ITA-C`가 비색상 `Approved` label과 neutral outline으로 표시되고 `ITA-A`, `ITA-B`는 보이는 `Rejected` label을 유지; 비교 이력으로 fragment 12개 모두 계속 이용 가능                   |

검증 후 responsive viewport override를 reset했다. Specimen은 field와 mark를 system
color로 mapping하고 보이는 wordmark를 보존하는 forced-colors override를 포함한다.
이번 browser pass에서는 전용 forced-colors emulation을 사용할 수 없었으므로 runtime
forced-colors 렌더링은 확인했다고 주장하지 않고 이후 acceptance check로 남긴다.

## 선택 결과 및 남은 Gate

1. **Shell identity alias — Approved:** transparent field 위 appearance별 neutral
   mark와 neutral wordmark를 쓰는 `ITA-C`.
2. **Chromatic logo alias — Rejected:** `ITA-A`, `ITA-B`; mark를 재착색하거나
   Indigo mark field를 도입하지 않는다.
3. **최종 mark drawing — Pending:** 색상이나 기본 white outline에 의존하지 않고
   최종 silhouette, clearance, 접근 가능한 Home name, exported size를 검증한다.
4. **Radix 배치 — Pending:** downstream handoff 전 승인된 identity source가 다른
   제한된 identity alias를 받을지 문서화한다. Source 승인에서 배치를 추론하지 않는다.
5. **Rare filled primary action — 별도 승인:** 문서 `51`은 Spectrum-neutral
   `RPA-A`를 승인하고 정확한 Dark hover/pressed text-contrast failure 뒤
   `RPA-B/C`를 거절한다. `ITA-C`에서 이 결정을 추론하지 않았으며 Radix action
   alias는 없다.
