- **판정 이름 대문자** — `◆JUST · JUST · GOOD · NEAR · MISS`. 빙고 DB 문구 362칸은 사용자가 Neon 에서 SQL 로 고쳤다.

- **의견 정렬 = `SortMenu`** — 보조 + 고스트 버튼 쌍은 보조 버튼이 입력칸 모양이 되며 선택이 입력칸처럼 읽혔다.

- **입력 컨트롤 한 언어(B′ · R3 · F2 · M2 · B2 · H2)** — 면 #1b1b1b + 경계 #717171 · 모서리 8 · 포커스 후광 ·
  모든 목록을 정렬 메뉴 모양으로 · 보조 버튼 = 입력칸 모양 · 높이 토큰 하나(44/40). 조사 자료 `docs/research/`.
- **홈 구역 제목 20/28** — 다른 페이지와 같게. 입력 글자는 16 유지(모바일 확대 방지).
- **오락실 상세 「위치」 · 「기체」 제목 20** — 레일 상자 안 「최근 확인」 은 16.
- **서열표 카드** — 테두리 = 이 표 달성(기준 색, 달성 + FC 는 초록 → 기준 색 그라데이션, Pianist 는 기준 색 하나),
  자켓 위엔 오른쪽 아래 난이도 판만, 달성한 곡 점수는 기준 색(S 노랑 · 990k 살구 · Pianist 분홍).
- **곡 상세 순위표 = 유저 랭킹 행** — 검정 명판은 넣지 않는다. 320 에서 닉네임 말줄임은 알고 수용.
- **필터 항목 글자 색** — 카테고리 · 난이도 · 내 기록(S 는 JUST 노랑)을 해당 색으로, 올리면 기본 글자색.
- **자켓 수집 = 관리자 북마클릿** — 자켓 없는 곡만 관리자 동기화 때 받아 저장, 사용자 오버레이엔 알리지 않는다.
