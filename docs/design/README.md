### 간격 · 모서리 · 높이 · 아이콘

- **간격:** 0 · 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64. `2` 는 아이콘 · 배지 · 차트 안 광학 보정에만.
  **역할별 값(2026-09-15):** 구역 사이 32 (모든 폭) · **페이지 제목(24/32) → 설명 · 메타 글줄 8, 제목(또는 설명 끝) → 첫 내용 16** ·
  구역 제목(20) → 첫 내용 12 · 상자 제목(16) → 내용 8 ·
  카드 안쪽 16 (목록 항목 카드 12 · 촘촘 격자 카드 8 · 1056 이상 큰 카드 24) · 떨어진 목록 줄 사이 8 (구분선 목록 0) · 문단 사이 16 ·
  선으로 나눈 묶음(필터 그룹 · 개인정보 요약)은 선 위아래가 같다 — 레일 · 팝오버 16, 전체 화면 창 24, 개인정보 요약 12.
- **모서리:** 누르는 상자 `radius/field` 8 (입력 · 셀렉트 · 검색 · 버튼 · 트리거 · 칩 · 적용 조건 · 페이지 번호 ·
  패턴 투표 버튼) / 상자 안 항목 · 체크박스 · 태그 `radius/control` 4 / 카드 `container` 8 / 떠 있는 창 `overlay` 10 / 원 `full`.
- **높이 — 두 단계(2026-09-15):**
  **큰 L** `--nl-control-height` 44 (1056 이상 40) — 입력 · 셀렉트 · 검색 · 필터 트리거 · 2단 탭 · 페이지 주 액션
  (하단 바 · 레일 · 목록 카드 액션 · 폼 제출 · 대화상자 버튼 · 설정 폼 행의 버튼).
  **중간 M** `--nl-control-height-compact` 36 (1056 이상 32) — 카드 안 버튼(오락실 기체) · 상자 없는 인라인 보조
  (팝오버 머리 줄 「초기화」 · 적용 조건 「전체 지우기」 · 「영역 초기화」 · 알림 안 「다시 시도」 · 시트 요약 줄 정렬) · 필터 칩 · 적용 조건 토큰.
  전체 화면 창 발의 「초기화」 는 주 액션과 같은 줄이라 L.
  버튼은 `size="sm"` 이 M. 아이콘 버튼은 자기 줄의 단계. **같은 줄은 한 단계.**
  폼 제출이라도 상자 안 인라인 칸의 버튼(의견 작성 칸 「취소 · 의견 작성」, 평가 잠금 카드 「로그인」)은 M — 이 둘 밖에 예외 없음.
  폼 안 **첨부 버튼**은 입력칸 역할이라 L — 붙인 뒤 들어서는 파일 줄(L)과 높이가 같아 자리가 튀지 않는다(2026-09-18).
- **선 두께 — 두 단계(2026-09-22):** **기본** `--nl-stroke-default` 1 — 구분선 · 경계(카드 · 입력 · 태그 · 떠 있는 창) · 포커스 선 · 칸 사이 선(gap + divider 바탕).
  **강조** `--nl-stroke-strong` 2 — 선택 밑줄(밑줄 탭 · 수치 전환) · 강조 테두리(서열 달성 · 체크박스 · 라디오 링 · 빙고 선택) · 위쪽 진행 막대.
  CSS 는 선 두께를 숫자로 쓰지 않는다 — `border` · `outline` · `box-shadow` 선 · 음수 오프셋(`calc(var(--nl-stroke-default) * -1)`) · 테두리를 빼는 여백 보정도 이 토큰. 선이 아닌 1 · 2(모서리 · 광학 보정 · 그림자 흐림)는 해당 없음.
  1단 탭 48. 펼쳐지는 메뉴 · 목록 행(셀렉트 · 정렬 · 검정 목록 · 「⋯」 메뉴 · 레일 체크 목록 · 설정 오락실 목록)은 L,
  헤더 메뉴(≡) 이동 줄만 48(1056 이상 40).
- **아이콘:** Lucide 실제 모양. 20 기본 · 16 글자 옆 보조 · 24 강조와 창 머리 가장자리 닫기.

### 포커스 · 상태 · 움직임

- **포커스:** 컨트롤 자신의 1px 흰 선 — 평소 경계가 있으면 색만 바꾸고, 없으면 포커스에서만 그린다.
  입력 · 셀렉트 · 검색 · 버튼은 여기에 바깥 4px 후광(`--nl-state-halo`)을 더한다.
- 목록(셀렉트 목록 · 정렬 메뉴) 항목의 흰 선은 **키보드로 움직일 때만** — 마지막 입력을
  `lib/inputModality.ts` 가 `<html data-input>` 에 적는다.
- **올림(hover) 면은 포인터 장치에서만** — 모든 `:hover` 규칙은 `@media (hover: hover)` 안에(터치는 탭한 뒤 hover 가 남아
  선택된 것처럼 보인다). `:not(:hover)` 로 평소 색을 정하는 규칙은 밖에 둔다.
- **누름**은 색 단계만. 크기 줄이기(scale) 없음. **문서에 없는 움직임을 넣지 않는다** — 상태는 즉시 바뀐다.
- **바쁨(busy)은 비활성이 아니다:** 버튼은 스피너 16 + 진행형 라벨. 화면 · 영역 로딩은 아래 「로딩」.
- **떠 있는 창**(목록 · 메뉴 · 팝오버 · 대화상자 · 차트 툴팁): 면 #222 · 1px `border/overlay` · 모서리 10 · `--nl-overlay-shadow`.
  예외 없음 — 헤더 메뉴 패널만 헤더에 붙는 위쪽 경계를 긋지 않는다. 미디어 위 판(자켓 카테고리 · 서열 카드 난이도)은 떠 있는 창이 아니다.

### 움직임 (2026-09-19)

근거: 디자인 가이드 6곳(Material 3 · Carbon · Apple HIG · Fluent 2 · Atlassian · Primer) + 실제 서비스 19곳 실측(데이터 · 랭킹 7 · 제품 12).
NosLog 는 데이터 서비스라 움직임은 **상태 · 위치 · 로딩**에만 쓰고 장식은 없다. **아래 목록에 없는 곳은 즉시 바뀐다.**

- **값은 `tokens.css` 의 움직임 토큰만** — CSS 에 숫자 시간 · `cubic-bezier` · `ease`/`linear` 를 직접 쓰지 않는다(인라인 · 부품별 값 금지, 테스트가 막는다). 새 움직임이 필요하면 이 목록과 토큰을 먼저 고친다.

| 토큰                                                        | 값                                                    | 쓰는 곳                                                       |
| ----------------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------- |
| `--nl-motion-duration-state`                                | 100ms                                                 | ① 올림 · 누름 색                                              |
| `--nl-motion-duration-popup`                                | 150ms                                                 | ③ 떠 있는 메뉴 열림                                           |
| `--nl-motion-duration-overlay-in` · `-out`                  | 200 · 150ms                                           | ④ 대화상자 · ⑤ 토스트 나타남 · 사라짐                         |
| `--nl-motion-duration-move`                                 | 200ms                                                 | ⑫ 헤더 숨김 · 오락실 시트                                     |
| `--nl-motion-duration-chart-in` · `-change`                 | 800 · 300ms                                           | ⑯ 그래프 나타남 · 값 바뀜                                     |
| `--nl-motion-loop-spin` · `-pulse`                          | 800 · 1600ms                                          | ⑩ 스피너 한 바퀴 · ⑪ 스켈레톤 한 번                           |
| `--nl-ease-enter` · `--nl-ease-exit`                        | `cubic-bezier(0.4, 1, 0.6, 1)` · `(0.6, 0, 0.8, 0.6)` | 들어올 때 감속 · 나갈 때 가속(Atlassian practical 과 같은 값) |

| `--nl-motion-delay-progress` · `--nl-motion-delay-skeleton` | 100 · 300ms                                           | 이 안에 끝나면 위쪽 진행 막대 · 스켈레톤을 띄우지 않음        |
| `--nl-motion-duration-progress`                             | 1500ms                                                | 위쪽 진행 막대가 80% 까지 차오름                              |

- **① 올림 · 누름 색** — 누를 수 있는 모든 것(`a` · `button` · `summary` · `label` 로 만든 줄 · 옵션 · 메뉴 항목 · 탭, 누를 줄을 품고 올림 면을 칠하는 카드 — 펼침 카드 · 오락실 결과, 올림 면을 `::before` 로 그리는 버튼)에 같은 값. 배경 · 글자색만 움직이고 포커스 선 · 경계는 즉시.
- **③ 떠 있는 메뉴**(셀렉트 · 정렬 · ⋯ · 필터 팝오버 · 빙고 칸 · 지도 범례 · ≡ 메뉴 · 폰 ≡ 뒤 어둠) — 열 때 페이드만, **닫을 때 즉시**
  (셀렉트 · ≡ 메뉴는 닫는 순간 떼어져 닫힘 움직임을 줄 수 없어 모두 즉시로 맞춤).
- **④ 대화상자 · 전체 화면 창** — 나타날 때 페이드 + 8 떠오름, 사라질 때 페이드만. 떠오름은 `translate` 속성(가운데 맞춤 `transform` 과 따로).
- **⑤ 토스트** — 나타날 때 페이드 + 8 올라옴, 사라질 때 페이드만(sonner 기본 400ms · 전체 높이 이동을 토큰으로 덮음).
- **⑩ 스피너** 회전 · **⑪ 스켈레톤** 불투명 1 → 0.5 깜빡임.
- **⑫ 위치 이동** — 헤더: 나타날 때 감속 · 숨을 때 가속. 오락실 시트: 화면 안 이동이라 감속. 손가락으로 끄는 동안은 움직임 없이 따라간다.
- **⑯ 그래프**(막대 목록 · 누적 막대 · 선 그래프, 2026-09-19 A) — 나타날 때 막대 · 선이 왼쪽부터 드러나고(바닥선 · 틀은 그대로),
  같은 막대 · 같은 점의 값이 바뀌면 새 값으로 옮겨 간다. 선 그래프는 점 구성(날짜)이 바뀌면 다시 드러난다. SVG 선의 옮겨 감은 `lib/motion` 이 같은 토큰을 읽어 움직인다.
  그래프를 그리는 곳은 공용 부품이든 페이지(프로필 랭크 분포 · 판정 요약 · 관리자 대시보드)든, 값이 바뀌는 진행 막대(빙고 상세 진행 · 악곡 머리 그레이드)든 공용 클래스 두 개만 붙인다. 빙고 목록 카드의 완료 막대는 값이 바뀌지 않고 여러 장이 한꺼번에 움직여 장식이라 움직임 없음 — 드러남 `nl-chart-reveal` · 막대 길이 옮겨 감 `nl-chart-bar`.
- **⑮ 지도** — 카드를 누르면 핀으로 미끄러진다(카카오맵 `panTo`). 목록 스크롤은 즉시.
- **즉시(움직임 없음)** — ② 누름 크기 줄이기 · ⑥ 탭 밑줄 · ⑦ 구역 펼침 · ⑧ 툴팁(그래프 · 용어 도움말) · ⑨ 체크박스 · 라디오 · 토글 · ⑬ 스크롤 연출 · ⑭ 페이지 이동.
- **동작 줄이기** — 기기 설정이 켜지면 `tokens.css` 한 곳에서 시간 토큰을 모두 0 으로(스피너 한 바퀴만 남김 — 멈추면 고장처럼 보인다). 지도는 JS 라 같은 설정을 읽어 곧바로 옮긴다.
- 손대지 않는 것: 채보 캔버스, 카카오맵 안 타일 페이드(라이브러리), 공식 사이트 위 북마클릿 창.

### 로딩 (2026-09-19)

근거: 디자인 가이드 7곳 · 실서비스 15곳 실측 · 우리 사이트 측정 — [로딩 시안 · 조사](./drafts/loading/). 로딩 표시는 **한 영역에 하나**.

- **사이트 안 이동 = 위쪽 진행 막대**(`NavigationProgress`, 일반 · 관리자 셸에 각각 하나) — 사이트 안 링크를 누르고 `--nl-motion-delay-progress` 안에 끝나지 않으면
  맨 위 2px `primary/default` 막대가 80% 까지 차오르고, 새 화면이 오면 끝까지 채우고 사라진다. **이전 화면은 그대로**(흐리게 하지 않음).
  다른 처리가 클릭을 막아 이동하지 않으면(저장 안 한 변경 안내 등) 뜨지 않는다. 동작 줄이기에서도 막대는 남는다.
- **스켈레톤 = 실제 부품의 틀 · 클래스 그대로** — 컨테이너 · 간격 · 안쪽 여백 · 높이가 저절로 같다. 제목 · 탭 · 필터 · 라벨처럼 **고정된 부분은 실제 글자 · 실제 부품**,
  이름 · 수치 · 사진 · 그래프 · 목록 자리만 스켈레톤. 부품마다 `…Skeleton` 을 부품 곁에 둔다(결과 카드 · 채보 묶음 · 기록 줄 · 순위 줄 · 곡 순위 줄 · 서열 카드 · 빙고 카드 · 의견 줄 · 막대 목록 · 수치 칸 · 수치 띠).
    - 글자 자리 `SkeletonText` — 그 글자 스타일 클래스를 받아 줄 높이(1lh)를 차지하고 막대는 글자 크기(1em). 폭은 네 단계(25 · 50 · 75 · 100%)만,
      짧은 값(순위 · 숫자)은 보이지 않는 표본 글자(「0,000」) 폭만큼 — 기준선 정렬 줄에서도 실제 글자와 같은 선에 선다. 값 칸에는 실제와 같은 글자 스타일 클래스를 붙여 줄 높이를 맞춘다.
    - 채움 = `border/subtle` 하나(어느 바탕 · 면 위에서도 보인다) · 모서리는 실제 부품 것 · 펄스(⑪). 입력 · 셀렉트 자리 = 컨트롤 L 높이 · 모서리 8.
    - **스켈레톤 안에 스피너를 넣지 않는다.** 모양을 모르는 한 덩어리(지도 등)만 그 자리 가운데 스피너 20.
- **시간** — 첫 진입(서버가 그림)은 지연 없이 스켈레톤. 화면 안 다시 불러오기는 `nl-loading-delay`(`--nl-motion-delay-skeleton`) 동안 숨겨 짧으면 번쩍이지 않게.
  최소 표시 시간은 두지 않는다. 다시 불러오는 동안 이전 내용이 있으면 그 내용을 흐린 색(pending)으로 두고 스켈레톤 · 글자를 끼우지 않는다.
  단 **값의 뜻이 바뀌는 전환**(지표 Grd ↔ 레이팅 · 기간 · 모드 Basic ↔ Recital — 성장 추이 · 베스트 성과)은 이전 내용을 두지 않는다. 처음 `--nl-motion-delay-skeleton` 동안만 흐린 색, 넘으면 같은 틀의 스켈레톤(그래프 면 · 요약 값 · 목록 줄, 라벨은 실제 글자). 같은 지표에 줄만 이어 붙는 「더 보기」 는 해당 없음.
  관리자 대시보드의 기간 전환도 같은 규칙 — 제목 · 기간 버튼 · 지표와 패널 라벨은 실제 부품으로 두고, 수치 · 그래프 · 목록만 현재 패널과 행 수가 같은 스켈레톤으로 바꾼다. 기간이 붙는 보조문구는 고정 안내를 두고 기간 값만 글자 스켈레톤으로 바꾼다. 같은 기간의 지표 전환은 이미 받은 값으로 즉시 바꾸므로 로딩을 만들지 않고, 주소·뒤로 가기와 기존 그래프 움직임을 유지한다.
- **안내** — 「…불러오는 중」 문장은 화면 읽기에만(`LoadingStatus`, 한 번), 로딩 중인 영역은 `aria-busy`. 보이는 곳에 로딩 문장 한 줄만 두지 않는다.
- 실제와 같은지 확인: 요청을 늦춰 스켈레톤일 때와 내용이 들어온 뒤 요소 위치 · 크기를 재서 비교한다(폭 390 · 1280).
